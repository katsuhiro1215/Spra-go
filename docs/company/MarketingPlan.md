# マーケティング方針

MVPは1ヶ月程度でのリリースを目標とし、対象は日本・アメリカ・イギリス・フランスの初級コンテンツ、課金導線なしの無料公開（`docs/MVPRequirements.md`）。広告予算はなく、実働も少人数（実質ソロに近い）という前提のもと、**広告に頼らず「サイト自体がコンテンツになる」形でオーガニック流入を積み上げる**ことを基本戦略とする。

## 1. 競合分析

| プロダクト | 特徴・獲得手法 | 無料→有料の転換 | SpraGoが学べる点 |
|---|---|---|---|
| **Duolingo** | インフルエンサー施策・SNS・PR・キャンペーンの4本柱。特にTikTokでは公式マスコット「Duo」を使ったミーム的投稿がトレンド音源に乗って伸び、動画再生数の増加が新規インストール増と相関している。ソーシャルリスニングで反応を製品・コンテンツ改善に還元 | ストリーク・ハート（体力）制で継続を促し、広告非表示や無制限ハートを有料化 | 「ゲームのキャラ・世界観そのものをSNSのネタにする」発想。SpraGoにもキャラや世界観（草原→森→雪山→宇宙の背景演出、飛行機アイテムなど）があるので同じ手が使える。ただしDuolingoの専属SNSマーケターによる日次投稿・大規模インフルエンサー起用は予算・人員が必要で今は真似できない |
| **はんぷく学習シリーズ「世界の国旗クイズ」**（3000万〜5000万DL） | 広告色のないシンプルな無料クイズアプリを多数リリースし、ASO（アプリストア内検索）と「国旗 クイズ」等の検索意図に直接応える設計で長期的に流入 | 広告表示＋アプリ内課金（広告除去）中心の軽量マネタイズ | 派手なプロモーションをせずとも、「検索されるキーワードにそのまま応えるコンテンツ」を大量に用意すれば個人開発規模でも数千万DL規模まで伸びる実例。SpraGoも「国旗 クイズ」「世界遺産 クイズ」等のロングテール検索需要はWebサイト側で拾える |
| **GeoGuessr / Seterra**（Seterraは長年運営された地理クイズサイトで、現在はGeoGuessrに統合） | Seterraは約20年、学校教員が授業で埋め込み利用する形で口コミ的に広まった無料Webクイズ。GeoGuessrはストリーマー・YouTuberがプレイ動画を配信すること自体が観戦コンテンツとして成立し、バイラルに寄与 | GeoGuessrは無制限無料プレイを廃止しPro等のサブスクへ移行。反発から無料代替サイト（FreeGuessr等）が生まれるなど、値付けの反発リスクも顕在化 | 「教材として先生・親が使いたくなる／子どもに見せたくなる」導線と、「プレイ自体が見て楽しいコンテンツになる」設計は広告費ゼロでも拡散する。一方で無料→有料の切り替えタイミングを誤るとユーザー離反を招く点は反面教師にする |
| **QuizKnock**（東大発の知識集団、YouTube登録者220万人超・視聴者の約8割が34歳以下） | 個人の「顔」が見えるクイズ・雑学コンテンツをYouTube中心に展開し、そこからWebメディア・ゲームアプリ・イベントへ拡大。広告費ではなくコンテンツ自体のファン化で成長 | 直接的な自社課金より、企業案件・イベント・メディア展開などのマネタイズが中心 | 「中の人」が見える継続発信が、ゼロ予算スタートでも数年でメディア化する好例。SpraGoも「なぜこの国を選んだか」「クイズの元ネタ」等をCEO/開発者目線で発信する余地がある |
| **あそんでまなべる 世界地図パズル**（Digital Gene） | 地図パズル形式の子供向け教育アプリ。派手な広告よりアプリストアのカテゴリ内評価・レビューで安定集客 | 買い切り・軽量課金 | 「老若男女」ではなく「親子で一緒に遊べる」ことを前面に出すニッチ訴求のほうが、小規模開発では刺さりやすいという示唆 |

**大きな予算が要る部分（今は真似しない）**: Duolingo規模の専属SNS運用チーム、有名インフルエンサー起用、大規模広告キャンペーン。
**個人〜小規模チームでも再現できる部分**: 検索意図に直接応えるコンテンツの量産（はんぷく学習シリーズ型）、教材として使いたくなる無料設計（Seterra型）、プレイ自体が見て楽しい・共有したくなる演出（GeoGuessr型）、「作り手の顔」が見える継続発信（QuizKnock型）。

## 2. Webサイト戦略

公式サイトはアプリ（ゲーム本体）とは別に、**「検索から流入し、遊んでみたくなってサインアップする」ための独立した窓口**として設計する。

### 構成（最小構成）
1. **トップ/LP**: 「興味が世界を広げ、世界が言葉を教えてくれる」というコンセプトを一文で伝え、プレイ画面のスクリーンショット・レベルアップ演出のGIF等でゲームらしさを最優先に見せる。CTAは「無料ではじめる」一択（有料訴求はMVPでは不要）
2. **国旗・国クイズの単体ページ群**: 「日本」「アメリカ」「イギリス」「フランス」それぞれについて、国旗・基礎知識・簡単な3問クイズを埋め込んだ静的ページを用意。Seterra型の「検索から直接クイズページに着地する」導線を最初から作る
3. **ブログ**: SEO軸。下記トピック例を月2〜4本ペースで
4. **会社・運営情報**: `docs/company/`にある内容を対外向けに簡略化したもの（運営者情報、問い合わせ）

### 基本SEO
- タイトル・見出しに「国名＋クイズ」「世界遺産＋クイズ」等、検索される複合語をそのまま使う（凝った言い回しより検索意図優先）
- 国・クイズ単位でURLを分け、内部リンクで回遊させる（1ページに情報を詰め込みすぎない）
- 表示速度・モバイル対応（Next.jsの標準機能で十分満たせる）

### ブログ記事テーマ例（地理・国旗・文化はネタが尽きにくい）
- 「似ている国旗を見分けるコツ」「国旗に隠された意味・由来（対象4ヶ国から）」
- 「世界遺産クイズ：フランスの世界遺産◯選」
- 「子どもと一緒に地図で世界を学ぶ方法」（親向け導線）
- 「日本・アメリカ・イギリス・フランスの学校生活の違い」等、雑学として拡散しやすい比較ネタ
- コンテンツ制作チーム（企画部門配下）が問題原稿を作る過程で得た調査素材をそのままブログ化すると、二重取材の手間を省ける

## 3. SNS戦略

老若男女ターゲットだが、無予算・少人数では全チャネル展開は不可能。以下2チャネルに絞る。

1. **X（Twitter）**: 日本語の雑学・クイズ系コンテンツと相性が良く、「今日のクイズ」形式の軽い投稿を継続しやすい。Duolingoのようにキャラクター（世界観の背景演出やアイテム）を擬人化した「中の人」的な発信も可能。開発の進捗共有（ビルドインパブリック）も個人開発文脈で反応を得やすい
2. **Instagram**: 親・ママ層とSNSの相性が最も良いチャネルとされ、「親子で学べる」訴求に向く。国旗・世界遺産の写真的なビジュアル、リール（短尺動画）でのプレイ画面紹介に向いている

YouTube ShortsやTikTokはQuizKnock・Duolingoのような継続投稿体力が必要なため、MVP直後の優先度は下げる（後述）。

### コンテンツフォーマット例
- 「今日の国旗クイズ」形式の1問投稿（回答は次の投稿で）
- プレイ画面・レベルアップ演出の短尺動画（体力・コンボ等ゲーム性を見せる）
- 「この国旗の由来、知ってる？」的な雑学ネタ（QuizKnock・はんぷく学習シリーズ型の検索意図に近い）
- 開発の裏側・コンテンツ制作の裏側（個人開発ならではの共感獲得）

## 4. 実行の優先順位（インパクト×工数）

| 優先度 | 施策 | 理由 |
|---|---|---|
| 高（リリース前に最低限） | LP1枚＋対象4ヶ国のクイズ単体ページ | サイトがないと検索流入もSNSからの受け皿もない。工数は小さく効果は大きい |
| 高 | X アカウント開設・週数回の「今日のクイズ」投稿開始 | 無料・低工数で開始でき、ローンチ告知の土台になる |
| 中 | ブログ月2〜4本 | SEOは効果が出るまで時間がかかるため、ローンチ直後よりコンテンツ制作と並走で継続することが重要。リリース直前に無理に量産しない |
| 中 | Instagram開設 | Xと運用リソースを食い合うため、Xが軌道に乗ってから着手でも良い |
| 低（リリース後でよい） | YouTube Shorts/TikTok本格運用 | 動画制作は工数が大きく、MVPの最優先（コンテンツ制作・経済ロジックのテスト）を圧迫するリスクがある |
| 低（リリース後でよい） | インフルエンサー施策・広告出稿 | 予算前提の施策。まずは無料流入で反応を見てから検討 |

**結論**: この1ヶ月は「サイトの土台（LP＋クイズページ）」と「X運用の型を作ること」の2点に絞る。ブログ・Instagramはローンチと並走で開始し、動画系チャネルと広告は明確に後回しにする。

## 5. 月商100万円との接続（試算の前提）

有料プラン価格は未確定（`docs/company/BusinessPlan.md`）だが、仮に月額500円のシンプルなプランと仮定すると、月商100万円には**有料会員 約2,000人**が必要になる。フリーミアム型サービスの無料→有料転換率は一般的に数%程度とされる（本ドキュメントでは検証済みの数値がないため幅を持たせる）。仮に転換率2〜5%だとすると、必要な月間アクティブ無料ユーザーは**4万〜10万人規模**となる。

広告費ゼロでこの規模に到達するには、単発のバズではなく「検索から継続的に人が流入する資産（サイト・ブログ・クイズページ）」を積み上げる必要がある。これはSeterra・はんぷく学習シリーズのような無料コンテンツの物量戦略、およびQuizKnock型の継続発信と同じ考え方であり、MVPの1ヶ月で完成させるものではなく、**リリース後も継続する前提の投資**として位置づける。MVP期間中にやるべきことは、有料化の準備ではなく、無料の間にできるだけ多くの人にサイト経由で試してもらう導線を作ることに尽きる。
