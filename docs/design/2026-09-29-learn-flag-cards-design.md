## 1. 背景と目的

学ぶタブ（`/learn`）の国選びは、幅によって形がちがう。

- スマホの幅: 小さな国旗の付いたボタンを2列に並べている
- パソコンの幅: 国を丸く並べる形と、本物の世界地図（`WorldMap`）を切り替える
  - 丸く並べる形では、6つ目の国（アメリカ）が下のメニューに隠れる（幅1280px・高さ800pxで確認）
  - 世界地図は小さい国が押しにくく、色が付くのは着いた国だけなので、ほとんど灰色に見える

地図をやめ、どの幅でも同じ国旗のカードにする。カードには、その国をどこまで進めたか（クリアしたステージの数）を出し、次にどの国で学ぶかを選びやすくする。地図の役割は、せかいタブ（`/trip`）の島の地図にまとめる。

**うまくいった目安**

1. 幅320〜1280pxのどこでも、全部の国のカードが重ならず、下のメニューにも隠れずに見える
2. 着いた国のカードで、国旗・国名と「クリアしたステージの数／全部の数」がわかる
3. まだの国は、着いた国と分けて並び、押すと今と同じ「せかいへ」の案内が出る
4. 世界地図の部品・画像・CSSがなくなる

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| 形 | どの幅でも国旗のカード。「フラッグ／地図」の切り替えと、丸く並べる形はやめる |
| カードの中身 | 国旗（大きく）・国名・クリアしたステージの数と全部の数。全部クリアした国は「ぜんぶクリア！」 |
| 分け方 | 「着いた国」を上、「まだの国」を下に分ける |
| 数え方 | 国の一覧のAPI（`GET /api/countries`）に、国ごとの数（`achievement: { cleared, total }`）を足す。画面の読み込みは今と同じ1回 |
| 世界地図 | 学ぶタブからなくし、部品・画像・CSSも消す。地図の役割はせかいタブにまとめる |

## 3. 画面（`/learn`）

### 3-1. 並び

上から次の順に並べる。

1. 見出し「どこから冒険する？」と「着いた国で学べるよ」（今のまま）
2. 「着いた国」の段: 見出し「着いた国」と、着いた国のカード
3. 「まだの国」の段: 見出し「まだの国」、その下に「せかいでチケットを使うと行けるよ」、まだの国のカード。まだの国がないときは、この段ごと出さない

- カードの並びは、スマホの幅（`md` より狭い）で2列、パソコンの幅で3列。幅は今と同じ最大768px（`max-w-3xl`）
- 国の順番はAPIの順（日本 → 旅の行き先の順）のまま。段に分けても、段の中の順番は変えない
- 見出しの文字は空の上に出すので、ほかの見出しと同じく時間帯で色が変わる部品（`SkyText`）を使う
- 国が1つもないときの「まだ国が登録されていません。お楽しみに。」と、読み込み中のスプルは今のまま

### 3-2. 着いた国のカード

- クリーム色のカード（`#fffaf0`・角丸・下に影）。カード全体が1つのリンクで、押すと今と同じ国の画面（`/travel/{id}/start`）へ移る
- 中身（上から）
  1. 国旗: 縦横2:3、カードの幅いっぱいに近い大きさ（スマホで幅約96px）。画像は今と同じ `/flag/{code}.svg`
  2. 国名: 太字。漢字にはふりがな（`AutoFurigana`）
  3. 進み具合の棒: 緑の棒で、クリアした割合だけ伸びる
  4. 数: 「3/20」。全部クリアした国は「ぜんぶクリア！」にして、クリアのステージの丸の絵（`SPRU_STAGES.cleared`）を小さく添える
- 読み上げの名前: 「日本、20ステージ中3クリア」（全部クリアは「日本、ぜんぶクリア」）

### 3-3. まだの国のカード

- 着いた国のカードと同じ大きさで、ベージュ（今の鍵のボタンの色）。国旗は灰色にし、国旗の左上の角に鍵の丸い印を重ねる（実装のときに変更。カードの角に置くと幅320pxで国旗にかぶり、国名の前に並べると「インドネシア」が2行に折れたため）
- 国名だけを出し、数と棒は出さない（まだ行けないため）
- 押すと、今と同じ「〇〇はまだの国」の案内（`LockedCountrySheet`）が下から出る
- 読み上げの名前: 「韓国(まだの国)」（今のまま）

### 3-4. 残すもの

- 右端のミニアプリの引き出し（`◀` のタブ）
- 鍵の国の案内（`LockedCountrySheet`）と、その文（`lockedCountryText`）

## 4. サーバー（`GET /api/countries`）

国ごとに `achievement` を足す。ほかの項目（`locked`・`has_language_mode` など）は今のまま。

```json
{ "id": 1, "code": "jp", "name": "日本", "locked": false, "has_language_mode": true, "achievement": { "cleared": 3, "total": 20 } }
```

- `total`: その国の、問題が1問以上あるステージの数。トリビアの初級〜上級・英語・地方のステージを全部数える
- `cleared`: そのうち、今遊んでいるプロフィールがクリアした（`profile_stage_progress.cleared_at` がある）ステージの数。ほかのプロフィールのクリアは数えない
- 今遊んでいるプロフィールがないときは `cleared` を0にする
- まだの国にも同じ形で付ける（画面では出さない）
- 項目の名前は、国の画面の地方の達成（`achievement: { cleared, total }`）に合わせる
- 数えるための読み込みは、国の数によらず2回（全部の国のステージをまとめて1回、プロフィールのクリアを1回）にする

今のデータでの `total`: 日本20・アメリカ45・イギリス45・フランス18・インドネシア18・韓国18。

## 5. 画面の部品

| ファイル | 役割 |
|---|---|
| `frontend/src/components/learn/country-cards.ts`（新しく作る） | 計算だけの部品。国を「着いた国」と「まだの国」に分ける（`learnSections`）、数の文（`achievementText`）、棒の割合（`achievementRatio`）、読み上げの名前（`countryCardLabel`） |
| `frontend/src/components/learn/country-card.tsx`（新しく作る） | カードの見た目。着いた国のカード（`ArrivedCountryCard`）と、まだの国のカード（`LockedCountryCard`） |
| `frontend/src/app/learn/page.tsx` | 3章の並びにする。切り替え・丸い並び・地図・`FlagThumb` を消す |

- `achievementText({ cleared, total })`: `total` が0なら `null`、`cleared >= total` なら「ぜんぶクリア！」、ほかは「3/20」
- `achievementRatio`: 0〜1におさめた割合（`total` が0なら0）
- 国の型に `achievement: { cleared: number; total: number }` を足す

## 7. テスト

### 7-1. サーバー（Pest、`tests/Feature/CountriesIndexTest.php`）

- 国ごとに `achievement` が付き、`total` は問題のあるステージだけを数える（問題のないステージは数えない）
- `cleared` は今遊んでいるプロフィールのクリアだけを数える（同じ国を別のプロフィールがクリアしていても数えない）

### 7-2. 画面（Vitest、`frontend/src/components/learn/country-cards.test.ts`）

- `learnSections`: 着いた国とまだの国に分け、それぞれの中の順番はAPIの順のまま
- `achievementText`: 3/20 →「3/20」、20/20 →「ぜんぶクリア！」、0/0 → `null`
- `achievementRatio`: 3/20 → 0.15、0/0 → 0、`cleared` が `total` を超えても1
- `countryCardLabel`: 「日本、20ステージ中3クリア」「日本、ぜんぶクリア」

### 7-3. ブラウザでの確認

- 幅320・390・1280pxで、町テスト（着いた国は日本だけ）の学ぶタブ
  - 全部のカードが見え、下のメニューに隠れない。横にはみ出さない
  - 日本のカードに国旗・国名・棒・数が出る
  - まだの国を押すと「せかいへ」の案内が出て、閉じられる
  - 日本のカードを押すと、日本の画面へ移る
- 確かめたあと、開発用のデータを確認前の状態に戻す（学ぶタブを開くだけではデータは変わらないが、日本の画面まで移ったときに変わっていないか確かめる）

## 8. やらないこと

- せかいタブの地図の作り替え（国が6〜7か国を超えたら「大陸ごとの島」にする案。国を増やすときに別の仕事にする）
- パスポートの「世界地図が埋まる」の構想（`SPEC.md` 4-4b）。地図を使うときは、せかいタブの地図を元に考える
- カードにスタンプの絵（スプル入りのバッジ）を出すこと（韓国など、まだ絵のない国があるため）
- 進み具合による並べ替え・おすすめの国の印
