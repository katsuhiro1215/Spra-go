## 1. 目的

- ランのタネの使い道の中心を作る。「集めたタネで、好きな衣装を選んで買う」。
- 走る・集める楽しさに、「見た目の楽しみ」を足す。ただし、学びの進み(コイン・ポイント・経験値)とは混ぜない。

## 3. ルール

| 項目 | 内容 |
|---|---|
| 手に入れ方 | タネ交換所で、ランのタネを払って買う。1着ずつ。買った物は**ずっと持てる**(消えない) |
| 着る | 1着だけ着る(または、ふつうのスプルに戻す)。プロフィールごとに覚える |
| 売る場所の出し方 | **その季節だけ、交換所に並ぶ**(ハロウィンは10月、クリスマスは12/1〜25。`GameRollout` の `season` と同じ形)。季節の外では並ばない(買った物は着られる)。→ 「あの季節だけ」で、集める楽しみが出る |
| 着られる場所 | きせかえの画面・町のスプルのあいさつ・スプルランの入口と結果・プロフィール |
| 着ない場所 | **クイズ・ミニクイズ・スプルランの遊びの中**(絵の数が多く、表情・ポーズが衣装ごとに要るため。反応を見てから) |
| 既存の「季節のあいさつ」(mascot-8の衣装4つ) | そのまま残す。着ている衣装があるときは、その衣装でごあいさつする |

## 4. 絵

- **1着につき、立ち姿の1枚**を使う(ハロウィン6・クリスマス6)。ランの入口・結果・町・プロフィールの、ふつうのスプルの絵(`cheer` など)のかわりに出す。
- ハロウィンの走りの絵は、ランの中で着ないので、**今回は使わない**(取っておく)。クリスマスの走りの絵は、頼まなくてよい。
- **背景の色つきの光(にじみ)を、描き直しで消してもらう必要がある。** 切り抜くと、緑・赤・オレンジの光が体のまわりに残るため。
  - 頼み方(ChatGPTに、元の絵を添えて): 「この絵と同じ構図・同じキャラクター・同じ衣装・同じポーズのまま、**背景を、光やぼかしのない真っ白(または透明)に**描き直してください。体のまわりの色つきの光、影は消してください。6体は、間隔をあけて並べてください」
- 取り込み: `tools/spru-assets/` に、きせかえ用の切り抜きを足す(元の絵は `company/spra/mascot/assets/costumes/` に整理して置く)。1着=`public/spru/costumes/{キー}.webp`。大きさ(幅・高さ)を `spru-assets.ts` に書き出す。
- 「S字の芽を守る」ルール(ブランド): 衣装の絵でも、芽の形が見えること。かぼちゃ系の2着は、頭に別の葉があるので、取り込むときに確かめる。

## 5. 仕組み

**設定** `config/costumes.php`: キー・名前・季節(`from`・`until`。`MM-DD`)・値段・絵のキー。

**データ**
| 場所 | 内容 |
|---|---|
| `profile_costumes`(新規) | `user_profile_id`・`costume_key`・`acquired_at`。`(user_profile_id, costume_key)` は一意 |
| `user_profiles`(足す列) | `costume_key`(いま着ている衣装。なければ null) |

**API**
| 道 | 内容 |
|---|---|
| `GET /api/costumes` | 全衣装。持っている・着ている・いま買える(季節の中か)・値段・買える(財布が足りる)か |
| `POST /api/costumes/{key}/buy` | 買う。季節の中で、まだ持っておらず、財布が足りるときだけ。**1つの取引(DB transaction)で、財布を引いて、衣装を渡す**。足りない・季節の外・もう持っている → 422。**1着ずつ**(二重の押しで、2回引かない) |
| `PUT /api/costume` | 着る(`key`)/ ふつうに戻す(`null`)。持っていない衣装は 422 |

- 2b のタネ交換所(町のかざり)と、**同じ画面**に並べる(「かざり」「きせかえ」の2つのタブ)。買う処理は、財布の引き方を1か所にまとめて共通にする(`RunSeeds::spend()`)。

## 6. 画面

- **タネ交換所**(入口: スプルランの入口の「タネ交換所へ」)
  - 上に、財布(タネの数)。タブ: きせかえ / 町のかざり
  - きせかえ: 衣装のカード(絵・名前・値段)。持っている物は「もっている」、季節の外は出さない、財布が足りない物は値段をうすく。買うときは確認(「◯◯を、タネ◯個で買う？」)
- **きせかえの画面**(スプルラン入口・プロフィールから): 持っている衣装を選んで着る。「ふつうのスプル」に戻せる
- 着ている衣装は、ランの入口・結果、町のあいさつ、プロフィールに出る

## 7. テスト

- Pest(`CostumeTest`): 買うと財布が減る・衣装が増える / 足りないと422で財布は減らない / 持っている衣装は買えない(財布は減らない)/ 季節の外は買えない・着られる(買った物)/ 着る・戻す / 持っていない物は着られない / 同時の2回押しで2回引かない / コイン・経験値・ポイントは変わらない
- Vitest: 衣装の並べ方・値段の表示・着ている絵の選び方(衣装があればその絵、なければふつう)
- 確認: スマホ幅で、買う→着る→ランの結果・町に出る
