- 前提: 国旗クイズ（`docs/design/2026-10-05-flag-quiz-design.md`。コース親・自動生成・はめ込み）、称号（`stages.title_reward`・`profile_titles`）、パスポート（`/passport`）、自動ふりがな（`components/app/auto-furigana.tsx`）
- 素材: Ownerが用意した47都道府県のバッジ（`company/spra/mascot/assets/badges/` の8枚のシート。1536×1024、1枚に5〜6個）

## 1. 背景と目的

Ownerの意見: 子どもたちがとても勉強になる。国旗クイズのように、都道府県を、県ごと・地方ごと・全国で答えられるようにし、上級をクリアしたら、その県のバッジがもらえるようにしたい。バッジは47県ぶんがそろっている。

**うまくいった目安**

1. ミニクイズに「都道府県クイズ」が出て、地方 → 県 の順に選べる
2. 県を選ぶと、初級 → 中級 → 上級に進める。上級で全問正解すると、その県のバッジがもらえる
3. バッジは、県のカードに出る（もらった県はカラー、まだの県は白黒で薄く）。もらった数が分かる
4. 県のデータ表に1行（県の事実）を足すだけで、問題が増える（画面を直さない）
5. 地方の県をまとめたクイズ（近畿まるごと）と、全国のクイズ（最難関）で、県を混ぜて遊べる

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 名前 | 「都道府県クイズ」。ミニクイズに自動で出る（ステージ3つ以上） |
| 形 | 大もと「都道府県クイズ」→ 地方 → 県（コース）。北海道だけは県が1つなので、地方の層を作らず、大もとの直下に置く。最後に「全国」 |
| 県のコース | 初級・中級・上級の3級。**各級は1ステージ（10問）で、そのステージがボス**（クリアすると次の級が開く）。ボスは「クリア」で次へ進め、「全問正解」で称号が付く |
| バッジ | 県の**上級のボスを全問正解**したとき。称号「◯◯はかせ」（例: 大阪府はかせ）を付け、その称号に県のバッジの絵を結びつける。初級・中級のボスは称号を付けない（称号の一覧が141個にならないように） |
| 地方まるごと | その地方の県を混ぜたコース（3級）。県が3つ以上の地方だけ。上級の称号は「近畿はかせ」のように文字だけ（バッジの絵は作らない） |
| 全国 | 47県を混ぜた最難関。3級それぞれ、複数のステージ＋ボス。3級とも称号あり（全国みならい・全国めいじん・全国はかせ）。あとの段階で作る |
| 問題のもと | 県のデータ表（`database/data/prefectures.php`）。国旗クイズと同じく、純粋な計算が計画を作り、Seederが書く |
| バッジの置き場 | まず、県のカード（コースの選択）と、クイズの結果。パスポートの「日本のバッジ」（もらった数と一覧）は、最後の段階 |
| 範囲 | 47都道府県。市町村・地図の形・声の読み上げは、今回はしない |

## 3. 全体の形

### 3-1. カテゴリー

```
都道府県クイズ（is_course_group）
 ├ 北海道          コース（初級・中級・上級）
 ├ 東北            is_course_group
 │   ├ 青森県 … 山形県   コース（各3級）
 │   └ 東北まるごと      コース（3級）
 ├ 関東 ・ 中部 ・ 近畿 ・ 中国 ・ 四国 ・ 九州沖縄   同じ形
 └ 全国            コース（3級。各級に複数のステージ＋ボス）
```

- 県のコースの `country_id` は空（鍵の国に当たらない）。地方の層は `is_course_group` が真のカテゴリー（国旗クイズの仕組みをそのまま使う）
- 地方の分け方は、8地方（北海道・東北・関東・中部・近畿・中国・四国・九州沖縄）。三重は近畿、沖縄は九州沖縄、山梨・長野・静岡は中部。データ表の `region` で決める

### 3-2. 仕組みの追加（小さく3つ）

1. **入れ子のコース**: `is_course_group` のカテゴリーの子が、さらに `is_course_group`（地方）になれるようにする。
   - ミニクイズの一覧（`MiniQuizzes`）は、大もとの下の**孫まで**ステージを数える
   - コースの窓口（`Courses::list`）は、子が地方（グループ）のとき、孫のステージの合計を数える。返事に、`group`（そのコースがさらにコースを持つか）・`title`（そのコースの上級のボスの称号）・`earned`（今のプロフィールがその称号を持つか）を足す
   - 画面 `/play/{id}`: 地方のカードを押すと、また県のカード（コースの選択）が開く。県のカードを押すと、今までの級・ステージの画面
2. **FlagQuizWriter を、入れ子のコースを書ける形に広げる**。国旗クイズの動きは変えない（今のテストで守る）。問題の目印 `meta.flag_key` はそのまま使い、都道府県は `pref:` で始める
3. **テキストのはめ込み**: 今のはめ込み（`meta.layout = "slots"`）は、国旗の絵を枠に入れる。県庁所在地の名前を、県名の枠に入れる形にするため、はめ込みの部品が、絵のない項目（文字だけ）も入れられるようにする（`FlagFitQuestion` の拡張）。サーバーの採点は変えない

## 4. 県のデータ表（`database/data/prefectures.php`）

1県＝1行。

| 項目 | 内容 |
|---|---|
| `key` | バッジのファイル名と同じ（例 `osaka`）。`public/badge/pref/{key}.webp` が実在する |
| `name` | 県の名前（例「大阪府」） |
| `region` | 8地方のどれか |
| `capital` | 県庁所在地（例「大阪市」） |
| `neighbors` | となりの県の `key`（互いに、そろっているように、テストで確認） |
| `foods` | 名物・特産（食べ物・くだもの）4つ。簡単なものから |
| `sights` | 名所・自然・建物 4つ。簡単なものから |
| `culture` | お祭り・伝統工芸・歴史・人物 3つ。簡単なものから |
| `hard`（任意） | 難読地名（漢字 → 読みの4択。まちがいの読みも書く）。上級に使う |

- 事実は、**文字**（例「たこやき」「大阪城」）。同じ文字が2つの県にあるもの（例 みかん＝愛媛・和歌山）は、「その県の名物はどれ？」では使えるが、「みかんで有名なのはどの県？」には使わない（正解が2つになるため）。また、ほかの県の問題で、まちがいの選択肢にもしない。この判定は、計画の計算が、表の中の同じ文字の数で自動で行う
- **Ownerの確認が要る内容**: 事実の正しさ、県庁所在地、となりの県、簡単・むずかしいの並び。最初の版は私が書き、公開前にOwnerが目を通す（`TASKS.md` に足す）

## 5. 級ごとの問題

1ステージ＝10問。まちがいの選択肢は、問題ごとに決まった並びで選ぶ（国旗クイズの `crc32` と同じ。同じ表からは同じ計画）。

### 5-1. 県のコース

| 級 | 中身 | まちがいの選択肢 |
|---|---|---|
| 初級 | 名物・名所の4択だけ。「◯◯県の名物は？」（`foods` の先頭2つ）と「◯◯県にあるのは？」（`sights` の先頭2つ）を順に、「◯◯で有名なのは どの県？」（同じ4つの逆）、「◯◯県は どの地方？」1問 | 全国の県から（ぜんぜんちがう県） |
| 中級 | 県庁所在地（県→県庁所在地、県庁所在地→県）、となりの県、名物・名所の3つ目、お祭りなど1つ目。**3問目と8問目は、はめ込み**（県庁所在地を、県の枠に入れる） | 同じ地方の県から |
| 上級 | 県名とちがう県庁所在地の問題（愛媛→松山など。表の県名と県庁所在地の名前が似ていない県で）、名物・名所の4つ目、お祭りなど、となりの県、`hard` があれば難読地名。3問目と8問目は、となりの県どうしのはめ込み | となりの県から（足りなければ同じ地方で足す） |

- どの級でも、その県の事実を中心に出す。出す事実の数が10問に足りない級は、順を変えた逆の形を足す（計画の計算が決める。同じ問いが2回出ない）
- **上級のボスを全問正解 → 称号「◯◯はかせ」**。画面は、称号がバッジに結びついた県なら、バッジを大きく見せる

### 5-2. 地方まるごと

県のコースと同じ3級で、その地方の県をすべて1回ずつ（県が10に満たなければ繰り返し）アンカーにする。1問ごとの形は、初級＝名物・名所から県、中級＝県庁所在地、上級＝となりの県・名前のちがう県庁所在地。まちがいは、その地方の県から（4県のときは足りないぶんを全国で足す）。3問目と8問目ははめ込み。上級のボスの称号は「◯◯はかせ」（バッジなし）。

### 5-3. 全国（あとの段階）

5-2 と同じ形で、アンカーは47県。各級を、均等に分けた複数のステージ（1ステージ7〜10県）＋ボスにする。初級は、知名度の高い県から（データ表に `tier` を足す）。詳細は、その段階の設計で決める。

## 6. バッジの取り込み

- 元のシートを `company/spra/mascot/assets/badges/prefecture/` にまとめて、名前を分かりやすい形に直す（例 `sheet_01.png`〜`sheet_08.png`。県との対応は、道具の表に書く）。国のスタンプ（`badge1`〜`5`）は、今の場所のまま
- 道具 `tools/pref-badges/make_badges.py`（Pillow）: シートごとに、丸いバッジの中心と半径を測り、まわりの光（にじんだ背景）を丸く切り抜いて透明にする。192×192のWebPにして `frontend/public/badge/pref/{key}.webp`。県との対応と測った位置は、道具の表（`crops.json`）に書く
- 合計は、1MB以内を目安にする（47枚）。表示は `next/image` で遅く読む
- 失敗しやすい点: 光のにじみ・リングの外側の色が丸の外に残る（透明にする）、5県のシートの2段目が中央に寄る

## 7. 画面

### 7-1. コースの選択（`CourseSelect`）

- 地方のカード: 地方名と、進み具合（地方の中のクリアしたステージ/全部）
- 県のカード: 県のバッジ（もらった県はカラー、まだは白黒で薄く）、県名、進み具合。北海道も同じ
- 「◯◯まるごと」「全国」のカード: バッジの代わりに、地方・日本の名前だけ。「全国」には、国旗クイズの世界ぜんぶと同じく「ちょうむずかしい」のひと言
- 地方・県の名前は、自動ふりがなで読みを付ける（辞書に県名・県庁所在地・事実の語を足す。長い語から並べる決まりを守る）

### 7-2. 結果

- 上級のボスの全問正解で、「◯◯県のバッジを ゲット！」と、バッジの絵（大きく）。称号の表示は、今のまま
- 全国・地方の称号は、今の称号の表示のまま（バッジなし）

### 7-3. パスポート（最後の段階）

- 「日本のバッジ」（もらった数/47）と、地方ごとの一覧（もらった県はカラー、まだは白黒）。押すと、その県のコースへ
- 既存の窓口 `/api/passport` の `titles` から、称号 → 県 の対応で数える。サーバーの追加は要らない

## 8. 段階

| 段階 | 中身 |
|---|---|
| 1 | 仕組み（入れ子のコース・テキストのはめ込み・称号→バッジ）と、**バッジ47県の取り込み**。データ表は、**近畿7県**（滋賀・京都・大阪・兵庫・奈良・和歌山・三重）。近畿まるごと。ここまでで遊べて、バッジがもらえる |
| 2 | 残りの地方を足す（地方ごとに、データ表を書く → Ownerが確認）。データが増えると、まちがいの選択肢の候補が広がり、近畿の問題の文も、再実行で更新される（進み具合は、ステージ・問題の番号を保つので消えない） |
| 3 | 全国（3級）。知名度 `tier` の追加 |
| 4 | パスポートの「日本のバッジ」 |

## 9. テスト

- **サーバー（Pest）**: 県のデータ表（`key` の重複なし・バッジのファイルが実在・すべての県に地方・となりが互いにそろう・県庁所在地・事実の数が足りる）、計画（どのステージも10問・同じ問いが2回出ない・初級に はめ込み なし・中級・上級の3問目と8問目がはめ込み・正解が1つだけ・同じ文字がほかの県にあるものは逆に出さない・まちがいの数が足りる・上級の選択肢にとなりの県が入る・同じ表から同じ計画）、書き込み（二重実行で増えない・国旗クイズが変わらない）、入れ子のコースの窓口（孫の合計・`group`・`title`・`earned`）、ミニクイズの一覧（孫まで数える）
- **画面（Vitest）**: 称号 → 県のバッジの対応、バッジの出し分け（カラー/白黒）、テキストのはめ込みの入れ方・戻し方・判定
- **ブラウザ**: 引き出しに出る → 地方 → 県 → 級、初級の4択、中級のはめ込み（文字）、上級のボスで全問正解 → バッジの表示、県のカードにバッジがカラーで出る、スマホ幅。確かめたあと、開発用のデータを元に戻す

## 10. やらないこと

- 地図の形の問題（県の形の絵がない。あとから足せる形にしておく）
- 市町村、人口・面積などの数字の問題
- 声の読み上げ
- バッジ以外のごほうびの追加（クリアのコイン・学習ポイントは今のまま）
- パスポートの「日本 → 都道府県」の階層（段階4は一覧の追加まで）
- Owner管理画面での県データの編集（表のファイルを直して再実行）
