# 復習の出し方の優先順位（滞留対策・苦手の語）— 設計書

- 作成日: 2026-10-09
- ステータス: 設計中（方針はOwner合意済み 2026-10-09。案B「枠を分ける」・苦手の語は出す日が来ていなくても出す・「今学んでいる国／言語」の枠は今回は入れない）
- 前提: 問題ごとの覚え具合（`docs/design/2026-09-29-spaced-review-design.md`。段階1〜5・出す日・まちがえた日）、単語帳の「苦手」マーク（`docs/design/2026-10-07-word-book-design.md`。`profile_words.status = weak`）、復習の変化（`docs/design/2026-10-09-review-variety-design.md`）
- きっかけ: Codexの指摘（2026-10-09）の④「復習の滞留対策」と、TASKSの「単語帳の苦手を出題で優先する」。問題が数千件になる前に、出し方を直す

## 1. 目的

出す日が来た問題が溜まっても、**今この子に必要な問題**が復習に出続けるようにする。

1. まちがえたばかりの問題が、古い問題の山に埋もれない
2. 古い問題も、止まらずに少しずつ進む
3. 単語帳で「苦手」にした語が、出題に効く
4. あと1回で「覚えた」になる問題が、早く片づく（山も減る）

**うまくいった目安**

1. 出す日が来た問題が100問溜まっていても、昨日まちがえた問題が今日の復習に入る
2. 苦手にした語の問題が、出す日が来ていなくても、3日あけて復習に入る
3. 出す日が来た問題が十分にあるとき、毎日の復習の中に「いちばん遅れている問題」が必ず3問以上入る（古い問題が止まらない）
4. 出す日が来た問題が少ないときは、今までと同じ動きになる

## 2. 今の問題点

出す日が来た問題を `QuestionMemory::dueIds` が「出す日が古い順」だけで並べ、毎日の復習が10問、ステージのおさらいが2問を取る。

1. **新しいまちがいが後回しになる。** まちがえた問題は次の日に出す日が来るが、古い順なので、前から溜まった山の後ろに並ぶ。山が1日の枠より大きいと、順番が来ない
2. **段階を見ていない。** あと1回で覚える段階5の問題と、さっきまちがえた段階1の問題が、同じ扱い
3. **単語帳の「苦手」が出題に効いていない**

## 3. 決定事項

| 項目 | 決定 |
|---|---|
| 方式 | 種類ごとの**枠**に分ける。足りない枠は「いちばん遅れている問題」で埋める |
| 毎日の復習（10問） | 最近まちがえた 3／苦手の語 2／あと1回で覚える 2／いちばん遅れている 残り（3以上） |
| ステージのおさらい（2問） | 1問目 = 「最近まちがえた → 苦手の語 → あと1回」の順で最初に見つかったもの。2問目 = いちばん遅れている問題。どちらも、そのステージの国を先に |
| 最近まちがえた | 最後の答えがまちがいで、まちがえた日が7日以内。出す日が来ているもの。新しい順 |
| 苦手の語 | 単語帳で「苦手」にした語の問題。**出す日が来ていなくても**、最後に答えてから3日以上あいていれば出す。覚えた問題も含める。古い順（最後に答えた日） |
| あと1回で覚える | 段階5で、出す日が来ているもの。出す日が古い順 |
| いちばん遅れている | 出す日が来ている問題すべて（上の枠で選んだものを除く）。出す日が古い順（今までと同じ並び） |
| 使われなかった枠 | 「いちばん遅れている問題」に回す（ほかの枠には回さない） |
| 同じ問題 | 1回の中で、同じ問題を2回出さない |
| 出さない問題 | 今までどおり: 国旗キャッチ専用の問題・鍵の国の問題・消された問題 |
| 今学んでいる国／言語の枠 | 今回は入れない（ステージには国の優先が既にある。毎日の復習は広く出す） |

### 苦手の語を出す日より前に出すとき

- 出す日より前の正解は、今のルールどおり、段階を進めない（覚え具合は変わらない。追加の練習になる）
- まちがえたときは、今のルールどおり、段階1・次の日に戻る
- 「覚えた」になっていた問題をまちがえたときも、今のルールどおり、覚えたでなくなる。苦手にしたのは「忘れた」の合図なので、それでよい

## 4. 設計

### 4-1. 設定（`config/review.php`）

```php
'priority' => [
    // 毎日の復習の枠(残りは「いちばん遅れている問題」)
    'daily' => ['recent_wrong' => 3, 'weak' => 2, 'almost' => 2],
    // ステージのおさらいの先頭の1問が探す順
    'stage' => ['recent_wrong', 'weak', 'almost'],
    'recent_wrong_days' => 7,   // まちがえてから何日までを「最近」とするか
    'weak_gap_days' => 3,       // 苦手の語を、最後に答えてから何日あけて出すか
],
```

`daily_size`（10）と `stage_mix`（2）は今のまま。

### 4-2. 選び方（`app/Support/ReviewPicker.php`・新しく作る）

`QuestionMemory` の細かい検索を使い、枠ごとに問題を選ぶ。`QuestionMemory::dueIds`（いちばん遅れている問題。今の検索）は変えない。

```
ReviewPicker::daily(profile, limit = daily_size): list<int>
  1. recent_wrong 枠・weak 枠・almost 枠を、この順で上限まで選ぶ(それまでに選んだ問題は除く)
  2. 残りの数を、dueIds(いちばん遅れている問題)で埋める(それまでに選んだ問題は除く)
  3. limit が枠の合計より小さいときは、枠の順に切り詰める

ReviewPicker::stage(profile, excludeIds, countryId): list<int>
  1. config('review.priority.stage') の順に探し、最初の枠から1問(国を先に)
  2. dueIds(1問、国を先に、1で選んだ問題を除く)
```

枠ごとの検索（どれも「覚えた問題でない」「鍵の国でない」「catch_only でない」。苦手の語は覚えた問題も含む）:

| 枠 | 条件 | 並び |
|---|---|---|
| recent_wrong | `due_on <= 今日` かつ `wrong_on >= 今日 − 7日` | `wrong_on` が新しい順 |
| weak | 語（`questions.meta.word_id`）が `profile_words.status = weak`、かつ（`due_on <= 今日` または `last_answered_on <= 今日 − 3日`） | `last_answered_on` が古い順 |
| almost | `level >= 5` かつ `due_on <= 今日` | `due_on` が古い順 |

- 国の優先（ステージ用）は、各枠の並びの先頭に「その国の問題を先に」を足す
- 苦手の語の条件は、`profile_words` を `questions.meta->word_id` で結ぶ（サブクエリ）

### 4-3. 呼び出し側の変更

| 場所 | 変更 |
|---|---|
| `Review::questionIds`（毎日の復習・状態の件数） | `QuestionMemory::dueIds` → `ReviewPicker::daily` |
| `routes/api.php` ステージのおさらい（1252行付近） | `QuestionMemory::dueIds(..., stage_mix, ...)` → `ReviewPicker::stage` |
| スプルキャッチ（`CatchGame`） | 変えない（キャッチの中は、今でも「まちがえた問題 → 出す日が来た問題」の順） |
| 国旗キャッチ専用の問題 | 今までどおり出さない |

### 4-4. 画面

画面は変えない。復習の件数（「N問」）は、苦手の語が足されるので、出す日が来た問題がなくても「復習できる」になることがある。それでよい（苦手にした語を練習できる）。

## 5. テスト

サーバー（Pest。`tests/Feature/ReviewPickerTest.php` を新しく作る）:

- 出す日が来た古い問題が20問あっても、昨日まちがえた問題が、毎日の復習に入る（最大3問）
- 8日前にまちがえた問題は「最近まちがえた」に入らない（古い順の枠で出る）
- 苦手の語の問題が、出す日が来ていなくても、最後に答えてから3日あいていれば入る。2日では入らない
- 苦手の語の問題は、覚えた問題でも入る
- 苦手でない語の、出す日が来ていない問題は入らない
- 段階5で出す日が来た問題が、最大2問入る。段階4は入らない
- 古い順の枠が、必ず残りを取る（recent_wrong が3・weak が2・almost が2の人でも、いちばん遅れている問題が3問入る）
- 使われなかった枠は、いちばん遅れている問題で埋まる。出す日が来た問題が少ないときは、今までと同じ並び
- 同じ問題が2回入らない（1つの問題が複数の枠に当てはまる場合）
- 鍵の国・国旗キャッチ専用の問題・消された問題が入らない
- ステージ用: 先頭の1問は「最近まちがえた」が優先され、その国の問題が先。2問目はいちばん遅れている問題。ステージの問題は除かれる
- 出す日より前の苦手の語に正解しても、段階が変わらない。まちがえると段階1・次の日になる（`QuestionMemoryTest` の既存の動きを確認）
- 既存のテスト（`ReviewTest`・`StageReviewTest`・`QuestionMemoryTest`）は、新しい並びに合わせて直す

確認（開発用DB）:

- 検証用のプロフィールに、出す日が来た問題を30問・昨日まちがえた問題を3問・苦手の語を2つ作り、`GET /api/review` の問題に、まちがえた問題と苦手の語が入ることを確かめる（確認後に元へ戻す）

## 6. やらないこと

- 回答時間・連続ミスを使った出し分け（TASKSの③。公開後でよい）
- 「今学んでいる国／言語」の枠
- 同じ語の2つの向き（英→日・日→英）を、1回の復習で2問出さないようにする仕組み
- 画面に「苦手の語です」などの札を付けること
- 点数による並べ替え（案A）
