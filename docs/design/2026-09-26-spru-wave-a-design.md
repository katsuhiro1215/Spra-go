- 前提: `docs/design/2026-09-26-world-town-design.md`（ワールド画面＋ポイントで買って置く、実装済み）

## 1. 背景と目的

ワールド画面の実装でゲーム性が増した。Ownerから、マスコット「スプル」と仲間たちの素材（`company/mascot/assets/mascot-2〜6.png`、背景透明）が用意され、次の構想が出た。

- 仲間（色違い・形違いのキャラクター）をゲームの中で手に入れ、自分の相棒にしていく
- スプルが成長して花を咲かせ、種をまき、また新しい芽が出る（スプルの形は変えず、Sの先に花が咲くだけ）

CEO案と合わせて洗い出し、Ownerの判断で次の5回（A〜E）に分けて作る。1回ごとに設計書 → 実装計画 → 開発 → ブラウザ確認 → マージの順で進める。本書はA回の設計書である。

| 回 | 作るもの |
|---|---|
| **A（本書）** | スプルの表情・ポーズの出し分け、シーン演出（レベルアップ・ステージ開始）、時間帯と季節 |
| B | 成長サイクル（芽→つぼみ→花→種）、毎日の水やり、種から仲間が生まれる |
| C | 相棒えらび（名前つき）、仲間ごとの成長、仲間からの復習問題 |
| D | 今日のおつかい、町のにぎやか度、家族の町を見に行く |
| E | 土地の解放と旅（ワールド画面の設計書でいう②）、国ごとのおみやげ |

- 後回し: 着せ替え（国ごとの帽子）、図鑑
- 入れないもの: コインで回す「ランダムに仲間が出るガチャ」（子ども向けに課金とくじを組み合わせると景品表示法等の懸念があるため。仲間は学んで育てることでしか増えない）
- 仲間は mascot-4・mascot-6 に共通する5人（Lumi・Momo・Kuru・Piko・Ruru）を正式とする想定。B回の設計で確定する

## 2. 決定事項（Owner確認済み）

| 論点 | 決定 |
|---|---|
| スプルを出す画面 | **町の画面とクイズ画面**。ショップ・バッグ・学ぶ画面の案内役は後の回 |
| 時間帯 | **実際の時刻で朝・昼・夕方・夜の4つ**。夜は明かりがともる。22〜6時はスプルが寝ている（タップで起きる。遊ぶことは止めない） |
| 演出 | **レベルアップは全画面でお祝い**（新しく買えるアイテムも見せる）。**ステージ開始は小さなカードで2秒、自動で消える** |
| 画像の持ち方 | 素材集から1体ずつ切り抜いたWebP画像にし、名前つきの一覧で管理する。3Dモデル（Spru Master）ができたら同じ名前で差し替える |
| テスト | フロントエンドに Vitest を入れ、時刻・季節・表情の決め方（画面から切り離した計算）を自動テストする |

- 今の仮画像（`public/spru/idle.png`・`joy.png`・`front.png`）は新しい画像に置き換え、削除する

### 4-2. 切り抜きの仕組み
- `tools/spru-assets/crops.json` に「どの素材集の、どの範囲を、どの名前で切り抜くか」を並べる
- `tools/spru-assets/extract.py`（Python + Pillow）がそれを読んで切り抜く。半透明の区切り枠や名前の文字は、透明度のしきい値で取り除く。背景つきのシーン画像は四角く切り抜く
- 素材集はリポジトリの外（`company/mascot/assets/`）にあるため、スクリプトは素材集の場所を引数で受け取る。切り抜いた画像はリポジトリに含める
- 画面側は `components/spru/spru-assets.ts` の一覧（キー → 画像の場所・縦横比・足もとの位置）だけを見る。差し替えのときはこの一覧と画像だけを直す

## 5. スプルの出し分けルール

### 5-1. 町の画面

| 場面 | スプル | 吹き出し |
|---|---|---|
| 町を開いたとき | `wave`（2.5秒）→ `three-quarter`（ゆらゆら） | 朝「おはよう！今日もいっしょに学ぼう」、昼「こんにちは！今日もいっしょに学ぼう」、夕方「おかえり！もうひとがんばりしよう」、夜（22時前）「こんばんは！寝る前にちょっとだけ学ぼう」 |
| 置く場所を選んでいる間 | `three-quarter`、顔アイコン `excited` | 「どこに置く？光っているマスをタップしてね」 |
| アイテムを置いた | `jump`（2.6秒） | 「〇〇を置いたよ！町がにぎやかになったね」 |
| バッグにしまった | `palms`（2.6秒） | 「〇〇をバッグにしまったよ」 |
| 通信エラー | `sad`（2.6秒） | 「うまくいかなかった…もう一度ためしてね」 |
| 初回プレゼントを受け取った | `jump`（2.6秒） | 「ポイントでショップのアイテムを買ってみよう！」 |
| スプルをタップ | `shy`・`laugh`・`cheer` からランダム（2.6秒） | 状況に合ったひとこと（5-2） |
| 30秒さわらない | `sit` | 「ひと休み…」 |
| 90秒さわらない | `sleep` | 「すやすや…」 |
| 寝ているときにタップ | `startled`（1.5秒）→ ふだんに戻る | 昼「わっ、びっくりした！」、夜「ふぁ…まだ起きてたの？」 |
| 夜（22〜6時） | 最初から `sleep` | 「すやすや…」。タップで起きて、1分さわらないとまた寝る |

- 優先順位: 今起きたできごと（置いた等） → 夜の眠り → さわらない時間 → ふだん
- 「さわる」とは、町の画面でのタップ・クリック・キー操作。さわると、さわらない時間は0に戻る
- 起こし方: 昼にさわらなくて座った・寝たときは、画面のどこをさわっても起きる（寝ていた場合は `startled` を挟む）。夜（22〜6時）の眠りは、スプルをタップしたときだけ起きる（ほかの操作では寝たまま）
- 吹き出しの左側に、そのときの表情の顔アイコンを出す（アクションのときは、そのアクションに合う顔: `wave`・`jump`・`cheer` は `happy`、`palms`・`sit` は `smile`、`sleep` は `normal`、`startled` は `surprised`）
- スプルは本物の `<button>`（読み上げ名「スプル」）にする。置く場所を選んでいる間は押せない

### 5-2. スプルをタップしたときのひとこと
上から順に、最初に当てはまるものを出す。

1. バッグにアイテムがある → 「バッグに〇〇があるよ。町に置いてみよう」
2. 今のポイントで買える、解放済みの町のアイテムがある → 「〇〇が買えるよ！ショップをのぞいてみよう」
3. 解放済みで、いちばん安いアイテムにポイントが足りない → 「あと〇ptで〇〇が買えるよ」
4. まだ解放されていないアイテムがある → 「Lv.〇で〇〇が買えるようになるよ」
5. それ以外 → 「つづきから学ぼう！」

### 5-3. クイズ画面

| 場面 | スプル |
|---|---|
| 正解 | `happy`。コンボ2以上は `laugh`、5コンボごとのボーナスのときは `cheer` |
| 不正解 | `sad`（`cry` は使わない。子どもが悲しくなりすぎないように） |
| HPが0で止まったとき | `sleep`、「スプルもひと休み。HPが回復したらまた遊ぼう」 |
| 結果画面 | 全問正解は `jump`、半分以上は `smile`、それ未満は `effort`（「次はもっとできるよ！」） |

- 正解・不正解の全画面表示では、「Correct!!」「Wrong...」の上に100px前後で出す

## 6. 演出

### 6-1. レベルアップ
- 回答APIの `profile.leveled_up` が true のとき、正解画面で「次へ」を押した後に全画面で出す。最後の問題でレベルが上がったときは、結果画面の前に出す
- 中身: シーン `grow` のカード、「レベルアップ！ Lv.〇」、「HPが全回復したよ」、新しく買えるようになった町のアイテム（絵と「〇〇が買えるようになったよ」）、「町に戻ったらショップをのぞいてみよう」、「つづける」ボタン
- 新しく買えるアイテム: クイズ開始時に `GET /api/shop` で読み込んだ一覧から、町のアイテムのうち「前のレベル < 必要レベル ≦ 新しいレベル」のもの。無ければその行は出さない
- 効果音: 既存の「全問正解」の音

### 6-2. ステージ開始
- 1問目を表示したとき、画面上部にシーン `challenge` と「Stage 〇 スタート！」の小さなカードを出し、2秒で消す
- カードは押せない（タップを邪魔しない）。動きを減らす設定のときは、動かさずに出して消す

## 7. 時間帯と季節

### 7-1. 時間帯（端末の時計）

| 時間帯 | 時刻 | 町の見た目 |
|---|---|---|
| 朝 | 5:00〜9:59 | 淡い空色、やわらかい光 |
| 昼 | 10:00〜15:59 | 今の配色 |
| 夕方 | 16:00〜18:59 | オレンジがかった空と地面 |
| 夜 | 19:00〜4:59 | 紺色の空と星。Spruの家の窓・灯籠・ちょうちんに明かりがともる |

- スプルが寝る時間は22:00〜5:59（夜の19〜22時は起きている）
- 画面を開いたまま時間帯が変わったときのため、1分ごとに確かめて切り替える

### 7-2. 季節（端末の日付の月）

| 季節 | 月 | 町に舞うもの |
|---|---|---|
| 春 | 3〜5月 | 桜の花びら |
| 夏 | 6〜8月 | きらきらした日差し |
| 秋 | 9〜11月 | 落ち葉 |
| 冬 | 12〜2月 | 雪 |

- 舞うものは十数個のSVGの小さな図形で、CSSで動かす。動きを減らす設定のときは出さない

### 9-3. ブラウザ確認（Playwright、スマホ幅390pxとPC幅）
