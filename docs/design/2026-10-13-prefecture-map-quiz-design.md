# 都道府県クイズの「地図の問題」— 設計書

- 作成日: 2026-10-13
- ステータス: 方針はOwner承認済み（地図データから描く。画像は生成しない）。この設計に沿って実装する
- 前提: `docs/design/2026-10-05-prefecture-quiz-design.md`（県のデータ表・問題の自動生成）、`docs/design/2026-10-06-prefecture-quiz-national-design.md`

## 1. 目的

「この色がついた県の県庁所在地は？」のように、**地図を使った問題**を、都道府県クイズに足す。地図は画像ではなく、**県の形のデータ**から、画面で描く。

- 形が正確（クイズの答えになるため）。
- 色を自由に塗れる。1つのデータで、問題を何通りも作れる。
- 画像の生成・枚数管理が要らない。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 地図データ | Natural Earth の 1:10m 行政区画（admin-1）。パブリックドメインで、出典の明記も不要（[利用条件](https://www.naturalearthdata.com/about/terms-of-use/)）。47都道府県がそろっていることを確認済み（12,669点・約450KB） |
| 採用しないデータ | 国土数値情報（出典・加工の明記・再配布の確認が要る）、地球地図日本の加工版（営利目的は利用報告が要る）。公開前に条件を調べる手間を避ける |
| 地図の描き方 | SVG。簡略化して、県ごとのパス（約60〜80KB）にしたものを、画面のデータとして持つ。沖縄は、九州の左下に小さな枠で寄せる（よくある日本地図の形） |
| 問題の形 | 今の4択のまま。地図は、問題文の上の絵として出す。答えの選択肢は、これまでどおり文字 |
| 問題の指定 | `questions.meta.map = { "highlight": "<県のkey>", "view": "<地方のkey>|japan" }`。マイグレーション不要（`meta` は既にあるJSON列） |
| 色 | 対象の県は濃い色（黄色）で塗り、太めの縁。ほかの県は、うすい色。色だけに頼らない（縁と、ゆっくり点滅する光の輪）。県名は、答えがわかるので、地図に書かない |
| 拡大の範囲 | 県の小ささに合わせ、**地方のまとまりで切り取って**表示する（`view`）。香川県を全国の地図で見せない |

## 3. 問題の種類（第1段階。4択）

| 種類 | 問題文 | 正解 | まちがい | 使う場所 |
|---|---|---|---|---|
| `map region` | 「ちずで いろが ついた けんは どの ちほう？」 | 地方名 | ほかの地方 | 県のコース・初級 |
| `map neighbor` | 「ちずで いろが ついた けんと となりあうのは どれ？」 | となりの県 | となりでない県 | 県のコース・初級／中級／上級 |
| `map capital` | 「ちずで いろが ついた けんの けんちょうしょざいちは どこ？」 | 県庁所在地 | 同じ地方などの県庁所在地 | 県のコース・中級／上級 |
| `map name`（作ってある・まだ使わない） | 「ちずで いろが ついた けんは どこ？」 | 県名 | 県名 | **地方まるごと・全国で使う予定** |

- すべて、県のデータ表（`prefectures.php`）の項目（名前・地方・県庁所在地・となり）だけから作れる。**新しい事実は要らない**ので、確認済みの事実の表がそのまま使える。
- 北海道は、となりの県がない（データ表で `neighbors` が空）ので、「となり」の地図の問題は作れず、別の問題に替わる（10問は保たれる）。
- **`map name` を県のコースに入れない理由**: 県のコースの画面の上には、「香川県 ・ Stage 1」と県名が出る。色がついた県の名前を聞くと、答えが見えてしまう。県名を出さない地方まるごと・全国のコースで使う。

### 3-1. 級ごとの並びへの入れ方（10問のうち、差し替えるもの）

今の10問の並びは変えず、一部を地図の問題に差し替える。1ステージあたり2問。はめ込み（`fit`）と `capital_differs` は残す。

- 初級: 2問目 `rev foods 1` → `map region`、9問目 `region` → `map neighbor`
- 中級: 1問目 `capital` → `map capital`、4問目 `neighbor` → `map neighbor`
- 上級: 4問目 `neighbor` → `map neighbor`、10問目 `rev culture 2` → `map capital`
- 地方まるごと・全国のコースは、今回は地図を出さない（今の形のまま）。県のコースだけ。

## 4. 地図データの作り方

- `tools/prefecture-map/build_map.py`（Python・標準ライブラリ＋Pillow不要）。入力: Natural Earth の GeoJSON。出力: `frontend/src/components/prefecture-map/japan-map.ts`（県ごとのSVGパス・全体と地方ごとの `viewBox`）。
- 投影: 緯度の補正をかけた平面（x = (経度−137)×cos(37.5°)、y = −緯度）。
- 沖縄は、九州の左下へ移動して、枠線で囲む。小笠原などの遠い島は、東京都のコースでは省く（面積が極小のため、描く価値がない）。
- 簡略化: ダグラス・ポイカー（許容 0.01度）＋小さな島（面積しきい値以下）を省く。ただし、**県の形がわかる**ことを確認する（目視と、頂点数の上限テスト）。
- 県のkey: `iso_3166_2`（JP-01〜JP-47）の番号と、データ表の並び（北から南＝都道府県コード順）で対応づけ、県名（`name_ja`）が一致することをテストで確かめる。

## 5. 画面

- `PrefectureMap`（`frontend/src/components/prefecture-map/prefecture-map.tsx`）: `highlight` と `view` を受け取り、SVGを描く。縦横比は `view` で決まる。
- クイズの画面（`quiz-session.tsx`）は、`question.meta.map` があれば、`meta.image` の代わりに、地図を出す。
- 色: 対象の県＝黄（`#f2b632`、縁 `#d99a12`）、ほかの県＝うすい緑（`#d6e8c6`、縁 白）、海＝うすい青。夜モードなどの暗い背景には出ない（クイズの画面は明るい）。
- アクセシビリティ: `role="img"`、`aria-label`＝「日本地図。色がついた県を答えてね」（県名は読み上げない）。

## 6. テスト

- 地図データ: 47県そろう／keyがデータ表と一致／頂点数が上限以下／各県に面積がある。
- 問題の計画: 各県のコース・各級に、地図の問題が指定数ある／`highlight` が実在の県の key／`map neighbor` は北海道に出ない／正解が事実の表と一致／まちがいが正解と重ならない。
- 画面の部品: `viewBox` の計算（地方→枠）／対象の県だけが塗られる。

## 7. 第2段階以降（今回は作らない）

- 「この県を タップしよう」（地図上の県を直接選ぶ）。新しい操作なので、別の設計にする。
- 地方まるごと・全国のコースで `map name` を使う（県名が画面に出ないので、答えが見えない）。
- 地名クイズ（市区町村）の地図: 市区町村の形のデータは重いので、位置の点だけで示す案を、別に検討する。
- 世界の国の地図問題（国別の形）。同じ作り方（Natural Earth の国境データ）で足せる。
