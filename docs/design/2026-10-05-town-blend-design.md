## 1. 背景と目的

今の町の地面は、緑の2色を交互に塗った菱形のマス（市松）で、マスが丸見えになっている。町の見た目を、置いたアイテムとなじむ、絵のある地面に変える。

1. 地面（区画ごとの草・竹林・砂・丘）と道を、絵で描く。市松のマスはなくす（道とアイテムを置く位置は今のまま）
2. 木や花を並べると、その足元が林・花畑の地面に変わる（隣り合うと見た目が変わるだけ。道や川を引く・つなぐ仕組みは入れない。Spra-worldの役目）
3. （案）旅した国の道のデザインを、町の道に使える

**うまくいった目安**

1. 町を開いたとき、市松のマスが見えず、草・砂・道の絵が見える。建物とアイテムの方が、地面より目立つ
2. 木を3本、近くに置くと、足元が林の地面に変わり、にぎやか度が少し上がる。花3つでも同じ（花畑）
3. 置く・動かす・戻すと、その場で地面も更新される
4. 置ける空きマスは、今までどおり光ってわかる（地面の絵にはマスの線を入れない）
5. 朝・昼・夕・夜と季節の色づけは、今までどおり地面にも効く

## 2. 決定事項

| 項目 | 内容 |
|---|---|
| 道・マス | 道の位置、地図の形、置くマスは今のまま。変えるのは見た目だけ |
| 地面の絵 | 真上から見た平らな絵（1024px。町では512pxのWebP）を、ゲームが斜めの菱形に変形して貼る（Owner用の依頼書に記載済み）。マスごとに塗らず、区画ごとに1つの絵として、つなぎ目なく貼る |
| なじみ | 木（しぜんのうち木の6種）3本以上、花（花の4種）3つ以上が、8方向のつながりでまとまると、その足元を林・花畑の地面にする。1つのまとまりで、にぎやか度 +4（2つ目から+1ではなく、まとまり1つごとに+4、最大3つまで） |
| 小物 | 草・小花・小石・落ち葉などを、マスごとに決まった位置にばらまく（毎回同じ） |

## 3. 地面の描き方

### 3-1. 菱形に貼る

町は、SVGで菱形1マス（幅64・高さ32）を並べて描いている（`components/world/world-scene.tsx`、`iso.ts`）。地面の絵は、SVGの `<pattern>` に入れ、次の変形で斜めにする。

- 絵（`T`px の正方形）は、**4×4マスをおおう**大きさにする
- `patternTransform="matrix(a b c d 0 0)"` の値は `a = 128/T`、`b = 64/T`、`c = −128/T`、`d = 64/T`（`T = 512` なら `matrix(0.25 0.125 -0.25 0.125 0 0)`）。絵の横の端が、菱形の右下方向に、縦の端が左下方向に対応する
- 絵は4マスごとに繰り返す。つなぎ目は、素材の加工（3-4）で消す

### 3-2. 区画ごとに塗る

- 今は、マス1つずつを `<polygon>` で塗っている（市松の2色）。これを、**区画（`config/world.php` の `land.plots`）ごとに、1つの大きな菱形**に、その区画の地面の絵で塗る。マスごとに塗ると、境目に細い線が出るため
- 道のマス（`land.paths`）は、道の絵で塗った菱形を、地面の上に重ねる。道の端は、草地との境をやわらかくするため、道の絵の外側に、少し濃い色のふちを、半透明で重ねる（絵を足さずに、色だけで）
- 側面（土のふち）、海、季節・夜の色づけは、今のまま

### 3-3. 小物をばらまく

- 区画ごとに、小物（草のかたまり・小花・小石・落ち葉・クローバー）を、**マスの座標から決まる位置**に置く（`crc32` のような、同じ入力から同じ結果になる並び。リロードしても同じ）
- 1マスに最大1つ、地面の約15%のマスに置く。道のマス・アイテムが立つマスには置かない（絵が重ならないよう、アイテムのマスと2×2の全マスを除く）
- 絵は小さく（1マスの幅の3割ほど）、地面の上に描く。アイテムを置く・動かすと、除くマスが変わるため、小物も追随する

### 3-4. 素材の加工（`tools/ground-assets/`）

- 原画（`company/spra/spra-world/assets/approved/ground/`）を読み、**上下左右のつなぎ目を消し**（半分ずらした絵と、中央を残す形でなじませる）、512pxのWebPにして `frontend/public/spru/ground/{キー}.webp` に出す
- 小物のシートは、輪郭ごとに切り出して、1枚ずつのWebPにする
- 画面側の一覧（`components/world/ground-art.ts`）は、手で書く（枚数が少ないため）。素材が増えたら行を足す

## 4. なじみ（林・花畑）

### 4-1. 決め方（純粋な関数）

- `components/world/blend.ts`: 置いた町のアイテム（`WorldItem` の `asset_key`・`x`・`y`・`footprint`）から、**まとまり**を求める
  - 木: `tree`・`sakura`・`momiji`・`pine`・`young_tree`・`broadleaf_tree`・`large_tree`（`palm`・`bamboo` は今回は入れない）
  - 花: `flowerbed`・`tulip`・`sunflower`・`pathside_flowers`
  - つながり: アイテムが使うマス（2×2は4マス）どうしが、**8方向（斜めも）で隣り合う**ものを、1つのまとまりにする
  - まとまりのアイテム数が3以上なら、林（木のまとまり）・花畑（花のまとまり）になる
- 地面を変えるマス: まとまりのアイテムが使うマスと、その**周囲1マス**（ただし道のマス・地図の外・ほかのアイテムが立つマスを除く）
- 返す形: `{ kind: "grove" | "meadow"; cells: Tile[]; itemIds: number[] }[]`

### 4-2. 描き方

- 変わるマスを、林・花畑の絵で塗り、**ふちをぼかして**（SVGの `feGaussianBlur` のマスク）、元の地面となじませる。マスの形が見えないよう、変わるマスをまとめて1つの形としてぼかす
- 変わるのは地面の絵だけ。アイテムの絵・影・光は今のまま

### 4-3. にぎやか度

- まとまり1つごとに、にぎやか度 **+4**（最大3つ＝+12まで）。`livelinessScore` に、まとまりの数を渡して足す（`components/world/liveliness.ts`）。数の決め方は純粋な関数なので、テストで確かめる
- 画面の「まだ」の文（`LIVELINESS_HINTS`）に、「木や花を、3つ近くに並べると、地面が変わるよ」を足す

## 5. 国の道（案。Owner判断待ち）

ChatGPTとの相談で、国ごとに道の見た目を変える案が出た（一覧は `company/spra/spra-world/docs/road-styles-by-country.md` に保存）。Spra-goには、**旅した国の道のデザインを、町の道に使える**形で入れる案。

- 道の位置・マスは変えない。変わるのは、道の絵だけ
- 使える道: 日本（初めから。今の土の道）＋旅で着いた国。Spra-goの旅の5か国（インドネシア・韓国・アメリカ・イギリス・フランス）で、**道の絵は全部で6種**
  - 日本: 土と砂利、あたたかい茶色（今の道。苔と自然石の石畳の版も候補）
  - インドネシア: 赤茶の土道・煉瓦
  - 韓国: 大きめの灰色の自然石を敷いた路地
  - アメリカ: 舗装道路（アスファルトの暗い灰色。道の中央に黄色の破線）か、開拓時代の茶色い土の道
  - イギリス: 灰色〜濃い灰色の小さな石畳（コブルストーン）
  - フランス: ベージュ〜灰色の不規則な石畳
- 切り替えの場所・操作は、段階2の設計で決める（案: 旅のハブの「着いた国」カードや、町の画面に、「道のもよう」を選ぶ小さな入口）。選んだ道は、プロフィールに保存する（`user_profiles.road_style`、なければ日本）
- 家族の町（ほかの家族の町を見る機能）でも、持ち主の選んだ道で見える（`road_style` を窓口の返事に含める）
- Spra-worldでは、国ごとの町の道（16か国の一覧）に使える。Spra-goの6種は、その先頭の6つ

**判断してほしいこと:** この案を段階2として進めますか。進める場合は、6種の道の絵（真上から見た平らな、つなぎ目なしの正方形。地面と同じ決まり）を、あとで依頼書にします。

## 7. テスト

- **画面（Vitest、純粋な関数）**: まとまりの求め方（隣り合わない・斜めでつながる・2×2が1つのまとまりに数える・2つしかないとき・混ざった木と花は別々）、変わるマス（周囲1マス、道・アイテムのマスを除く）、にぎやか度の加算（まとまり1つ+4、最大3つ）、小物の位置が毎回同じ・道とアイテムのマスに出ない、変形の行列の値
- **ブラウザ**: 市松が見えない・道が読める・木3本で林に変わる・1本動かすと元に戻る・夜と季節の色が地面にも効く・スマホ幅・置ける空きマスが光る。確かめたあと、開発用のデータを元に戻す
- 絵のファイルがないとき、今の市松で描かれる（`ground-art.ts` に絵がないキーを入れたテスト）

## 8. やらないこと

- 道・川を自由に引く、つなぐ（Spra-worldの役目）。道の位置を増やす
- 小川・泉をつなげて川にする（曲がり・T字の絵ができてから、別の依頼）
- 区画ごとに複数の地面の種類・斜面・段差
- 地面の絵の季節ごとの差し替え（色づけは今のまま）
- 林・花畑の人気の統計、音
