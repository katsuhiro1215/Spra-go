# 復習: 今学んでいる所の枠 — 設計書

- 作成日: 2026-10-09
- ステータス: 実装済み（2026-10-09）（方針はOwner合意済み 2026-10-09: 直近7日でいちばん多く答えた所）
- 前提: `docs/design/2026-10-09-review-priority-design.md`（優先の枠。6章で見送った「今学んでいる国／言語」の枠）

## 1. 目的
いま取り組んでいる国・コースの復習が、毎日の復習に必ず入るようにする（遊んでいる内容と復習がつながる）。

## 2. 決定事項
| 項目 | 決定 |
|---|---|
| 「所」 | 問題に国があれば**国**、なければ**ステージのカテゴリ**（子なら親）。どちらもない問題は所なし |
| 今学んでいる所 | 直近7日（今日を含む）に答えた問題（`last_answered_on`）を所ごとに数え、最も多い所。同数なら、最後に答えた日が新しいほう。答えた記録がなければ、枠なし |
| 新しい枠 `now` | 出す日が来た問題で、所が今学んでいる所のもの。出す日が古い順。毎日の復習で**2問** |
| 毎日の復習 | 最近まちがえた3／苦手の語2／あと1回2／今学んでいる所2／残りは古い順（1問以上） |
| ステージのおさらい | 変えない（国の優先が既にある） |

## 3. 設計
- `config/review.php`: `priority.daily` に `'now' => 2`、`priority.window_days` = 7
- `QuestionMemory::hotArea(profile): ?string`（所の鍵 `c{国id}` / `k{カテゴリid}`）、`slotIds` に `now`
- 所の式（SQL）: `COALESCE(CONCAT('c', questions.country_id), CONCAT('k', (最初のステージのカテゴリの親 または 自身)))`

## 4. テスト
- 直近7日で多く答えた国の、出す日が来た問題が `now` で出る（古い順）。別の国は出ない
- 8日前より古い答えは数えない／同数は新しいほう／記録がなければ空
- 国のない問題はステージのカテゴリで数える（親カテゴリにまとめる）
- 毎日の復習: `now` が2問入り、残りの古い順が1問以上残る
