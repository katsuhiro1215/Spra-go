# 効果音の配置

`components/app/sound-provider.tsx` が参照するファイル名(固定):

- `correct.mp3` — 正解時（「ピンポン！」）
- `incorrect.mp3` — 不正解時（「ブブー！」）

このディレクトリに上記2ファイルを置くだけで、クイズ画面(`quiz/[stageId]`)と体験クイズ(`world/[code]`)の両方で自動的に鳴るようになる。片方だけ置いても、もう片方は再生に失敗するだけで画面側はエラーにならない。

フリー素材を使う場合は、商用利用可・改変可・クレジット表記不要（またはクレジット表記対応可能）なライセンスのものを選ぶこと。
