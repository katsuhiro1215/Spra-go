## 1. 背景と目的

幼児は国旗が好き。国旗クイズに続いて、国旗が流れてくるゲームを、スプルキャッチと同じ遊び方で作る。ミニゲームの一覧に、別の1行として並べる（英単語と国旗は別のゲーム。Owner決定）。

**うまくいった目安**

1. ミニゲームの一覧に「スプルキャッチ（こっき）」が出て、最初から遊べる（アメリカ・イギリスに着かなくてよい）
2. 上に「『日本』の国旗は？」と出て、国旗の絵が2〜4つ流れてくる。正しい国旗を、種を投げるか、スプルを動かして受け取る
3. 英語のスプルキャッチは、今までどおり動く
4. 国の一覧を直して再登録すれば、問題の文・国旗が直る

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| 流れるカード | **国旗だけ**。いつも「『国名』の国旗は？」と上に出て、国旗の絵が流れる。国名が流れる形は作らない |
| 選び方 | 難しさ（初級・中級・上級）だけ。大陸は選ばない |
| 遊び方 | 英語のスプルキャッチと同じ（1回10問・ハート3つ・タップで種を投げる・◀▶で動かす・点数とコンボ・HPは使わない） |
| 難しさの中身 | 列の数と落ちる速さは英語と同じ（2列・8秒／3列・6秒／4列・4.5秒）。出す国と、まちがいの国旗は4章 |
| ごほうび | 英語とは別に、国旗キャッチで1日の最初の3回まで。経験値と学習ポイントを正解の数に応じて（英語と同じ数字）。コインは出さない |
| 鍵 | 関係なし（国旗の問題に国の鍵はない） |
| 作り方 | 国旗キャッチ専用の問題を作る。サーバーのゲームの部分は、英語と共通にして、設定だけを分ける |

## 3. 全体の形

- ミニゲーム（`MINI_GAMES`）に1行足す: 「スプルキャッチ（こっき）」・「流れてくる国旗を、スプルがキャッチ！」・`/games/flag-catch`
- サーバー: `/api/games/flag-catch`（英語の `/api/games/catch` と同じ3つの窓口）
- 遊んだ記録: `profile_game_plays.game` に `flag_catch` を入れる（表は変えない）
- 画面: `/games/flag-catch`。選ぶ・ゲーム・結果は、英語と共通の部品を使う

## 4. 問題

### 4-1. 難しさごとの国

国旗クイズと同じ国の一覧から作る。1問は1か国。

| 難しさ | 出す国 | 国の数（今の一覧） | まちがいの国旗 |
|---|---|---|---|
| 初級 | 知名度1の国 | 約46 | 世界の知名度1の国から |
| 中級 | 知名度1・2の国 | 約100 | 世界の知名度1・2の国から |
| 上級 | すべての国 | 193 | 似ている国（最大4。足りなければ世界の国で足して3つ以上） |

- 問題の形: 問題文「『日本』の国旗は？」（`「」`の中を大きく出す、今のスプルキャッチと同じ）。選択肢は、国旗の絵（`label` は国名）
- 正解の国と、まちがいの国旗は、決まった並びで作る（国旗クイズの計画と同じく、名前から決まる並び。同じ一覧からはいつも同じ）。まちがいは、初級・中級は最大8つ、上級は似ている国（3〜4つ）を持たせ、出すときに、列の数−1だけをランダムに選ぶ（今の仕組み）
- 計画は `FlagCatchPlanner`（新規。純粋な計算）。まちがいの選び方（`wrongCountries`）は、国旗クイズと同じものを使う（`FlagQuizPlanner` の関数を、外から呼べるようにする）

### 4-2. データベース

- 難しさごとに、クイズを1つ作る（「国旗キャッチ 初級」「国旗キャッチ 中級」「国旗キャッチ 上級」）。ステージには入れない
- 問題は `meta.flag_key`（`catch:{級}:{国のkey}`）で見つけて、あれば更新、なければ作る（何度実行しても重複しない。選択肢は中身が変わったときだけ作り直す）。`meta.catch_only = true` を付ける
- 書き込みは `FlagQuizWriter` に足す（`FlagQuizSeeder` が、国旗クイズと一緒に書く）

### 4-3. 出す順・覚え具合

- 1回10問を選ぶ決まりは、英語と同じ（最近まちがえた問題と、復習の日が来た問題を、あわせて6問まで先に。残りはランダム）
- 答えは、英語と同じく、問題ごとの覚え具合に記録する（まちがえた国旗が、次に先に出る）
- **国旗キャッチ専用の問題は、ステージのおさらいと仲間からの復習には出さない**（`meta.catch_only` が付いた問題を、`QuestionMemory::dueIds` で除く）。英語のステージのおさらいに、国旗の問題が混ざらないようにするため。国旗キャッチの中の復習（`dueIdsAmong`）は、そのままに使う

## 5. サーバーのゲームの部分

`App\Support\CatchGame` を、英語と国旗で共通にする。

- 各関数（`summary`・`start`・`rewardedPlaysLeft`・`finish`）に、ゲームの名前（`catch`・`flag_catch`）を渡す。省略すると `catch`（今の呼び出しは、そのまま動く）
- 設定は `config/games.php` の `catch`（今のまま）と `flag_catch`（新規）。`flag_catch` は、英語と同じ `question_count`・`review_max`・`daily_rewarded_plays`・`score`・`difficulties`（`lanes`・`fall_ms`・`reward`）を持ち、問題の出どころを `quizzes`（難しさ → クイズの名前）で指定する。`max_label_width` は持たない（国旗の選択肢には長さの上限を使わない）。`messages.empty` を持つ
- 問題の出どころ: 英語は今までどおり（「英語を学ぶ」のステージの問題。鍵のある国は除く）。国旗は、難しさのクイズの問題（多肢選択・正解が1つ・まちがいが列の数−1以上）
- ごほうびのお金の記録の理由は、`game_{ゲームの名前}`（`game_catch`・`game_flag_catch`）。1日の回数・自己ベスト・ごほうびの数は、ゲームごとに別に数える
- 窓口: `/api/games/flag-catch`（`GET /`・`POST /plays`・`POST /plays/{play}/finish`）。英語と同じ処理を、ゲームの名前だけ変えて登録する。終えるときは、回の `game` が、その窓口のゲームと同じことを確かめる
- 選択肢の返事に、国旗の絵を足す（`image`。絵のない選択肢は `null`）
- 分析の「よく使われる遊び」に、国旗キャッチの行を足す（`Analytics::activities`）
- レアな種の条件 `catch_perfect` は、今までどおり英語のスプルキャッチだけを数える（国旗キャッチは数えない）

## 6. 画面

- ゲームの種類ごとの設定（`catch-view.ts` の `CATCH_GAMES`）: 名前・あそびかた・説明文・窓口の道筋。英語は今までの文のまま。国旗は、名前「スプルキャッチ（こっき）」、あそびかた「①『国名』の国旗が上に出るよ ②流れてくる国旗をタップ！スプルが種を投げてキャッチするよ ③10問やってみよう。ハートは3つ」
- 流れるカード（`catch-game.tsx`）: 選択肢に `image` があれば、国旗の絵（3:2・切り取らず全体）を出す。列が4つのスマホ幅でも、はみ出さない大きさにする。絵がなければ、今までどおり文字
- 結果の「まちがえた言葉」: 国旗では、まちがえた国名と、正しい国旗の絵を出す（`missedWords` に、正しい選択肢の絵を足す）
- ページ: 今の `/games/catch` の中身を、種類を受け取る共通の部品（`CatchPageView`）に移し、`/games/catch` と `/games/flag-catch` の2つのページから使う
- 3・2・1のヒント・◀▶のヒント・種を投げる動きは、英語と同じ

## 7. テスト

- **サーバー（Pest）**
  - 計画（難しさごとの国の数・まちがいの数・上級に似た国旗・決まった並び）
  - 書き込み（重複しない・名前を直すと直る）
  - 国旗キャッチの開始（国旗の絵つきの選択肢・列の数・問題の数）
  - 終了（採点し直す・ごほうびは国旗キャッチ専用に1日3回・英語の回数に影響しない・自己ベストが別）
  - おさらい・仲間の復習に出ない
  - 英語のスプルキャッチが変わらない（今のテスト）
  - 窓口（別のゲームの回を終えられない・ログイン必須）
  - 分析の行
- **画面（Vitest）**: ゲームの種類ごとの設定、`missedWords` の国旗の絵、問題の読み込み（絵の取り込み）
- **ブラウザ**: ミニゲームの一覧に出る、選ぶ画面のあそびかた、国旗が流れる（2・3・4列）、タップで種を投げる、◀▶で動かす、結果の「まちがえた国旗」、スマホ幅

## 8. やらないこと

- 大陸を選ぶこと
- 国名が流れる形（国旗を見て国名を受け取る）
- 国名の読み上げ（声）
- ランキング・対戦
- レアな種の条件に国旗キャッチを入れること
