# 県マスターと地名コース（都道府県クイズ 拡張）— 設計書

- 作成日: 2026-10-06
- ステータス: 案（Owner確認待ち）。方針はチャットでOwner合意済み（地名と一般を2種類に分ける・称号は2段階・出し方のルール・一般は現状維持）
- 前提: `docs/design/2026-10-05-prefecture-quiz-design.md`、`docs/design/2026-10-06-passport-prefecture-badges-design.md`、`docs/design/2026-10-06-question-explanation-design.md`
- 問題の元原稿: `company/spra/spra-go/content/japan/prefectures/`（47県。Codexが作成。Claudeが形式を点検済み）

## 1. 目的

1. 県ごとに「地名」の問題（市区町村の読み）を足し、子どもが地名だけを何度でも遊べるようにする。
2. 「一般（名物・名所など。今のコース）」と「地名」の**両方**をクリアした人に、県の最上位の称号「◯◯マスター」を渡す。
3. 問題が多いコースは、**プールから毎回10問を選んで**出す。ただし子どもが「覚えて進めた」と感じられるよう、出し方のルールを決める。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| コース | 県ごとに「◯◯」（一般。今のまま）と「◯◯ 地名」（新規）の2つ。どちらも同じ地方の下に並ぶ |
| 一般コース | **今のまま**（初級・中級・上級が各1ステージ10問のボス）。新しい一般CSV（県14問前後）は取り込まない。いまのDBの30問が、新CSVの14問を含むため。新CSVは、将来「出題の優先度」を決める材料に取っておく |
| 地名コース | 級は初級・中級・上級・最高難易度。各級は**1ステージ（ボス）**で、問題はプールから抽選 |
| 最高難易度 | 地名の上級のボスを全問正解すると開く。称号の条件には入れない（挑戦枠） |
| 称号 | 2段階。「◯◯はかせ」＝一般の上級ボス全問正解（今のまま）。「◯◯マスター」＝**はかせを持ち、かつ地名の上級ボスを全問正解したとき**（順番は問わない） |
| バッジ | マスターのバッジの絵は、はかせと同じ。見た目だけ、金のふちを付ける（CSS。新しい絵は作らない） |
| 報酬 | 地名コースのステージクリアのコイン・ポイントは、一般の**半分**。XPなど答えの報酬は、今の仕組みのまま |
| 出題 | 4択が基本。地名のプールは4択のみ |

## 3. 出し方のルール（プールから10問を選ぶ）

プールが出す問題数より多いステージにだけ使う。プールが出す数以下のステージ（一般・国旗・英語など）は、今のまま全問を出す。

1. 出す数は `stages.question_count`（10。最高難易度は5）。プールは、そのステージにつながる問題すべて。
2. **まちがえた問題を先に混ぜる**: プロフィールの覚え具合（`profile_question_memories.wrong_on`）が新しい問題を、最大3問まで入れる。
3. **前回の半分を残す**: 前回そのステージで出した問題のうち、半分（5問）を次の回にも出す（やり直しの達成感のため）。前回の問題は、新しい表 `profile_stage_draws`（`user_profile_id`・`stage_id`・`question_ids`〔JSON〕）に持つ。前回がなければ、すべて新しく選ぶ。
4. **残りは、まだ正解したことのない問題から**ランダムに選ぶ。足りなければ、正解済みの問題から選ぶ。
5. **ボスは固定寄り**: プールの先頭5問（並び順）は毎回出し、残り5問を上の2〜4で選ぶ。称号がかかるので、毎回まったく別の問題にしない。地名コースは全ステージがボスなので、この決まりが地名コースの標準になる（1と3の「前回の半分」は、ボスでは先頭5問の固定に置き換わる）。
6. 選んだ問題は、同じ問題文が続かないよう並べ替えてから返す。選択肢の並びは、今のとおり毎回シャッフル。

おさらい（`QuestionMemory::dueIds`）は、今のまま。ボスには足さない。

## 4. サーバー

- **出題**（`GET /api/stages/{stage}`）: プールが `question_count` より多いときだけ、3章の抽選をして返す。返事の形は変えない。
- **クリア**（`POST /api/stages/{stage}/complete`）: 満点の数を「ステージの問題数」から**「出した数」**に変える（プールが大きいときは `question_count`、そうでなければ今の問題数）。ボスの全問正解の判定も同じ数で行う。
- **報酬の割合**: `stages.reward_percent`（整数。既定100）を足す。地名コースは50。ステージクリアの `applyEconomy` に、この割合を掛ける。
- **マスターの付与**: ボスを全問正解したあと、`PrefectureMaster::grantIfReady($profile, $県)` を呼ぶ。条件は「はかせを持つ」かつ「その県の地名の上級ボスの `best_score` が、出した数以上」。条件がそろい、まだ持っていなければ、`ProfileTitle` を作る。返事の `title_granted`・`title`・`title_badge` は、マスターが付いたときはマスターのものを返す（一般のボスでもはかせとマスターが同時に付くことがある。その場合はマスターを返す）。
- **地名コースの作り方**: `PlaceNameQuizPlanner`（元CSVから計画を作る純粋な計算）→ 既存の `FlagQuizWriter::writeTree`。コースは、同じ地方の下の「◯◯ 地名」。問題の `meta.flag_key` は `pref:{県のkey}:place:{級}:{番号}`（再実行しても重複しない）。`FlagQuizWriter` は、ステージの計画に `draw`（出す数）があれば `question_count` に使い、なければ今まで通り問題の数にする。
- **取り込みの入れもの**: 元CSVは `company/` にあり、本番にはない。取り込み用に `database/data/place-names/{県のkey}.csv`（47枚）へコピーする。北海道は4つに分かれているので1枚にまとめる。取り込みのコマンドは `php artisan db:seed --class=PlaceNameQuizSeeder`（`PrefectureQuizSeeder` と同じ流儀。何度実行しても同じ）。
- **解説**: CSVの「解説(要約)」を、そのまま `questions.explanation.summary` に入れる。地名の漢字（問題文の『』の中の語）は、今と同じ `meta.plain` に入れて、ふりがなを付けない。

## 5. 画面

- 県のコースの一覧に、「◯◯ 地名」のカードが並ぶ。作りは今のコースのカードと同じ。
- パスポートの「日本のバッジ」: 数の文を「はかせ 12/47・マスター 3/47」にし、マスターの県は金のふちを付ける。`GET /api/passport` の `prefecture_badges` に `master`（bool）を足す（今の項目は変えない）。
- ステージ結果: マスターが付いたときは、はかせと同じ「称号ゲット」の画面を、マスターの名前で出す。

## 6. ふりがな

地名コースの要約（例:「『札幌』は、『さっぽろ』と読むよ。石狩地方にある市だよ。」）には、辞書にない漢字が出る。取り込みのテストが、辞書にない漢字と、その語の一覧を出す。直し方は今までと同じ（熟語を `tools/furigana/` から辞書に足す。単漢字は足さない）。一覧が多すぎるとき（異なる語が300を超える目安）は、要約の書き方を変えるか、Ownerに相談する。

## 7. テスト

- サーバー（Pest）: 抽選（先頭5問の固定・まちがい優先・前回の半分・足りないとき・プールが小さいとき全問）、満点の数、報酬の半分、マスターの付与（順番が逆でも付く・はかせなしでは付かない・二重に付かない）、パスポートの `master`、取り込み（件数が集計CSVと一致・4択の形・同じ問題文と正解の重複なし・再実行で増えない）、ふりがなの網羅。
- 画面（Vitest）: 数の文、金のふちの判定。
- ブラウザ: 地名コースを遊ぶ・やり直して問題が入れ替わる・マスターの称号・パスポート・スマホ幅。確認のあと、プロフィール7を元に戻す。

## 8. 段階

1. **出題の仕組み**: 抽選・満点の数・報酬の割合（`reward_percent`）・`profile_stage_draws`。今のコースは変わらない。
2. **地名コースの取り込み**: 47県×4級。解説・ふりがな。
3. **県マスター**: 称号・パスポート・結果画面。

## 9. やらないこと

- 一般問題の追加・置き換え（新しい一般CSVの取り込み）。
- 地名コースの称号・バッジの新しい絵。
- 最高難易度の称号（挑戦枠のみ）。
- 抽選の細かい調整画面（数字は `config/` に置く）。

## 10. Ownerにお願いすること

- 地名問題2,125問の確認（元CSV。取り込む前に、少なくとも北海道と、読みの難しい県を）。
- 報酬の「半分」でよいか。遊んでみて、多すぎ・少なすぎがあれば `reward_percent` で調整する。
