# 特定商取引法に基づく表記（下書き）

> **下書きです。** 公開前にOwnerが確認し、必要に応じて専門家の確認を受けます。【要入力】の所はOwnerが埋めます。確認する点は `docs/legal/README.md` にまとめています。

学習ゲーム「Spra Go」のコイン（有償コイン）の販売について、特定商取引に関する法律に基づき、次のとおり表示します。

| 項目 | 内容 |
|---|---|
| 販売業者 | かつコード |
| 運営統括責任者 | 【要入力: Ownerの氏名】 |
| 所在地 | ご請求があれば遅滞なく開示します【要確認: 住所を書く場合はここに書く】 |
| 電話番号 | ご請求があれば遅滞なく開示します【要確認: 電話番号を書く場合はここに書く】 |
| メールアドレス | 【要入力: お問い合わせ用のメールアドレス】 |
| 販売価格 | 購入の画面に表示する価格（税込）。例: コイン100枚 120円、コイン550枚 500円、コイン1200枚 1,000円【要確認: 価格は正式に決めたものに直す。税込かを確かめる】 |
| 商品代金以外に必要な料金 | インターネットに接続するための通信料（お客様のご負担） |
| 支払方法 | クレジットカード（決済サービス Stripe を利用） |
| 支払時期 | 購入の手続きが終わったとき。実際に引き落とされる日は、カード会社の規約によります |
| 商品の引渡時期 | 支払いが終わったあと、すぐに購入の手続きをしたプレイヤーに付きます |
| 返品・キャンセル | デジタルのものの性質上、購入のあとの返品・キャンセルはお受けしていません。ただし、返金ポリシーに定めるとき（二重の請求、コインが付かない、不具合、未成年者の取り消しなど）は返金します |
| 動作環境 | 最新版の Google Chrome・Safari・Microsoft Edge などのブラウザ【要確認: 動作を確かめた環境に直す】 |
| 有効期限 | ありません（家族アカウントやプレイヤーを削除したときはなくなります） |
