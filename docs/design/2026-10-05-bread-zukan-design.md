## 1. 背景と目的

Spra-worldの確定画像にある、パンと作物の絵を、Spra-goで使う。Spra-worldは「種を育てて、収穫して、加工して、届ける」生産の流れを中心の遊びにしていて、進行・通貨・持ち物はSpra-goと分ける方針（`spra-world/docs/planning-handoff.md`）。そのため、Spra-goには**育てる・加工する仕組みは入れず、集めて眺める「ずかん」だけ**を作る（Owner決定）。

毎日のおつかいを3つそろえると、パン屋さんから1つ、おくりものがもらえる。ずかんには、日本語の名前に加えて、英語の名前も出す（Spra-goは英語を学ぶアプリでもあるため）。

**うまくいった目安**

1. おつかいを3つそろえて受け取った日に、パンかやさいが1つ、ずかんに入る（その日1回だけ）
2. 「じぶん」から「パンとやさいのずかん」を開くと、15個のますが並び、もらった物は絵と名前、まだの物はシルエットと「？」で出る
3. 15個そろうと「ぜんぶそろった！」と出る（そのあとのおつかいは、今までどおり）
4. 今のおつかい・ごほうび（ポイント・おまけ・なかよし度）は変わらない

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 範囲 | ずかんだけ。育てる・加工する仕組み、畑の絵（育つ4段階）は使わない（あとの拡張に取っておく） |
| 集め方 | 今日のおつかい3つをそろえて受け取った日の、おまけと一緒に、**まだ持っていない物から1つ**（ランダム） |
| 置き場所 | 「じぶん」のメニューに、「パスポート」と並べて「パンとやさいのずかん」を足す（ページは `/zukan`）。下のタブは増やさない |
| 15個 | パン10種・作物3種（にんじん・じゃがいも・玉ねぎ）・小麦のたば・小麦粉の15点（4章） |
| 見せ方 | もらった物: 絵・日本語（ふりがな）・英語。まだの物: 暗いシルエットと「？？？」。名前はもらうまで出さない |
| 全部そろったあと | もう贈らない（おつかいと、ポイント・おまけは今までどおり） |
| 値段・売り買い | なし（もらうだけ。ショップには出さない） |
| 画面外の仕組み | 町には置かない。バッグには入れない（ずかんの中だけ） |

## 5. サーバー

### 5-1. データ

- 表 `profile_zukan`: `user_profile_id`、`item_key`（`string(32)`）、`received_at`。`(user_profile_id, item_key)` に一意の制約（`profile_souvenirs` と同じ形。連打しても1つだけ）
- 設定 `config/zukan.php`: `items`（キー → 日本語・英語・種類）。画面側の絵のキーは `zukan_{キー}` と決まる

### 5-2. 贈る（`Zukan::gift`）

- `Zukan::gift(UserProfile $profile): ?array` — まだ持っていない物から1つを選んで記録し、`{ key, name, english, kind }` を返す。全部持っていれば `null`
- 選び方は、一覧のうち持っていない物を `random_int` で1つ。重複しないよう、記録は一意の制約が最後の守り（二重に呼ばれても1つだけ。重複したときは、別の物を選び直す）
- 呼ぶ場所は `Errands::claim` の中、**3つ目を受け取っておまけが出る分岐**（今の `$bonus` の分岐）。プロフィールは、呼び出し側でロックされているので、同じ日に二重に贈られない
- 返事（`gained`）に `gift`（贈った物、なければ `null`）を足す。今の `points`・`bonus`・`bond` は変えない

### 5-3. 窓口

- `GET /api/zukan`（ログインとプロフィールが必要）: `{ items: [{ key, kind, owned, name, english, received_at }], owned_count, total }`
  - 持っていない物は `name`・`english`・`received_at` を `null`（名前をもらうまで出さない）
- `GET /api/errands` の `bonus` に、`gift_left`（まだ贈れる数。`total - owned_count`）を足す（画面で「おまけ＋おくりもの」を出すかを決めるため）

## 6. 画面

### 6-1. ずかんのページ（`/zukan`）

- 見出し「パンとやさいのずかん」と、集めた数「3 / 15」
- 15個のますを、2列（スマホ幅）で並べる。もらった物は、絵・日本語・英語。まだの物は、同じ絵を暗いシルエット（`brightness(0)` と薄い不透明度）にして、「？？？」
- もらった物をタップしても何も起きない（見るだけ）
- 全部そろったら、上に「ぜんぶそろった！」の帯を出す

### 6-2. 入口

- 「じぶん」のメニュー（`components/app/me-sheet.tsx`）の「パスポート」の下に、「パンとやさいのずかん」を足す。アイコンは、ずかんの絵のうち、メロンパンを小さく使う
- 町の画面のボタンは増やさない

### 6-3. おくりもの

- おつかいの3つ目を受け取ったとき（`errand-sheet.tsx`・`errand-return.tsx` の受け取りの表示）、返事に `gift` があれば、「パン屋さんから おくりもの！」と、贈られた物の絵・日本語・英語を出す
- そのあとで「ずかんを見る」のボタン（`/zukan` へ）を出す
- 全部そろっていて `gift` が `null` なら、今までどおり

### 6-4. おつかいの表示

- おつかいの下の「3つそろうと おまけ +30pt」の文に、まだ贈れる物があるとき（`gift_left` が1以上）「と おくりもの」を足す

## 7. テスト

- **サーバー（Pest）**
  - 贈る処理: 持っていない物から1つ贈る・重複しない・15個そろったら `null`・二重に呼んでも1つだけ
  - おつかい: 3つ目を受け取ると `gift` が返り、ずかんに入る（1つ目・2つ目では返らない）。同じ日に同じおつかいをもう一度受け取ろうとしても、贈られない（今の「もう受け取ったよ」）。全部そろっている日は `gift` が `null` で、ポイントとおまけは今までどおり
  - 窓口: ログイン必須。持っていない物は名前が `null`。数が合う。ほかのプロフィールのずかんは見えない
  - 設定: 15点すべてに日本語・英語・種類がある
- **画面（Vitest）**: ずかんの一覧の並べ方（もらった物・まだの物の分け方、「3 / 15」）、おくりものの文
- **ブラウザ**: おつかいを3つ受け取るとおくりものが出る、ずかんにシルエットともらった物が並ぶ、スマホ幅で切れない、全部そろった帯。確かめたあと、開発用のデータを元に戻す

## 8. やらないこと

- 種を育てる・収穫する・小麦粉からパンを作る（生産の仕組み。Spra-worldの役目）
- 畑の絵（育つ4段階）を町やずかんで使うこと（あとの拡張）
- 町に置く・売る・買う・交換する
- ずかんの物を使ったクイズ（「bread」の問題など）。あとで足せるよう、英語の名前だけ持っておく
- 15個以外の物（ずかんの一覧は設定なので、あとで足せる）
- 音・読み上げ
