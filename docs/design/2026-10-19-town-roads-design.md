## 1. 目的

- 町に、**自分で道を引ける**ようにする。置くだけだった街づくりに、「つなぐ・形をつくる」遊びを足す。
- **Spruが、行きたい場所へ歩ける**ようにする(試作の「街を歩く」)。

## 2. 今の町(読んだ結果)

- 道は、サーバーの設定(`config/world.php` の `land.paths`)で**決まっている格子**(横が y=3・9、縦が x=3・9)。ふやす・けす手段はない。
- 道・目印のマスには、アイテムを置けない(サーバー `WorldPlacement::check`、画面 `validAnchors`)。仲間の立つ場所(`companion_spots`)とSpruの場所(4,3)は、道のマス。
- 町の API(`GET /api/world`)の `land` は、`paths`(道)・`blocked`(置けないマス=目印+道)・`spru`(立つ場所)を含む。家族の町(`Family.php`)も同じ形の `land` を使う。
- 画面は、段階1でCanvasになった。押せる場所は、HTMLの透明ボタン。地図の枠(`TownMap`)は、指のスクロール・ボタン拡大・ピンチ。
- Spruの絵は、立ち姿などの1枚ずつ。**歩く絵(4方向×3コマ)は、今のSpra Goにはない**。試作の `assets/*_passing|step_l|step_r.png`(12枚・640×800)にある。

## 3. 遊び方

### 3-1. 道

| 操作 | 内容 |
|---|---|
| 入口 | 町の「道をつくる」ボタン。押すと、画面の下に道の道具が出る |
| 道具 | 「ひく」「けす」「うごかす」「もどす」「やりなおす」「おわる」 |
| ひく | 指(マウス)を置いたマスが光る。押したまま動かすと、つながった道の形が、先に見える(置けるマスは明るく、置けないマスは赤)。離すと、道ができる |
| けす | 自分が引いた道を、なぞって消す |
| うごかす | 地図をスクロール・拡大する(今のとおり)。道を引いている間は、1本指でスクロールしない |
| もどす・やりなおす | 最後の引く・消すを取り消す・もう一度する(この画面を開いている間、20回まで) |

- 道のデザインは、今選んでいる道(`road_style`。日本の土の道・旅した国の道)のまま。引いた道も同じ絵になる。
- **引ける場所**: 開いた区画の、陸のマスで、目印・アイテム・道がないところ。雲の区画・海・地図の外には引けない。
- **消せるのは、自分が引いた道だけ**。もとからある格子の道は、消せない(目印と仲間の立つ場所を守るため)。
- 道の上にはアイテムを置けない(今のまま)。道を引いたマスにアイテムがあれば、引けない。道を消せば、置ける。
- 引ける数の上限は、300マス(設定で変えられる)。
- お金・ポイントはかからない。経験値・にぎやか度も変わらない(今回は)。

### 3-2. Spruが歩く

- 道具が出ていないとき、**何もないマスをタップすると、Spruがそこへ歩く**。歩けるのは、開いた区画の陸のマスで、目印・アイテム・仲間のいるマスでないところ(道の上も草の上も歩ける)。経路は、4方向(試作と同じ)の最短。
- 歩いている間は歩く絵(向きで4方向)。着いたら、その場で立ち姿に戻る。吹き出し・タップの範囲も、Spruについていく。
- 歩く場所は、**保存しない**(開き直すと、いつもの場所に戻る)。夜、家で寝ているときは歩かない(タップは今のまま)。
- 歩いている途中の新しいタップは、そこへ向きを変えて行く(試作は「着いてから」だった。待たせない)。
- アイテムを置いている間・道具を使っている間は、歩かない。歩くことも「さわった」ことにして、スプルのうたた寝・あいさつの間隔(`lastInteractionAt`)を動かす。
- 動きを減らす設定でも歩く(自分でさわって起こる動きなので)。ゆれ・跳ねは出さない。

## 4. データ・サーバー

| 場所 | 内容 |
|---|---|
| テーブル `profile_roads`(新規) | `user_profile_id`・`x`・`y`・`created_at`。`(user_profile_id, x, y)` は一意。道の種類は列にしない(今は道のデザインはプロフィールで1つ) |
| 設定 `config/world.php` | `roads.max`(300) |
| `WorldLand::toArray($level, $profile = null)` | 引いた道を `paths` と `blocked` に**足して**返す。引いた道だけの一覧を `custom_paths` で返す(画面が「消せる道」を知るため) |
| `WorldPlacement::check` | 置くマスが引いた道なら422「道があるよ」 |
| `WorldRepair` | 引いた道は、置いたアイテムと重ならない決まりなので、直す物はない(テストで確かめる) |
| 家族の町 `Family.php` | その人の引いた道も、`land` に入れて見せる |

### API

- `POST /api/world/roads` — body: `{ "add": [[x,y],…], "remove": [[x,y],…] }`(それぞれ100まで。空でもよいが、両方空は422)。
  - **全部通るか、全部通らないか**(トランザクション。プロフィールの行をロックしてから調べる)。
  - `add`: 範囲内・開いた区画・海でない・目印でない・もとの道でない・もう引いてない・アイテムが置いてない・上限をこえない。1つでも外れたら422(どれが外れたかの言葉を返す)。
  - `remove`: 自分が引いた道だけ。もとの道・引いてないマスなら422。
  - 返り値: `{ custom_paths: [[x,y],…] }`(いまの全部)。

### 5-2. 変えるもの

- `town-canvas.tsx`: `onTilePointer({type, x, y})`(down・move・up・click)を受けて、押したマス・ドラッグのマスを返す。道具が出ている間は `touch-action: none`。引いている道の先読み(`strokePreview`)を、動く層に描く(置ける=明るい色、置けない=赤)。
- `town-map.tsx`: 道具が出ている間(`lockScroll`)は、マウスのドラッグ・指の1本スクロールを止める(拡大ボタン・ピンチ・「うごかす」は使える)。
- `world-scene.tsx`: 道具が出ている間は、透明ボタン(アイテム・家・畑・仲間・スプル・雲の札)を押せなくする(`pointer-events: none`)。Spruの位置(`spruAt`)を受けて、タップの範囲・吹き出しを動かす。
- `world-screen.tsx`: 道具の状態(`tool`)、引いた道(`customRoads`)、取り消しの履歴、Spruの位置・経路を持つ。
- `canvas/scene-model.ts`: スプルを `spruAt`(小数のマス座標。歩く間)の位置で、重なり順に入れる。歩く間の絵(`walkFrame`)を選ぶ。
- 引いたあとの地面の層は、`groundSignature`(`land` を含む)が変わるので、**引いた(離した)ときだけ**作り直す。引いている間は、動く層の先読みだけ。

### 5-3. 引くときの手順(画面)

1. 道具「ひく」で押す → 押したマスを先読みに入れる。
2. 動かす → 前のマスから今のマスまでを `strokeTiles` でつなぎ、先読みにたす(もう入っているマスはたさない)。
3. 離す → 先読みから、置けるマス(`canDrawAt`)だけを引く道として、**すぐ画面に反映**(`customRoads` を更新)し、`POST /api/world/roads` を送る。
4. 失敗(422・通信)したら、反映をもとに戻して、言葉を出す(「ここには、道をひけないよ」)。成功したら、サーバーの返り値で上書きする。
5. 履歴に「引いたマス・消したマス」を足す。もどすは、逆の差分を送る。

- 同じマスの二重の送信・連打は、「送っている間は次を送らない」(順番に送る)で防ぐ。

## 6. Spruの歩く絵

- 試作の12枚(`assets/{lower_left|lower_right|upper_left|upper_right}_{step_l|passing|step_r}.png`、640×800・透明)を、`tools/spru-assets/` の切り抜きに足し、`public/spru/walk/{向き}_{コマ}.webp` と `spru-assets.ts` に書き出す(今までのスプルの絵と同じやり方)。
- 大きさは、町の立ち姿(`front`、高さ58)と**並べて見て合わせる**(歩く絵だけ大きく・小さくならないように、足元と体の高さをそろえる)。
- 原本は変えない(`showcases/` からコピーして使う)。Spra Worldと同じ絵なので、そのままSpra Worldの素材にもなる。
- 歩く向き: ±x が右下・左上、±y が左下・右上(試作と同じ)。

## 9. 危ないところ

- **スマホで、指の1本が、スクロールと道を引くことで取り合いになる**: 道具が出ている間だけ引く(`touch-action: none`)。スクロールしたいときは「うごかす」か、2本指(ピンチ)・拡大ボタン。
- **遠くまで引くとき、画面の端で止まる**: 今回は端でのスクロールは作らない(縮小して全体を出してから引く。0.4倍で全部の土地が入る)。足りなければ、あとで足す。
- **2つの画面で同時に引く**: サーバーが全部通るか全部通らないかで守る。画面はサーバーの返り値で上書きする。
- **引いた道と、仲間・Spruの立つ場所**: 立つ場所はもとの道(消せない)なので重ならない。歩く場所は保存しないので、引いた・消した道とずれる心配はない。
- **道を引くたびに、地面の層(大きなCanvas)を作り直す**: 離したときだけ。軽さを測って、遅ければ道だけの層に分ける。

## 10. やらないこと(段階2)

- 道の種類を、マスごとに選ぶ(土・石畳)。カーブ・交差・坂の専用の絵(試作の「交通タイル」)。
- 道の費用・ポイント・経験値。にぎやか度に、道の数を入れる。
- 仲間が歩く。Spruの歩く場所の保存。
- 道を引くための、画面の端でのスクロール。
- 地図の広さ・区画の変更(段階3)。長方形の建物(段階4)。
