# 日本のコースを、分野ごとのステージにする — 設計書

- 作成日: 2026-10-21
- ステータス: **実装済み（開発環境で確認。本番への反映は、Ownerが手順書どおりに行う）**
- きっかけ: Ownerの声（2026-10-15）「問題がいろいろ散らばっているので、わかりにくい。ステージ1は『あいさつ』、ステージ2は『地名』のように、ステージごとにテーマを決めたい」。前の設計（`docs/design/2026-10-15-question-variety-design.md`）の「プール（全ステージ共通）から抽選する」を、日本のコースでは、「1ステージ＝1分野」に替える

## 1. 決めたこと

- 日本のメインの道は、**級（初級・中級・上級）ごとに、8つの分野（1分野＝1ステージ）＋最後のボス（全分野のまとめ）の、9ステージ**。
- 8つの分野（番号つき。`company/spra/spra-go/content/japan/` のフォルダ名と同じ）:

| ステージ | 分野 |
|---|---|
| 1 | 日本のことばとマナー |
| 2 | 日本の基本情報 |
| 3 | 地方と都道府県（日本地図の「この県は？」47問を含む） |
| 4 | 県庁所在地 |
| 5 | 食べ物・名物 |
| 6 | 観光地・文化（祝日・年中行事31問を含む） |
| 7 | 山・川・湖 |
| 8 | 歴史・産業 |
| 9（ボス） | 日本のまとめ（全分野から） |

- 各ステージで出す数は、初級10・中級15・上級20（ボスは15・20・25）。ステージの問題の数は、約25〜47問なので、毎回、抽選する（まだ答えていない問題を先に出す、前の抽選から5問を残す、まちがえた問題を最大3問足す、は、これまでの仕組みのまま）。
- **ステージのなかは、やさしい順**（問題の難しさ `grade` 1〜5の昇順。同じ難しさのなかは、ばらばら。同じ問題文は続けない）。ステージごとの難しさの坂道は、級（初級→中級→上級）と、ステージのなかの並びで作る。ステージの番号による難しさの調整は、しない（テーマごとのステージなので、番号の順に難しくなるわけではない）。
- **ボス**は、全分野の問題をいっしょにしたプール。先頭の5問（固定）が、いろいろな分野の難しい問題になるように、分野を順に回って、難しい順に集める。
- 画面: ステージの道（蛇行）の、ステージの横に**テーマの名前**を出す。ステージの始まりのルールのカードと、問題の上の見出しにも、テーマの名前を出す。

## 2. 原稿とデータ

- 原稿は、8分野 × 3級のCSV（`company/spra/spra-go/content/japan/<分野>/final/questions.csv`。採用版704問）。`tools/content/build_jp_fields.py` が、取り込み用のJSON（`docs/content/drafts/jp_fields_{beginner,intermediate,advanced}.json`）にする。
  - 分野Nは、ステージ番号 20+N に取り込む（一時的な置き場）。`course:build` が、分野ごとのステージ1〜8に並べ直し、取り込みの置き場（21〜28と、地図=11・祝日行事=12）を消す。
  - 問題には、問題の番号（`key` = 問題ID。例: `JP05-B-001`）・難しさ（`grade`）・解説・画像（`/quiz/jp/<画像キー>.webp`）を付ける。取り込みは、`key` があれば `key` で見分ける（「県と県庁所在地の正しい組み合わせは？」のように、問題文が同じでも、別の問題として取り込む）。○×は、`true_false`（選択肢は「ただしい」「まちがい」）。
  - 取り込みは、何度流しても同じ。難しさ・解説・画像が変わったときだけ、書き換える。
- 画像: `frontend/public/quiz/jp/`（51点。640×640のWebP、合計約3.5MB）。
  - ChatGPTで作った46点（01・02・05・06・07・08）と、アプリの県の形データから作った地図5点（`tools/content/render_jp_maps.mjs`。ChatGPTだと日本列島の形がくずれるため）。
  - 画像がない問題も、文字だけで成り立つ。
- **テーマの名前**: `stages.theme_name`（新しい列）。`config/themed_courses.php`（旧 `config/japan_course.php`）に、分野の名前・出す数・ボスの称号の定義がある。
- 前からあった日本の問題（国旗3問・首都・言語など）のうち、地図47問は分野3、祝日・年中行事31問は分野6に入れた。それ以外は、新しい8分野に同じ内容があるので、ステージから外した（問題そのものは消さない。覚え具合の記録を守る）。
- 難しさ（`grade`）のない前からの問題には、取り込みのとき、級に合う印（初級2・中級3・上級4）を書く。

## 3. 進み具合について（Ownerへ）

日本のステージの意味が、すべて変わる（初級の1〜10が、分野の1〜8とボスの9になる）。そのため、**日本のステージの、いままでのクリアの記録と、抽選の記録は、反映の最初の1回だけ消える**（ステージの番号が同じでも、中身が別なので。もう一度並べ直しても消えない）。

- 消えるもの: 日本のメインの道の、ステージのクリア・最高点・やった回数。
- 消えないもの: ほかの国・世界遺産・英語などのステージ、レベル、コイン、学習ポイント、町。すでにもらったごほうびも、そのまま。
- 影響を受けるのは、いまの招待ユーザー。日本の道を、また最初から遊べる形になる。

## 4. 本番への反映の手順

1. `git push`（main）。
2. サーバー: `cd ~/Spra-go && git pull --ff-only && scripts/deploy.sh --no-pull`（DBの移行が、自動で走る。`stages.theme_name` の列が増える）。
3. サーバーのコンテナで、`production:bootstrap` を流す（原稿の取り込み → 外す問題 → コースの並べ直し の順に、まとめて行う。何度流しても同じ）。または、次の3つを、順に流す:
   - `content:import docs/content/drafts/jp_fields_beginner.json`（中級・上級も）
   - `content:import docs/content/drafts/jp_extra_beginner.json`（中級・上級も。地図と祝日行事。すでに取り込み済みなら不要）
   - `course:build`
4. 確認: 日本の道に、ステージ1〜9とテーマの名前が出る／ステージ5に食べ物の画像の問題が出る／ボスがある。

## 5. テスト

- `ThemedCourseTest`（旧 `JapanCourseTest`）: 9ステージ・テーマの名前・出す数／分野ごとの問題とやさしい順／地図と祝日行事の振り分け／難しさのない問題への印／ボスの先頭5問／原稿のない級はそのまま／何度並べ直しても同じ・クリア記録は残り、最初の1回だけ消える／取り込み（key・難しさ・解説・画像・○×・再取り込み）／APIがテーマの名前を返し、順番を保つ。
- 取り込みのJSONは、`content:import --dry-run` で検証できる。

## 6. 今回やらないこと

- ほかの国（アメリカ・フランス・イギリス・韓国・インドネシア）の分野化。日本で型ができたので、同じ手順（分野の決定 → Codexに原稿の依頼 → 確認 → 画像 → 取り込み）で、国ごとに進める。
- 「ステージ番号による難しさの調整」（`2026-10-15-question-variety-design.md` の段階3の、難しさの印による抽選の絞り込み）。ステージが分野ごとになったため、不要になった。
- 世界の国旗クイズ・都道府県クイズ・英語のコースの変更。
