# メインゲームの作り直し（国レベル・言語コース・長いステージ）— 設計書

- 作成日: 2026-10-07
- ステータス: Owner合意済み（2026-10-07。方針は3章、9章の6項目も決定済み）。設計書の確認のあと、実装計画に進む
- 前提: `SPEC.md` 4-2（冒険ループ）・4-4/4-4a（コンテンツ・言語モード）・4-4b（パスポート）、`docs/design/2026-10-06-prefecture-master-design.md`（プールからの抽選）、`docs/design/2026-10-05-road-style-design.md`（国の道の絵）

## 1. 目的

今のメインゲームは、国ごとに初級・中級・上級が各1〜5ステージで、遊びきるのが早い。国を増やす準備も追いつかない。そこで、

1. 級とステージを長くして、遊びごたえと難しさを出す。
2. **国ごとのレベル**と**言語ごとのレベル**を作り、パスポートで見えるようにして、続ける動機にする。
3. 「◯◯を学ぶ」と「◯◯語を学ぶ」を分けて、国と言語が混ざる混乱をなくす。
4. ステージの道を、国の雰囲気とスプルが歩く、ゲーム性のある画面にする。

## 2. 今の作りと、課題（調査結果）

- 国ごとの学習（国旗・世界遺産）は、**国に結びついたステージ**（`stages.country_id`）。国旗は 3級×5ステージ（4×10問＋ボス20問）。世界遺産はほぼ1ステージ×3問。
- 英語は「英語を学ぶ」（言語モードのカテゴリー）で、アメリカとイギリスに**同じ内容が国ごとに別のステージ**として付いている。フランス語・日本語のコースはない。「言語」という仕組みはゲーム側にない。
- 国のレベルはなく、プロフィールのレベル（町の土地の解放だけに使う）だけがある。パスポートのスタンプは、その国の**全カテゴリーの全ステージ**（国旗・英語・世界遺産）を全部クリアして銅・銀・金になる。ステージを増やすと、条件がとても厳しくなる。
- `/travel/[countryId]` は、級ごとに1つのカテゴリー（先頭）しか出さない（世界遺産と国旗が同じ番号で並ぶ）。
- クリアに最低の点数はなく、遊び終えれば `cleared_at` が付く。ボスの称号だけが全問正解。
- チケットは「その国の初級のボスをクリア」で増える。カテゴリーを区別しないので、英語や世界遺産の初級ボスでも増える。
- 体力（HP）は、正解で−1・不正解で−2（最大20）。**ステージが15〜25問になると、全問正解でもHPが足りなくなる**（9章）。
- `StagePath` は縦に並べるだけで、道・背景・スプルは出ない。スプルは歩く絵（`outing/walk.webp` など）の静止画だけで、アニメーションはCSSの動きで作る。

## 3. 決定事項（Owner合意）

| 項目 | 決定 |
|---|---|
| 級とステージ | 各級10ステージ。通常ステージは 初級10問・中級15問・上級20問。ステージ10がボス |
| ボス | 通常より多め。初級15問・中級20問・上級25問（通常＋5問。数は設定で変えられる） |
| 国ごとの規模 | 国のデータでステージ数・問題数を変えられる。アメリカ・フランスは30ステージ、バチカン・東ティモールなどは少なくてよい（例: 初級だけ5〜10ステージ） |
| 学ぶコース | 「◯◯を学ぶ」と「◯◯語を学ぶ」の2つに分ける |
| 言語コース | **言語ごとに1つ**。国からは「その国の母国語のコース」へつなぐ。複数の国から同じコースに入れる（アメリカ・イギリス→英語、南米の国々→スペイン語） |
| レベル | 国レベル（日本・アメリカ・フランス…）と、言語レベル（英語・フランス語…）を、別々に持つ |
| パスポート | 「国レベル」と「言語レベル」を、別の表で出す。**母国の言語レベルは出さない**（日本人の日本語レベルなど） |
| 母国 | プロフィール（家族アカウント）に「母国」を持たせ、**今は全員「日本」に固定**。選ぶ画面は外国人向けを始めるときに作る |
| 画面 | ステージの道に、国の道の絵と周りの地面を敷き、スプルが一緒に歩く。素材のある国は道の絵を使い、日本は素材が届くまで今の共通の道 |
| HP（体力） | **正解ではHPを減らさない。不正解のとき−1**（最大20のまま）。今の「正解−1・不正解−2」から変える |
| クリア率 | 通常ステージ60%以上・ボス80%以上。称号は全問正解のときだけ |
| 近道 | 中級の正答率が50%を超えていれば、上級をボス前でも開ける。初級クリアとチケットで、次の国へ出発できる（今のまま） |
| 既存のステージ | 公開前なので作り直す（今のステージと進み具合は移行しない） |
| 報酬 | 通常ステージのクリア報酬は半分（コイン50・ポイント25。`reward_percent` 50）、ボスは今のまま（100・50）。答えごとの報酬は今のまま。遊んで調整する |
| 最初の対象 | 日本・アメリカ（英語）・フランス（フランス語）の3つで型を作り、広げる |

## 4. 設計

### 4-1. コースの考え方

- **国のコース（◯◯を学ぶ）**: 国ごと。ステージは今まで通り `stages.country_id` を持つ。級ごとに10ステージ（小さな国は少ない）。
- **言語のコース（◯◯語を学ぶ）**: 言語ごと。ステージは**国に結びつけず**（`country_id` は null）、言語のカテゴリー（今の「英語を学ぶ」と同じ `is_language_mode`）にだけ付ける。同じ言語のステージが国ごとに重ならず、進み具合も1つになる。
- **国と言語の対応**: `config/languages.php`（新）に、国の `key` → 言語の `key` を書く。例: `us`・`gb` → `en`、`fr` → `fr`、`kr` → `ko`、`jp` → `ja`。言語のカテゴリーの名前は「◯◯語を学ぶ」。母国の言語は出さない（4-5）。
- 国に言語の対応がない（バチカンなど）ときは、言語のボタンを出さない。

### 4-2. 級・ステージ・問題

- **ステージの数**: データ（`stages` の行）で決まる。コードに10を埋め込まない。最後のステージが唯一のボス（`is_boss`）で、番号は1からの連番にする（今の鍵の判定が前提にしている）。
- **問題の数**: `stages.question_count`（通常10・15・20、ボス15・20・25）。`FlagQuizWriter`・`ImportContentCommand` の `draw` と同じく、問題は**プール**として持ち、出すときに抽選する（`is_pool`。`StageDraw` をそのまま使う）。
- **プール**: 1つの級の問題を、その級のすべてのステージにつなぐ（`stage_questions` は、同じ問題を複数のステージにつなげられる）。`StageDraw` は「まだ答えたことのない問題」を先に出すので、ステージを進めるほど新しい問題に出会える。目安は、1国あたり 初級60・中級80・上級100問以上。小さな国は少なくてよい。
- **テーマ**: ステージにテーマ（首都・国旗・地理など。`question_theme_id`）を付けたいときは、そのテーマの問題だけをそのステージにつなぐ。

### 4-3. クリアの条件

- **通常ステージ**: 正答率 **60%以上**でクリア（`cleared_at` を付ける）。未満は、遊んだ記録（`attempts`・`best_score`）だけ残し、クリアにしない。
- **ボス**: 正答率 **80%以上**でクリア。称号は、今まで通り**全問正解**のときだけ付ける。
- 率は `config/quiz.php`（`clear_percent`: 通常・ボス）で変える。
- 今は最低点がない（遊べばクリア）ので、この変更で既存のコースも少し難しくなる。

### 4-4. 進級（次の級・次の国）

- **級**: 前の級のボスをクリアすると、次の級が開く（今のまま）。**近道**として、前の級の正答率（その級で答えた問題の正解の割合）が **50%を超えている**ときも、次の級を開く。
- **国**: 初級のボスをクリアして、チケットを持っていれば、次の国へ出発できる（今のまま）。チケットの数え方は、**その国の「◯◯を学ぶ」の初級のボス**だけを数えるよう直す（今は英語や世界遺産のボスも数えてしまう）。
- 解釈の確認は 9章。

### 4-5. レベル

- **国レベル**: その国の「◯◯を学ぶ」のステージの、クリアした数。1ステージクリアで1上がる。最大は、その国のステージの数（アメリカ30、小さな国は10など）。
- **言語レベル**: その言語のコースのステージの、クリアした数。母国の言語は、パスポートに出さない。
- 新しい表は作らず、`profile_stage_progress` から数えて返す（今のパスポートの `achievement` と同じ作り方）。同じステージを何度クリアしても1回。
- パスポート（`GET /api/passport`）に、`country_levels`（国・レベル・最大）と `language_levels`（言語・レベル・最大）を足す。今のスタンプ（銅・銀・金）は残す。ただし、スタンプの条件を「その国の**国のコース**の、級のすべてのステージをクリア」に直す（英語・世界遺産は含めない。ステージが増えても条件が重くなりすぎない）。
- 母国: `user_schemas`（家族アカウント）に `home_country`（既定 `JP`）を足す。言語レベルの表から、母国の言語を除く。

### 4-6. 画面

- **入り口**: `/learn` の国のカード → `/travel/[国]/start`（今のまま）。2つのボタン「◯◯を学ぶ」「◯◯語を学ぶ」。ボタンの名前は国・言語から作る（今は「英語を学ぶ」固定）。
- **ステージの道**（新しい部品 `StageMap`）:
  - 国の道の絵（`road_{key}.webp`）を、曲がる道として敷く。周りは地面の絵（草・砂など）。国の絵がなければ共通の道。
  - 10ステージが、道に沿って並ぶ。ふつうの画面でスクロールできる縦長にする。
  - スプルは、いま遊ぶステージの上に立つ。ステージをクリアすると、次のステージへ歩く（歩く絵の `outing/walk.webp` を、CSSの動きで移動。`prefers-reduced-motion` のときは動かさない）。
  - ステージの印は、今の鍵・開いた・クリア済み・ボスの絵を使う。
  - 今の `StagePath` は、`/play/[id]`（ミニクイズ）などが使うので残す。`StageMap` は、国のコース・言語のコースで使う。
- **級の切り替え**: 今の3つのタブのまま（最高難易度は地名コースだけ）。
- **国のコース画面の不具合**: 級ごとに1つのカテゴリーしか出ない点は、国のコースを「1本の道」にまとめることで解消する（世界遺産などの別のテーマは、あとで別の道として足す）。
- **日本の道の絵**: Ownerが最後に用意する。届くまでは、今の共通の道。

### 4-7. データの作り方

- 国のコースの内容は、今まで通り `content:import`（`docs/content/drafts/*.json`）で入れる。ステージ数・問題数が違う国のため、**国ごとのコース定義**（`database/data/country-courses.php`）を足す: 国ごとに「級ごとのステージ数・通常の問題数・ボスの問題数」。インポートは、プールとして書く（`question_count` に出す数、`is_pool` を真）。
- 言語のコースは、言語ごとの内容（`docs/content/drafts/{言語}_*.json`）から、`country_id` を付けずに書く。今のアメリカ・イギリスの英語の内容は、1つにまとめる（問題文が同じ問題は重複しない作りが、すでにある）。
- 公開前なので、既存のステージ・進み具合は**作り直して**よい（移行は作らない）。

## 5. 段階

1. **ステージとクリアの仕組み**（サーバー）: 級ごとのステージ数・出す数・ボスの数をデータで決める。クリア率（60・80%）・近道（50%）。国のコース定義。チケットの数え方の修正。HPの調整（9章）。
2. **レベルとパスポート**: 国レベル・言語レベル・母国の項目・スタンプの条件の修正。
3. **言語コース**: `config/languages.php`、言語のコースの書き込み（国に結びつけない）、画面の入り口（ボタン名）。英語（アメリカ・イギリス共通）の内容をまとめる。
4. **ステージの道**（`StageMap`）: 国の道の絵・スプルが歩く動き。
5. **内容を足す**: 日本・アメリカ・フランスの問題（国と言語）をプールとして増やす。
6. **ほかの国へ広げる**: イギリス・韓国・インドネシア、小さな国。

3つの国（日本・アメリカ・フランス）で、1〜4を通して確かめてから、5・6に進む。

## 6. 影響を受ける所（調査より）

- チケット・おみやげ（`Travel::context`・`config/travel.php` の `boss` 条件）。テスト（`TravelTest` など）は、ボスの考え方を変えなければそのまま通る。
- パスポートのスタンプ（`routes/api.php` の `/passport`）。条件と、段位の決め方の順序の弱さ（金が銅なしで付く）も、直す。
- `/travel/[countryId]`・`/trip/[key]`（`pickBeginnerGroup`）・`StagePath`・`lib/difficulty.ts`・パスポートの画面。
- Owner管理画面のステージ作成（`stage_number` の重複の規則が国を見ない・`is_pool`・`reward_percent`・最高難易度がない）。
- `GET /api/countries` と `GET /api/countries/{id}` で、ステージの数え方（問題のないステージを含むか）が違う。そろえる。
- 報酬: ステージクリアのコイン・ポイントは、ステージ1つにつき固定。ステージが増えると、もらえる総量が増える（9章）。

## 7. テスト

- サーバー（Pest）: クリア率（通常60・ボス80・称号は全問正解のみ）、近道（50%）、チケット（国のコースの初級ボスだけ）、国レベル・言語レベル（同じステージを繰り返しても1）、母国の言語レベルを除く、言語コースが国に結びつかないこと、国ごとのコース定義の取り込み（再実行で増えない）、スタンプの条件。
- 画面（Vitest）: レベルの表示・ステージの道の位置の計算・スプルが動く先。
- ブラウザ: 日本・アメリカ・フランスで、国のコース・言語のコースを遊ぶ。スマホ幅。確認後、プロフィールを元に戻す。

## 8. やらないこと

- 母国を選ぶ画面と、外国人向けの翻訳・解説（母国は日本に固定）。
- 日本語を学ぶコース（外国の人向け。あとで）。
- 日本の道の絵（Ownerが最後に用意）。
- 国ごとの背景の追加（素材のある国の道の絵だけを使う）。
- 世界遺産などの別のテーマの道（あとで別の道として足す）。

## 9. 決まったこと（旧「Ownerに決めてほしいこと」）

3章の表のとおり。HPは「不正解のとき−1」（`routes/api.php` の答えの処理: 正解 `-1` を `0` に、不正解 `-2` を `-1` に。`config/world.php` に出して変えやすくする）。報酬は、通常ステージの `reward_percent` を50、ボスを100にする（国のコース定義で決める）。
