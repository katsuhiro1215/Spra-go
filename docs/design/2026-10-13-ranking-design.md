# ミニゲームのランキング — 設計書

- 作成日: 2026-10-13
- ステータス: **実装済み（段階1・2）**。ニックネームは自動のみ・点数と時間を出す・パスワード入れ直し、で確定（Owner承認 2026-10-13）。Googleだけで登録した保護者（パスワードなし）は、パスワードを設定するまで、オンにもニックネームの変更もできない（2026-10-13 修正）。方針はOwner承認済み（段階1=家族、段階2=みんな。みんなの表示は「ニックネームと順位」。保護者がOn/Offできる）
- 前提: `docs/design/2026-10-09-minigame-rollout-design.md`、`2026-10-09-slide-puzzle-design.md`、`2026-09-29-spru-catch-design.md`

## 1. 目的と、守ること

ミニゲームの記録を、家族やほかの子と比べられるようにして、「もう1回」の気持ちを作る。ただし、子どもが使うアプリなので、次を守る。

1. **知らない人に、子どもを特定できる情報を見せない**（本名・顔・学年・場所・自由な文章）。
2. **保護者が決める**（初期値はOff。子どもが自分でOnにできない）。
3. **順位でやる気をなくさせない**（上位だけを見せ、下位には「自己ベスト」を見せる）。
4. **ごほうびは順位と結びつけない**（不正の動機になるため。順位は「見せるだけ」）。

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 順位を付ける単位 | ゲーム × 級（初級／中級／上級）。ゲームは `catch`・`flag-catch`・`space-trip`・`puzzle-flag`・`puzzle-space` |
| 並べる値 | キャッチ系・うちゅう旅行＝点数（高いほう）。パズル＝かかった時間（短いほう） |
| 1人の記録 | その期間の中の、いちばんよい1回（ベスト） |
| 期間 | 家族＝「今週」と「自己ベスト（ずっと）」。みんな＝「今週」だけ。週は日本時間の月曜0時で切り替え |
| 家族 | 同じ家族アカウント（`user_schema_id`）のプロフィール全員。ニックネームではなく、今のプロフィール名とアバターを出す |
| みんな | 保護者がOnにした家族のプロフィールだけが、載る・見られる。表示は**ニックネームと順位とアバター**（点数・時間も出す。出さないほうがよければ決める＝7章） |
| 載る人数 | 上位10人＋自分の順位（10位より下でも、自分の順位は見える）。同じ値は同じ順位（先に出した人が上） |
| 保護者のスイッチ | 家族アカウントごと（`user_schemas.ranking_public`、初期値Off）。**Onにするときは、保護者のパスワードを入れ直す**（子どもが勝手にOnにできないように） |
| Offにしたとき | 次のリクエストから、みんなのランキングに載らず、見ることもできない（家族のランキングは残る）。記録は消さない |
| ニックネーム | プロフィール名は本名のことがあるので使わない。**自動で付ける**（「あかい うさぎ」のように、色＋どうぶつ。プロフィールごとに固定。保護者が付け直せる）。自由入力は、今回は作らない（不適切な言葉の対策が重くなるため） |
| 不正対策 | 14章。時間は、サーバーが測った時間と食いちがうものは載せない |

## 3. 画面

- ゲームの一覧（`/games`）の各ゲームの画面に［ランキング］ボタンを足す。
- ランキング画面: 上に［家族］［みんな］の切り替え、その下に［初級］［中級］［上級］、期間（家族のみ：今週／ずっと）。
- 並びは、1〜10位。自分の行はハイライト。10位より下なら、一覧のあとに「あなたは ○位」を足す。記録がない級は「まだ きろくが ないよ。あそんでみよう」。
- みんなの［Off］のとき（保護者がOnにしていない）: 「みんなのランキングは、おうちの人が オンにすると 見られるよ」と出す（家族のランキングは見られる）。
- 保護者の設定: 保護者の画面（`/profiles` の管理）に「みんなのランキングに参加する」のスイッチ。Onにするとき、パスワード入力。説明文に「表示されるのは、ニックネーム・アバター・順位・記録だけです。名前や学年は出ません」。ニックネームの付け直しもここ。
- 自己ベストを更新したとき、ゲームの終わりの画面に「ベスト こうしん！」と、いまの順位（家族・みんな）を出す。

## 4. データ

### 4-1. 新しい列・表
- `user_schemas.ranking_public` boolean、初期値 false。
- `user_profiles.ranking_nickname` string、null可。最初に必要になったときに自動で付ける（`RankingNickname::ensure($profile)`）。重ならなくてよい（表示は同じ名前でも順位で区別される）。
- ランキングの集計用に、`profile_game_plays` の索引を足す: `(game, difficulty, played_on)`。
- 集計の表は作らない。`profile_game_plays`（終えた回）から、その場で出す。人数が増えて重くなったら、5分のキャッシュ、さらに集計表へ（今は作らない）。

### 4-2. 集計の考え方（`app/Support/Ranking.php`・新規）
```
board(game, difficulty, scope: family|public, period: week|all, viewer): {
  rows: [{rank, name, avatar, value, is_me}],   // 上位10
  me:   {rank, value} | null                    // 10位より下 or 圏外のとき
}
```
- 対象の回: `finished_at` がある・`game`・`difficulty` が合う・（パズルは `elapsed_ms` がある）。
- 週の範囲: `Garden::today()` を基準に、月曜〜日曜（`played_on`）。
- 点数ゲーム: プロフィールごとに `MAX(score)`、降順。同点は、その値を先に出した回（`finished_at` が早い）が上。
- パズル: プロフィールごとに `MIN(elapsed_ms)`、昇順。同じなら先に出した回が上。
- 家族: `user_schema_id` が同じプロフィールだけ。みんな: `ranking_public` がtrueの家族のプロフィールだけ。
- 載るのは、記録のあるプロフィールだけ。

## 5. API

| 通信 | 内容 |
|---|---|
| `GET /api/games/{path}/ranking?scope=family\|public&difficulty=初級&period=week\|all` | ボード。`public` で、保護者がOffなら 403（画面は説明を出す）。`period=all` は family のみ（public で指定したら 422） |
| `GET /api/ranking/settings` | `{public: bool, nickname: string}`（現在のプロフィールの家族） |
| `PUT /api/ranking/settings` | `{public: bool, password: string}`。Onにするとき（false→true）だけ、パスワード確認。Offは確認なしで切り替えられる |
| `POST /api/ranking/nickname` | ニックネームの付け直し（パスワード確認つき） |

- 既存の `finish` の返事に、`rank_family`（今週）と `rank_public`（今週。Onのときだけ）を足す。
- ログインしているプロフィールは `ActiveProfile::require` で決める（家族の町の API と同じ）。

## 6. 順位の見せ方（やる気を守る）

- 10位までと自分だけ。全員の一覧は見せない。
- 自分が圏外なら、順位の数字より、「自己ベスト」と「ベスト こうしん」を大きく見せる（順位は小さく）。
- 他人の記録の点数・時間を出すか: 点数・時間を出す（目標にできる）。ただし、パズルは問題（旗）が回ごとに違い、旗によって難しさが違う。このため、パズルは**時間に加えて、解いた旗の数（初級3・中級2・上級1）が同じ級の中でだけ比べられる**ことを、画面に小さく書く。

## 7. Ownerに決めていただきたいこと

1. **ニックネーム**: 自動（色＋どうぶつ）のみでよいか。保護者が自由に付けられるようにするか（不適切な言葉の確認が必要）。**おすすめは自動のみ。**
2. **みんなのランキングで、点数・時間を出すか**。おすすめは「出す」。
3. **パスワードの入れ直し**でよいか（保護者用の暗証番号を新しく作るより軽い）。

## 8. 不正・安全

- **時間の改ざん**: `elapsed_ms` は端末の値。サーバーは、`start` で回を作った時刻（`created_at`）から `finish` までの時間を持っている。**`elapsed_ms` がこれより10%＋2秒以上長い、または1ピースあたり0.3秒未満（ピースの数 × 0.3秒）の短さのときは、`profile_game_plays.time_verified` を false にして、ランキングの対象外にする**（遊んだ記録・自己ベスト・ごほうびはそのまま）。切り詰めはしない。
- **点数の改ざん**: 点数は、サーバーが答えから採点し直している（既存）。変更なし。
- **1回あたりの連続プレイ**: 既存のごほうびの回数制限は変えない。ランキングの対象は、制限に関係なく、終えた回すべて。
- **個人情報**: みんなに出るのは、ニックネーム・アバター・順位・記録だけ。プロフィールID・名前・レベル・町は出さない（API の返事にも含めない。テストで確かめる）。
- **やりとりなし**: コメント・スタンプ・フォロー・ほかの子の町へのリンクは、みんなのランキングには付けない。
- **アカウント削除・プロフィール削除**: 回の行も一緒に消える（既存の外部キー）ので、ランキングからも消える。
- **法務**: プライバシーポリシーに、「ランキングに載る情報」「保護者のスイッチ」を足す（`docs/ops` の法務【要入力】と合わせる）。

## 10. テスト

- 集計: 点数＝高い順／パズル＝短い順／同点は先に出したほうが上／プロフィールごとにベスト1回／週の境目（月曜0時＝日本時間）／別の家族・別のゲーム・別の級が混ざらない／記録のない人は載らない。
- 家族: 同じ家族だけ／自分が10位より下でも `me` が出る。
- みんな: Offの家族は載らない・見られない（403）／Onにすると載る／Offに戻すと、すぐ消える／自分の家族がOffなら、見られない。
- 設定: Onにするときパスワードが違えば 422（切り替わらない）／Offはパスワードなし。
- 返事の中身: プロフィールID・名前・レベルを含まない。
- 不正: 実測よりずっと長い時間は切り詰め／短すぎる時間は載らない／`elapsed_ms` のない回は、パズルの対象外。
- `finish` の返事に `rank_family` が付く。公開Offなら `rank_public` が付かない。

## 11. 今回やらないこと

- 順位に応じたごほうび・称号（不正の動機になる。いつか足すなら、別の設計）。
- みんなのチャット・スタンプ・フォロー。
- 期間ごとの履歴（先週の順位表）。必要になったら、週の締めに集計表へ書く。
- 地域別・学年別のランキング（個人情報に近づくため）。
