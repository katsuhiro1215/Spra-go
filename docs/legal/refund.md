# Spra Go 返金ポリシー（下書き）

> **下書きです。** 公開前にOwnerが確認し、必要に応じて専門家の確認を受けます。【要入力】の所はOwnerが埋めます。確認する点は `docs/legal/README.md` にまとめています。

かつコード（以下「運営者」）が提供する学習ゲーム「Spra Go」（以下「本サービス」）で購入したコイン（有償コイン）の返金について、次のとおり定めます。言葉の意味は、利用規約と同じです。

## 1. 返金の考え方

有償コインは、購入するとすぐにプレイヤーに付くデジタルのものです。そのため、次の「2. 返金するとき」と、法令で求められるときを除き、購入のあとの返金・取り消しはお受けしていません。

## 2. 返金するとき

次のときは、申し出を受けて確かめたうえで返金します。

| とき | 返金する金額 |
|---|---|
| 同じ購入で、二重に請求されたとき | 多く請求された分 |
| 支払いが終わったのに、有償コインが付かなかったとき | その購入の金額（付かなかったコインの分） |
| 本サービスの不具合で、購入した有償コインが使えなかったとき | 使えなかった有償コインの分 |
| 18歳未満のお子さまが、保護者の同意なく購入したとき | 法令（民法の未成年者の取り消し）に従って対応します。保護者からご相談ください【要確認: 返金する範囲は専門家に確認する】 |

- 付かなかった有償コインを、あとから付けて解決できるときは、返金の代わりにコインを付けることがあります（ご希望をうかがいます）。
- 返金したときは、返金した分の有償コインを、家族アカウントから差し引きます。

## 3. 申し出の方法

保護者から、次の窓口にメールでお知らせください。

- 窓口: 【要入力: お問い合わせ用のメールアドレス】
- お知らせいただくこと
  1. 家族アカウントに登録しているメールアドレス
  2. 購入した日時と金額（Stripeから届く領収書のメールがあれば、あわせてお送りください）
  3. 返金をご希望の理由

購入から【要確認: 30日】以内の申し出をお願いします。これを過ぎた場合も、法令で求められるときは対応します。

## 4. 返金の方法

返金は、購入に使った支払い方法（クレジットカードなど）に、決済サービスのStripeを通して戻します。カード会社によって、返金が反映されるまで日数がかかることがあります。現金や銀行振込での返金は行いません。

## 5. 家族アカウントの削除・本サービスの終了

1. 家族アカウントやプレイヤーを削除すると、残っていたコインはなくなり、返金はできません。削除の前に、使っていない有償コインがないかお確かめください。
2. 本サービスを終えるときは、使っていない有償コインを、法令に従って払い戻します。払い戻しの方法と期間は、終えるときにお知らせします。
