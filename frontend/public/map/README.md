# world.svg の出典

出典: Wikimedia Commons [BlankMap-World.svg](https://commons.wikimedia.org/wiki/File:BlankMap-World.svg)（パブリックドメイン、著作権者本人により権利放棄が宣言されている）。

- 各国は ISO 3166-1 alpha-2（小文字）を`id`とした`<path>`要素として個別に存在する（例: `id="jp"`, `id="us"`, `id="gb"`）。
- `svgo`（`cleanupIds`無効設定）でコメント・メタデータを除去し軽量化したもの（元ファイル: 約1.08MB → 約840KB）。パブリックドメインのため配布・改変は自由。
