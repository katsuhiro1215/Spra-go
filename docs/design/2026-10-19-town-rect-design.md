# 街づくり段階4a(長方形の建物の土台)— 設計書

- 作成日: 2026-10-19
- ステータス: **Ownerの指示で実装**(2026-10-19。「4aだけ進める」「家の成長(4c)はSpra Worldだけ。ゲーム性が異なるため」)。ブランチ `feature/town-shapes`
- 全体: `docs/design/2026-10-19-town-canvas-design.md` の段階4のうち、4a。4b(4×4以上の大きな建物)は、絵が届いたとき。4c(家の成長・地面のアップグレード)は、**Spra Goではやらない**

## 1. 目的

町のアイテムの大きさを、正方形(N×N)だけでなく、**長方形(幅×高さ。3×2など)**にできるようにする。今は長方形の絵がないので、**土台だけ**作る。絵が届いたら、設定を1行ずつ変えるだけで、長方形にできる。見た目も遊びも、今のまま変わらない。

## 2. 決まり

- 大きさの設定(`config/world.php` の `asset_footprints`): 数字は今までどおり N×N。**`[幅, 高さ]`** も書ける。幅は x の向き(右下)、高さは y の向き(左下)。(フロントの `art-keys.ts` の `ASSET_FOOTPRINTS` と必ず一致。テストで確かめる)
- **左右反転(今ある機能)が、そのまま「向きを回す」になる。** 等角の絵は、左右反転すると、x と y の向きが入れ替わる。長方形を反転すると、**幅と高さが入れ替わる**(3×2 ⇄ 2×3)。回転用の新しい絵は要らない。
- 置くマスは、(x, y) を奥のマスにして、幅×高さ。いまの向き(反転しているか)の大きさで調べる。
- 置いたまま反転するとき、新しい向きで置けるかを調べる。置けなければ422(「ひっくり返すと、ほかの物や道にぶつかるよ。」)で、向きは変わらない。バッグの中の物・正方形の物は、いつでも反転できる。
- API: 置き物・ショップ・ごほうびに、いまの向きの `w`・`h` を足す。`footprint` は、**長いほうの辺**(今までの意味。ごほうびの大きさの上限・にぎやか度・「大きな物」の判定)。
- 絵の縮尺・影・夜の光の位置は、**幅と高さの平均**(正方形は一辺。反転しても変わらない)。
- 重なり順は、手前のマス(x+w−1, y+h−1)。絵の真ん中は、幅×高さの真ん中。
- 引いた道・歩く・林や花畑のまとまり・`world:repair` は、同じ「いまの向きの大きさ」を使う。

## 3. 作ったもの

- サーバー: `ShopItem::size()`・`ProfileWorldItem::size()`、`WorldPlacement::tiles($x, $y, $w, $h)`・`check(..., $mirrored)`、反転のAPI、`world:repair`、`toWorldArray`・ショップ・ごほうびの `w`・`h`。
- 画面: `itemSize`・`footprintTiles`・`depthTile`・`footprintCenter`・`validAnchors`(幅×高さ)、`assetSize`(絵の大きさ)、描く物の一覧・プレビュー、ショップ・バッグ・ごほうびの大きさの表示(今までの「2×2マス」は、3×3の物にも付いていた不具合を、あわせて直した)。

## 4. 確認

- Pest `WorldRectTest`(10件): 大きさの書き方 / APIの `w`・`h` / 置くマス・重なり / 反転で入れ替わる・置けなければ422 / バッグ・正方形は反転できる / 反転した向きで置く / 引いた道 / `world:repair`。
- Vitest: `land`(幅×高さ)・`art-keys`(`[幅, 高さ]` の一致・`assetSize`)・`scene-model`(長方形・反転・プレビュー)・`gifts`。
- 画面(Playwright): パン屋を一時的に3×2として、置いた・反転した・置く場所の光(3×2がおさまる所だけ)を確認した。**今の設定は変えていない**(どの絵も、これまでの大きさのまま)。

## 5. 絵が届いたら

1. 絵を `tools/spru-assets/` で書き出し、`ITEM_ART_KEYS` に足す(いつもの手順)。
2. `config/world.php` の `asset_footprints` と、`art-keys.ts` の `ASSET_FOOTPRINTS` に、`'bakery' => [3, 2]` のように書く(2か所は一致させる)。
3. `world:repair --dry-run` で、置けなくなる物がないかを確かめてから、本番に出す。
- 絵の依頼文は、Spra Worldの試作 `showcases/spraworldsample/ready/`(3×2の店3種×4方向ほか)がそのまま使える。向きは、2方向(反転で入れ替わる)でも足りる。
