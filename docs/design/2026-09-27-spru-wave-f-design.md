## 1. 背景と目的

2026-09-26のコンセプト「学ぶほど世界が広がる」の②「レベルによる土地の解放と、新しい国への旅」の後半にあたる。E回で町が広がり、海辺の区画に桟橋ができた。F回では、その桟橋から船で国をめぐる「旅」と、旅先の国で学ぶともらえる「おみやげ」を作る。

- 学ぶ → レベルとポイント → 町のアイテム（旅じたく）→ 旅に出る → 旅先の国で学ぶ → おみやげを町に飾る → 次の国へ、という流れを作る
- 学ぶタブの国選びは今のまま全部開いておく（旅で学習を締めない）。旅は「その国で学ぶきっかけ」と「学んだ証を町に残す」ための仕組み

## 2. 決定事項（Owner確認済み）

| 論点 | 決定 |
|---|---|
| 旅でできること | **旅のハブ＋国の画面**。「旅する」タブに国の島が並び、行ける国へ出発する。着いた国の画面に、その国のステージの入口とおみやげが出る（E回9章） |
| おみやげの使い道 | **町に置けるアイテム**。ショップでは買えない、その国らしい置物・名所のミニチュア。置く・動かす・にぎやか度はほかのアイテムと同じ |
| おみやげの条件 | **1個目＝その国のステージを1つクリア（1マス）、2個目＝その国の初級のボスをクリア（2×2）**。次の国へ行くには前の国の2個目が要る |
| 旅の順番 | **1本道で5か国**: インドネシア → 韓国 → アメリカ → イギリス → フランス |
| 旅のじゅんび | **レベル＋町のアイテム＋前の国のおみやげ**（3-1の表）。町のアイテムは「持っている」（置いていてもバッグでもよい）で満たす |
| 作り方 | **設定ファイルに書く**（A案）。国の順番・条件・おみやげは `config/travel.php`。DBには「着いた国」と「受け取ったおみやげ」だけを持つ |
| 出発点・出発の場面 | 海辺の桟橋から船で出発する。リュックのスプル（mascot-7）の後ろ姿・走る姿を使う（E回9章） |

### 今後の方針（D回・E回から引き続き）

- コインで回すガチャ、コインで育つのを早める機能は作らない
- 有料の素材は使わない。アイテム・おみやげの絵は画面側でSVGで描く

## 3. 遊びのルール

### 3-1. 旅のルート

| 順 | キー | 行き先 | 必要レベル | 町のアイテム | 前の国のおみやげ |
|---|---|---|---|---|---|
| 1 | `id` | インドネシア | 7 | 小さな船 | なし |
| 2 | `kr` | 韓国 | 9 | 自転車 | インドネシアの「ボロブドゥール寺院」 |
| 3 | `us` | アメリカ | 11 | 大きな船 | 韓国の「仏国寺」 |
| 4 | `gb` | イギリス | 13 | お城 | アメリカの「自由の女神」 |
| 5 | `fr` | フランス | 15 | タワー | イギリスの「ストーンヘンジ」 |

- 国の状態は3つ
  - **着いた国**（`visited`）: 一度出発した国。以後いつでも行ける
  - **次の行き先**（`next`）: まだ着いていない国のうち、いちばん順の早い国（1つだけ）。旅のじゅんびがすべてそろうと出発できる
  - **まだ先の国**（`later`）: それより後の国。国名と国旗は見えるが、じゅんびリストは出さない
- 旅のじゅんびの3種類
  - レベル: 今のレベルが必要レベル以上
  - 町のアイテム: その絵（`asset_key`）のアイテムを1つでも持っている（町に置いていても、バッグに入っていてもよい）
  - 前の国のおみやげ: 前の国の2個目（初級ボスのおみやげ）を受け取っている
- 最初の旅（インドネシア）はLv.7で、海辺の区画（桟橋）が開くのと同じレベル
- 「今いる国」や移動にかかる時間は持たない。着いた国へは何度でも行ける
- 学ぶタブでクリアしたステージも、おみやげの条件に数える（クリアの記録は1つ）。ただし、受け取れるのはその国に着いてから

### 3-2. おみやげ

| 国 | 1個目（1マス、ステージを1つクリア） | 2個目（2×2、初級のボスをクリア） |
|---|---|---|
| インドネシア | コモドドラゴンの像（`komodo`） | ボロブドゥール寺院（`borobudur`） |
| 韓国 | トルハルバン（`dol_hareubang`） | 仏国寺（`bulguksa`） |
| アメリカ | バイソンの像（`bison`） | 自由の女神（`liberty`） |
| イギリス | 赤い電話ボックス（`phone_box`） | ストーンヘンジ（`stonehenge`） |
| フランス | エッフェル塔の置物（`eiffel`） | モン・サン=ミッシェル（`mont_saint_michel`） |

- 2個目は、どれもその国の初級ステージに出てくる名所（学んだ名所がおみやげになる）
- 条件の数え方
  - 1個目: その国（`stages.country_id`）のステージを、ジャンル・難易度を問わず1つでもクリアしている
  - 2個目: その国の、難易度が初級でボス（`is_boss`）のステージを、ジャンルを問わず1つでもクリアしている
- 受け取り方: 旅先の国の画面の「おみやげ屋さん」で［受け取る］を押す。バッグに入る（`profile_world_items`、置く場所は未定のまま）
- 1つのおみやげは1回だけ受け取れる。ショップでは買えない（非売品）

### 3-3. 新しい町のアイテム（旅じたく）

| 名前 | 絵のキー | 大きさ | 必要レベル | 値段 |
|---|---|---|---|---|
| 小さな船 | `boat_small` | 1マス | 7 | 200pt |
| 大きな船 | `boat_large` | 2×2 | 11 | 450pt |

- ふつうの町のアイテムとして売る（置き場所は区画で縛らない。海辺の砂浜に置くと自然に見える）
- ショップでは、旅のじゅんびに使うアイテム（小さな船・自転車・大きな船・お城・タワー）に「旅じたく」の札を出す。どれが旅じたくかは `config/travel.php` から決める

## 4. データとサーバー

### 4-1. テーブル

| テーブル | 内容 |
|---|---|
| `profile_trips`（新規） | `id`・`user_profile_id`（プロフィールが消えたら消す）・`destination`（行き先のキー、例 `id`）・`arrived_at`・`timestamps`。一意の制約（`user_profile_id`＋`destination`） |
| `profile_souvenirs`（新規） | `id`・`user_profile_id`（同上）・`souvenir`（おみやげのキー、例 `komodo`）・`received_at`・`timestamps`。一意の制約（`user_profile_id`＋`souvenir`） |

- 追加だけで、既存のデータは変えない。適用は通常の `php artisan migrate`（`migrate:fresh` は使わない）
- 行き先・条件・おみやげの中身はDBに持たない（設定ファイル）
- おみやげの町のアイテム（`shop_items`）は、そのおみやげを初めてだれかが受け取ったときに作る（スプルの花と同じ、`firstOrCreate`）。`type=decoration`・`price=0`・`currency=point`・`min_level=1`・`meta={asset_key, not_for_sale: true, souvenir_of: 国名}`

### 4-2. 設定

- `config/travel.php`（新規）

```php
'destinations' => [
    [
        'key' => 'id',
        'name' => 'インドネシア',
        'country_code' => 'id',          // countries.code（大文字・小文字は区別しない）
        'flag' => 'id',                  // public/flag/ のファイル名（DBの国コードは大文字小文字が不揃いなため）
        'min_level' => 7,
        'items' => ['boat_small' => '小さな船'],   // 旅じたく: 絵のキー => 名前
        'greeting' => ['text' => 'Selamat datang!', 'reading' => 'スラマット ダタン'],
        'souvenirs' => [
            ['key' => 'komodo', 'name' => 'コモドドラゴンの像', 'condition' => 'stage'],
            ['key' => 'borobudur', 'name' => 'ボロブドゥール寺院', 'condition' => 'boss'],
        ],
    ],
    // 韓国（kr / 환영합니다! ファニョンハムニダ / bicycle）
    // アメリカ（us / Welcome! ウェルカム / boat_large）
    // イギリス（gb / Hello! ハロー / castle）
    // フランス（fr / Bienvenue! ビアンヴニュ / tower）
],
```

- 並び順がそのまま旅の順番。「前の国のおみやげ」は、1つ前の行き先の `condition=boss` のおみやげ
- おみやげのキーは、そのまま絵のキー（`asset_key`）にする
- `config/world.php`
  - `asset_keys` に `boat_small`・`boat_large` を足す（管理画面のショップ編集の絵の選択肢にも増える）。おみやげの絵のキーは入れない（Ownerがショップで売れないようにする）
  - `asset_footprints` に `boat_large` と2個目のおみやげ5つ（`borobudur`・`bulguksa`・`liberty`・`stonehenge`・`mont_saint_michel`）を足す

### 4-3. サーバーの部品

| 部品 | 役目 |
|---|---|
| `Travel`（新規、`app/Support/Travel.php`） | 設定の行き先を読み、プロフィールごとの状態（着いた国・次の行き先・じゅんびリスト・おみやげの条件と受け取り）を計算する。出発とおみやげの受け取りを行う |
| `ProfileTrip`・`ProfileSouvenir`（新規モデル） | 4-1のテーブル。`UserProfile` に `trips()`・`souvenirs()` を足す |
| `ProfileWorldItem::toWorldArray()` | `souvenir`（おみやげなら true）を足す |
| `WorldItemSeeder` | 小さな船・大きな船を足す |

- 状態の計算では、クリアしたステージ（国・難易度・ボスか）、持っているアイテムの絵のキー、着いた国、受け取ったおみやげを、それぞれ1回のクエリで読む
- 国（`countries`）が見つからない行き先は、`country_id: null` で返し、おみやげの条件は満たさない（画面は壊れない）
- 出発とおみやげの受け取りは、トランザクションの中でプロフィールを `lockForUpdate` してから行う（連打しても二重にならない。一意の制約でも防ぐ）

### 4-4. API

- `GET /api/travel`（新規）: `{ level, destinations: Destination[] }`
  - `Destination` = `{ key, name, country_id, code, flag, min_level, state: 'visited'|'next'|'later', ready, checklist, souvenirs, gift_ready, greeting }`
    - `flag`: 国旗の画像のパス（例 `/flag/kr.svg`）。設定の `flag` から作る
    - `ready`: `next` で、じゅんびがすべてそろっている
    - `checklist`: `[{ kind: 'level'|'item'|'souvenir', label, done, hint }]`
      - レベル: 「レベル7」／ヒント「あと2レベル」
      - 町のアイテム: 「小さな船」／ヒント「Lv.7でショップに出るよ」か「ショップで買えるよ」
      - おみやげ: 「インドネシアのおみやげ『ボロブドゥール寺院』」／ヒント「インドネシアのおみやげ屋さんで受け取ろう」か「インドネシアの初級のボスをクリアしよう」
      - そろっているものは `hint: null`
    - `souvenirs`: `[{ key, name, asset_key, footprint, condition: 'stage'|'boss', condition_label, met, received }]`
      - `condition_label`: 「インドネシアのステージを1つクリア」「インドネシアの初級のボスをクリア」
    - `gift_ready`: `visited` で、条件を満たしてまだ受け取っていないおみやげがある
    - `greeting`: `{ text, reading }`
- `GET /api/travel/{key}`（新規）: その行き先1つ（形は同じ）。知らないキーは404、まだ着いていない国は422「まだこの国に着いていません。」
- `POST /api/travel/{key}/depart`（新規）: 出発する
  - 着いたことのある国なら何もせず `{ first: false, destination }`
  - `next` でない国は422「まだこの国には行けません。」、じゅんびがそろっていなければ422「旅のじゅんびがそろっていません。」
  - 出発できたら `profile_trips` に記録して `{ first: true, destination }`
- `POST /api/travel/{key}/souvenirs/{souvenir}`（新規）: おみやげを受け取る
  - 知らないキー・その国にないおみやげは404
  - まだ着いていない国は422「まだこの国に着いていません。」、条件を満たしていなければ422「まだ受け取れません。」、受け取りずみなら422「もう受け取っています。」
  - 受け取れたら、バッグに入れて `{ world_item, destination }` を返す
- `GET /api/world`: `travel_ready` を足す（次の行き先のじゅんびがそろっていれば `{ key, name }`、なければ `null`）。`items`・`bag` の各アイテムに `souvenir` を足す
- `GET /api/shop`: 各商品に `travel_gear`（旅じたくなら true）を足す
- 回答API・ステージクリア・購入・置く・家族の町のAPIは変えない（家族の町では、置いたおみやげがそのまま見える）

## 5. 画面

### 5-1. 旅のハブ（`/trip`、新規）

- ボトムナビの「旅する」の行き先を `/passport` から `/trip` に変える（パスポートはハブの右上のリンクから開く）
- 海の地図（`components/travel/travel-map.tsx`）: SVGで描き、スマホの幅にちょうど収まる（ドラッグは要らない）
  - 下に日本の島（はじまりの町・桟橋）、そこから点線の航路が上へジグザグに伸び、5つの島をつなぐ
  - 島の上に、国旗・国名・状態の札を載せたボタンを重ねる（ふりがなが付くよう、文字はSVGでなくHTML）
    - 着いた国: スタンプ・「おみやげ 1/2」。受け取れるおみやげがあれば「おみやげ！」の札
    - 次の行き先: 「じゅんび中」か「出発できる」。出発できるときは島が光る
    - まだ先の国: うす暗い島
  - 読み上げ用のラベル: 「インドネシア（出発できます）」「韓国（じゅんび中）」「アメリカ（まだ先）」「インドネシア（着いた国・おみやげ1/2）」
- 日本の島のスプルがひとこと言う（上から順に最初に当てはまるもの）
  1. 受け取れるおみやげがある国がある →「〇〇のおみやげ屋さんで、おみやげを受け取れるよ！」
  2. 次の行き先のじゅんびがそろっている →「じゅんびができたよ！〇〇へ出発しよう」
  3. 次の行き先がある → そろっていないものの最初について「次は〇〇！あと2レベルだね」「小さな船があれば〇〇へ行けるよ」「〇〇のおみやげがあれば△△へ行けるよ」
  4. 全部の国に着いた →「5つの国をぜんぶ旅したね！すごい！」
- 島を押すと、下からカード（`destination-sheet.tsx`）が出る
  - 次の行き先: 旅のじゅんびリスト（そろったものに✓、そろっていないものにヒント）と［出発する］（全部そろったときだけ押せる）
  - 着いた国: おみやげ2つの状態と［行く］
  - まだ先の国: 「前の国へ行ってからね」

### 5-2. 出発の場面（`departure-scene.tsx`）

- その国に初めて行くとき（`first: true`）だけ出す。全画面、約4秒、［とばす］あり
  1. 0〜1.2秒: リュックのスプルの後ろ姿（`outing/back`）が桟橋へ歩いていく
  2. 1.2〜2.8秒: 船が海を渡る（SVGの船が航路を進む）
  3. 2.8秒〜: 着いた国でスプルが走ってくる（`outing/run`）、「インドネシアに着いた！」。4.2秒で国の画面へ移る
- 動きを減らす設定のときは、3の場面だけを出す
- 2回目からは場面なしで国の画面へ行く
- ［出発する］で `POST /api/travel/{key}/depart` を呼び、成功してから場面を出す。失敗したらカードに理由を出す

### 5-3. 旅先の国の画面（`/trip/[key]`、新規）

- 上の段: 国旗・国名・その国のことばの「ようこそ」（例「Selamat datang!」、読み「スラマット ダタン」、「ようこそ」の意味）と、喜ぶスプル（`happy`）
- おみやげ屋さん（`souvenir-stand.tsx`）: おみやげ2つのカード（絵・名前・条件・状態）
  - 受け取れる →［受け取る］、まだ → 条件（「初級のボスをクリアしよう」）、受け取りずみ →「受け取りずみ」
  - 受け取ると、スプルが「バッグに入れたよ。町に置いてみよう！」と言い、バッグへのリンクを出す
- ステージの入口: その国の初級のステージの道（今の `StagePath` を使う）
  - 使うグループ: 初級で、ことばを学ぶモードでなく、ボスがあるグループ（なければ最初の初級のグループ）
  - その下に［もっと学ぶ（中級・上級）］→ 今の学ぶ画面（`/travel/[countryId]`）
- ［旅の地図へ戻る］→ `/trip`
- まだ着いていない国・知らない国を開いたときは、`/trip` へ戻す

### 5-4. ほかの画面

- 町: スプルを押したときのひとことに「旅のじゅんびがそろったよ！『旅する』から〇〇へ出発しよう」を足す（「畑に水をあげよう！」の次）
- ショップ: 旅じたくのアイテムに「旅じたく」の札
- バッグ: おみやげに「おみやげ」の札
- 家族の町: 置いたおみやげも見える（今のしくみのまま）
- 新しい画面は、ふりがな（`AutoFurigana`）・動きを減らす設定に対応する

## 6. 素材

- 町のアイテムの絵（SVG）: 小さな船・大きな船、おみやげ10個を新しく描く。`components/world/travel-art.tsx`（新規）に置き、`item-art.tsx` の絵の一覧に合わせる。今ある箱・屋根の描き方（`IsoBox`・`IsoRoof`）は `components/world/iso-shapes.tsx` に移して共有する

## 7. テスト

### バックエンド（Pest）

- ハブ
  - 行き先が5つ、設定の順に返る。Lv.1では、インドネシアが `next`（`ready: false`）、ほかは `later`
  - インドネシアのじゅんびリスト: レベル（「あと6レベル」）、小さな船（「Lv.7でショップに出るよ」）
  - Lv.7で小さな船を持っている（バッグでも町に置いていても）と `ready: true`
- 出発
  - じゅんびがそろっていなければ422、そろっていれば記録されて `first: true`、2回目は `first: false`（記録は1つ）
  - `later` の国（韓国）は、レベルが足りていても422
  - インドネシアに着いた後、韓国のリストに「ボロブドゥール寺院」（受け取るまで未）・自転車・Lv.9が並ぶ
  - ほかのプロフィールの記録は数えない
- おみやげ
  - 着く前は422、条件を満たしていなければ422
  - その国のステージを1つクリアすると1個目を受け取れる（着く前にクリアしていても数える）
  - 2個目は初級のボスでだけ満たす（中級のボス・初級のふつうのステージでは満たさない）
  - 受け取ると、バッグに入り、絵のキーが付き、2個目は `footprint` 2、`souvenir: true`。2回目は422
  - 知らないキー・その国にないおみやげは404
  - `gift_ready` が、受け取れるおみやげがあるときだけ true
- `GET /api/travel/{key}`: 着く前は422、着いた後は `greeting` 付きで返る
