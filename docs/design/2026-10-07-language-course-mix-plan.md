# 言語コースの出し方 実装計画

> 実行する人へ: 実行方法はネイティブ（CEOがインラインで実装し、最後に自分で見直す）。テストを先に書き、失敗を見てから実装する（RED → GREEN）。

**目的:** 言語コースで、単語中心・文章を少しずつ増やし、答えたことのある単語を優先して出す。

**設計書:** `docs/design/2026-10-07-language-course-mix-design.md`（Owner合意済み）

**ブランチ:** `feature/language-mix`。計画のコミットは #00491、タスクは #00492 から。

## 全体の決まり

- テスト: サーバー `./vendor/bin/sail test`、画面は今回触らない。開発DBは `migrate:fresh` を使わない（`course:build` を再実行して反映）。
- コメントは理由が分かりにくい所に1行だけ。コミットは `#番号: type:要約`、末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`。

## 計画時の判断

1. **言語コースのボス以外のステージでは、「前回の問題から5問を残す」決まりを使わない。** 文章・単語の割合を守るのを優先するため（残すと割合が崩れる）。ボスは今まで通り、先頭5問を固定し、残りを選ぶ（割合なし）。
2. **「答えたことのある問題」は、`profile_question_memories` に行がある問題**（ミニゲームでもメインでも）。出どころの区別は付けない。
3. **種類の印は `questions.meta.kind`**。付いていない問題は `word`。

## タスク

### タスク1（#00492）: 問題に種類（word / sentence）を付ける

**ファイル:** `app/Support/CoursePoolBuilder.php`（`buildLanguages`）、`config/courses.php`。テスト `tests/Feature/LanguageCourseTest.php` に追記。

**設定:** `config/courses.php` に `'language_kind_by_theme' => ['vocabulary' => 'word', 'phrase' => 'sentence', 'grammar' => 'sentence']`。

**振る舞い:** `buildLanguages` が、プールにまとめる問題ごとに、元のステージの `question_theme_id`（`QuestionTheme.key`）から種類を決め、`questions.meta.kind` に書く（既存の `meta` は残す）。同じ問題が複数のステージにあるときは、先に見つかった種類。テーマが分からない問題は `word`。

### タスク2（#00493）: 割合と、答えたことのある問題の優先

**ファイル:** `app/Support/StageDraw.php`、`config/courses.php`。テスト `tests/Feature/StageDrawTest.php`（または新規 `LanguageDrawTest.php`）。

**設定:**

```php
'language_mix' => [ // 級 => [ステージ1の文章の割合(%), ステージ7の文章の割合(%)]
    '初級' => [10, 30],
    '中級' => [20, 40],
    '上級' => [30, 50],
],
'learned_share' => 70, // 言語コースで、答えたことのある問題を先に選ぶ割合(%)
```

**振る舞い:**
- `StageDraw::sentencePercent(Stage $stage): ?int`（新）: ボス（最後のステージ）は `null`。そうでなければ、`language_mix[級]` の [ステージ1, ステージ7] の間を直線でつなぎ（n=1〜7）、n≥7 は ステージ7の値。四捨五入した整数。例: 初級 n=1→10、n=4→20、n=7→30、n=9→30。
- 言語コースのステージ（`category.is_language_mode` かつ `country_id` が null）では `pick` が別の選び方（`pickLanguage`）を使う。それ以外は今のまま。
- `pickLanguage`（ボス以外）: N = `playCount()`、文章 `round(N × 割合/100)`、単語 `N − 文章`。各種類の中の選び順: ① まちがえた問題（`wrong_on` が新しい順。全体で最大 `wrong_max`）→ ② 答えたことのある問題（ランダム。その種類の必要数の `learned_share`% まで）→ ③ まだ答えていない問題（ランダム）→ ④ 残りの答えたことのある問題。ある種類が足りないときは、もう一方の種類で埋める。結果は N 問。
- ボス: 先頭5問を固定（今のまま）。残りは、プール全体（種類を分けず）を、上の ①〜④ の順で選ぶ。
- どちらも結果を `profile_stage_draws` に保存し、`arrange`（同じ問題文が続かない並べ替え）を通す。

- [ ] **1. 失敗するテストを書く:** 言語コースの初級（N=10）で、文章の数が ステージ1＝1問・ステージ4＝2問・ステージ7＝3問（プールに単語・文章が十分ある）。中級ステージ1＝2問、上級ステージ1＝3問。`sentencePercent` の値（初級 1→10・4→20・7→30・9→30、ボス→null、中級 1→20・7→40）。ボスは種類の制約なしで N 問・重複なし・先頭5問を含む。答えたことのある単語が優先される（単語9問のうち7問以上が、答えたことのある単語。プールに答えたことのある単語が十分あるとき）。答えたことのある単語が少ないときは、新しい単語で埋まり、N 問になる。文章が足りないときは単語で埋まる。まちがえた問題は先に入る（最大3問）。国のコース（国旗）の抽選は変わらない（既存のテストが守る）。
- [ ] **2. 失敗を確認 → 実装。**
- [ ] **3. 全体のテスト → コミット。**
