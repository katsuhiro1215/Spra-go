## 1. 目的

- Spra Goに、**反射神経で遊ぶ、スピード感のあるゲーム**を1本足す。クイズとは違うテンポの「息抜き」にする。
- **期間限定**で出し、その間は、**コインがいつもより多く**手に入る。「今だけ」の楽しみで、アプリを開く理由を作る。
- 走る・ジャンプする・集める・ぶつかる・点数・ランキングの**骨組み**を作る。あとで「クイズラン」(2つのレーンから正解に飛び込む)を、モードとして足せるようにする。

**うまくいった目安**
- 説明を読まなくても、タップするだけで、5歳の子が遊べる。
- 1回が、30秒〜2分くらいで終わる(だんだん速くなって、いつかはぶつかる)。
- もう1回やりたくなる(ベストの更新、ランキング)。
- 1日にもらえるコインに上限があり、クイズで学ぶ時間を、奪いすぎない。

## 2. 遊び方

| 項目 | 内容 |
|---|---|
| 走る | スプルは、自動で右へ走る。画面は横に流れる |
| ジャンプ | 画面のどこでもタップでジャンプ。空中で、もう1回タップすると2段ジャンプ(キーボードは スペース・↑) |
| じゃまもの | 低いもの(石・切り株・水たまり)は、1回のジャンプでこえる。高いもの(しげみ・さく)は、2段ジャンプでこえる |
| タネ | 地面に並ぶタネと、ジャンプの弧の上に浮かぶタネ。ときどき**金のタネ**(タネ5個分) |
| ハート | 3つ。じゃまものにぶつかると1つ減り、1.5秒だけ点滅して、ぶつからない。0になったら終わり |
| 速さ | 始めはゆっくり。10秒ごとに少しずつ速くなる(上限あり) |
| 点数 | 走った距離 1m = 1点、タネ1個 = 10点(金のタネは50点) |
| 終わり | 走った距離・タネ・点数・ベスト・家族のランキングの順位・もらったコインを見せる。「もう1回」と「もどる」 |

- **終わり方は、エンドレス**(ゴールなし)。速くなり続けるので、いつかはぶつかる。上手な子ほど長く走れて、ランキングの差が出る。
- **難しさは1つ**(「ふつう」)。速さが上がることで、難しさの坂道になる。ランキングも1つにまとまる。
- 始める前に「3・2・1」と「タップでジャンプ！」の一言。やめるボタン(確かめつき)は、うちゅう旅行と同じ。

### 2-1. 動きの数字(初めの値。試作で、Ownerが触って調整する)

画面の大きさによらず同じ遊びになるよう、ゲームの中では、**横400×縦300の広さ**で計算し、画面に合わせて拡大する。

| 項目 | 初めの値 |
|---|---|
| 速さ | 始め 220 / 上限 420(1秒に進む広さ。40 = 1m)。10秒ごとに +15 |
| ジャンプ | 1段目の高さ 約120、2段目で さらに約90。空中にいる時間 約0.7秒 |
| じゃまものの高さ | 低い 30〜50、高い 110〜140 |
| じゃまものの間かく | 「今の速さで、1回ジャンプして着地し、少し走れる長さ」より短くしない(かならず、こえられる並びにする) |
| 当たりの大きさ | 絵より小さめ(スプルは見た目の7割)。かすっただけでは、ぶつからない |

## 3. ごほうび

| 項目 | 内容 |
|---|---|
| もらえるもの | **コインだけ**。学習ポイント・経験値は出さない(学習ポイントは「学んだしるし」なので、学びと関係のないゲームでは出さない) |
| 量 | タネ1個 = コイン1枚(金のタネは5枚)。**1回の上限は60枚** |
| 回数 | **1日3回まで**、ごほうびが出る。4回目からは練習(記録とランキングには残る) |
| 1日の最大 | 180枚 |
| ほかのミニゲームとの関係 | 全ゲームの合計の上限(1日6回)には**数えない**。学びのミニゲームのごほうびを減らさないため。「今週のミニゲーム」(1.5倍)の順番にも入れない |
| HP | 使わない(ほかのミニゲームと同じ) |

- 目安: ステージを1回クリアすると、約125枚(正解15問×5枚+クリア50枚)。航空券は200枚、回復薬は50枚。1日180枚は、「ステージ1回と少し」で、イベントの間は、航空券がいつもより早く買える。
- コインは、お店でも買える(100枚120円)。**1日の上限と、期間限定**であることで、買うコインの値打ちを、崩しすぎないようにする。

## 4. 期間限定の出し方

- ミニゲームの出し分け(`catalog`)に、**終わる日 `ends_on`** を足す。`released_on`(始まる日)から `ends_on`(終わる日。その日を含む)までだけ、一覧に出て、遊べる。期間の外は、一覧に出ず、APIは404。今ある `season`(毎年くり返す期間)とは別に、**1回きりの期間**を表す。
- 一覧と学ぶ画面のお知らせに、「**期間限定**」の札と「**あと◯日**」を出す。始まった日から、今ある「NEW」のお知らせも出る。
- 期間が終わったら、隠す。**次のイベントでは、背景とじゃまものの絵を変えて**(日本の町、宇宙など)、また出せる作りにする(絵のセットを「テーマ」として差し替える)。
- 期間の日付は、設定ファイルで決める(配信し直さなくても、日付で出て、日付で消える)。
- 参考: 管理画面の「イベント」(`events`)は、期間ラベルだけの器で、プレイヤーには出ていない(`SPEC.md`)。今回は、ミニゲームの設定で済ませ、イベントの器とはつながない。

## 5. 画面

- 縦長のスマホで遊ぶ。上に、点数・タネ・ハート・やめる。まん中に、**横長のゲームの場面**(横400×縦300の比率)。その下は、どこを押してもジャンプになる広い場所。
- **試作の絵**: スプルは、今ある絵(走る `run`・ジャンプ `jump`・びっくり `startled`)を使う。じゃまもの・タネ・背景は、仮の図形と色で描く。
- **本番の絵**(ChatGPTで作る。依頼文は、この設計書の承認後に私が用意する):
  - スプルの横向き: 走る(2〜4コマ)・ジャンプ・ぶつかった
  - じゃまもの: 石・切り株・水たまり・しげみ・さく(各1枚)
  - タネ・金のタネ
  - 背景: 空・遠くの山・近くの草はら の3枚(横につなげても、つなぎ目が見えない絵)と、地面
- 背景は、遠いものほどゆっくり流す(奥行きが出る)。
- **動きを減らす設定**(端末の設定)のとき: 背景の流れを止める。ゲームそのものは動く。
- 音: ジャンプ(`select`)、タネ(`coin`)、ぶつかった(`warning`)、終わり(`allCorrect`)。BGMは、ミニゲームのBGMを使う。

### 6-3. ずるの防ぎ方

ゲームは画面の中で動くので、点数を、画面から送られたまま信じない。

- 点数は、**サーバーが**、距離とタネから計算し直す。
- サーバーが、「回を始めた時刻」から「終えた時刻」までを測る。**距離は「最高の速さ × その時間」以下**、**タネは「1秒に出るタネの上限 × その時間」以下**でないと、受け付けない(記録にも、ランキングにも、ごほうびにも入れない)。
- 1回の上限(60枚)と、1日3回の上限があるので、ずるをしても、もらえるコインには限りがある。
- コースは種で決まるので、あとで「押した時刻の並び」を送ってもらい、サーバーで同じ動きを再現して確かめる形にも、広げられる(今回はしない)。
