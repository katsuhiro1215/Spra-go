# スプルスイム(スプルランに続く、泳ぐミニゲーム)— 設計書

- 作成日: 2026-11-10
- ステータス: 段階1(試作)・段階2(サーバー・経済・ランキング)とも実装済み(2026-11-10)。10章に追記
- きっかけ: スプルランが好評だったので、似た骨組みで新しいミニゲームを作る。Ownerの案:「Spruが泳いでいくゲーム。タップで上昇、何もしないと沈む。障害物を避けながらコインをとる」
- 前提: スプルランの仕組み(`docs/design/2026-10-22-spru-run-design.md`)をそのまま流用する。**遊びの骨組み(純粋なエンジン関数＋画面が描くだけ)は、スプルランと同じ形**にする。いちばん近い作りはスプルラン

## 1. 目的

- スプルランと同じ「反射神経で遊ぶ、スピード感のある」ミニゲームを、水中テーマで1本足す。操作感はスプルランの「タップでジャンプ」ではなく、**押している間だけ上昇する**(Flappy系)。
- 集めた「コイン」は**専用の通貨**とし、ブラックフライデーのイベント時に、本物のコイン・景品に交換できるようにする。

## 2. 遊び方

| 項目 | 内容 |
|---|---|
| 泳ぐ | スプルは、自動で右へ進む。画面は横に流れる |
| 浮く・沈む | 画面を押し続けている間は上昇、離すと沈む(重力)。スプルランの「タップでジャンプ」とは違う操作感 |
| じゃまもの | 海の生物(くらげ・うに・タコの足など)。上下から対になって迫り、間のすき間をくぐる |
| コイン | すき間・通り道にコインが浮かぶ。ときどき大きい/光るコイン(複数枚分) |
| ハート | 3つ。ぶつかる・水面を出る・海底に沈みきると1つ減り、スプルランと同じ無敵時間(点滅)。0になったら終わり |
| 速さ | スプルランと同じく、だんだん速くなる(上限あり) |
| 終わり方 | エンドレス(ハート0で終了) |

- 「どの並びも、押す・離すのタイミングでかならずこえられる」ことを、スプルランの `minGapAfter`・お手本の子のテストと同じ考え方で保証する(6章)。
- 水の中なので、**タネではなくコイン**(呼び名は「スイムコイン」。スプルランの「ランのタネ」と同じ、ゲーム専用の通貨)。

## 3. ごほうび(経済)— Owner確認済み(2026-11-10)

スプルランが「コインは出さず、専用の『ランのタネ』にする」と決めた経緯(コインは実際にお金で買えるので、ゲームで大量に出すと購入コインの価値が崩れる)と、**同じ考え方**を採る。

- 専用の通貨「スイムコイン」(仮称。`swim_coin`)。本物のコイン・学習ポイント・経験値・ランのタネとは別の財布
- **ブラックフライデーのイベント時に、本物のコイン・景品と交換できるようにする**(交換所の作り方は、スプルランの「タネ交換所」と同じ形。`profile_currency_ledger` に通貨 `swim_coin` を足す)
- 具体的な量・1日の上限・交換レートは、**段階2(サーバー)の設計時に、Ownerと改めて決める**(スプルランの14章と同じ進め方)

## 10. 段階2: 本番実装の記録(2026-11-10)

スプルラン(`app/Support/RunGame.php`・`14章`)とまったく同じ設計パターンで複製した。

**バックエンド**(`Spra-go` リポジトリ直下。Laravel):
- `App\Support\SwimGame`(`RunGame.php` の複製): `GAME = 'spru_swim'`。`summary()`/`start()`/`abandon()`/`finish()` を同じ形で実装
  - チート対策: `finish()` はクライアント申告の距離・コイン数を、サーバー側で `started_at` からの経過時間をもとに再計算した理論上限(`maxDistanceM`/`maxCoinValue`)と比較し、超えていれば422で拒否。スプルランの加速する速さと違い、**スイムは速さが一定**(`SWIM_SPEED=170px/秒`)なので、上限式はそのぶん単純
  - `max_coin_value_per_sec` は `swim-engine.ts` の `MAX_COIN_VALUE_PER_SEC`(=20)と同じ値。`score` の計算式(距離×2+コイン×2)も `scoreOf()` と同じ
- `config/games.php` に `spru_swim` ブロックを追加(`.env` の `SPRU_SWIM_RELEASED_ON`/`SPRU_SWIM_ENDS_ON` で公開日を制御。デフォルトは未公開)
- `routes/api.php` に `games/spru-swim`(summary・ranking・plays start/abandon/finish)を追加。ミドルウェアは既存の `EnsureGameAvailable` をそのまま使用
- `UserProfile::applyEconomy()` に `swim_coin` の分岐を追加。財布は `user_profiles.swim_coins`(マイグレーション `2026_11_10_000001_add_spru_swim_columns.php`)。**コイン・経験値・学習ポイント・ランのタネとは完全に別管理**(3章の方針どおり)
- `App\Support\GameRollout` に `SWIM_PATH = 'spru-swim'` を追加(スプルランと同様、今週のゲームの抽選対象には入れない)
- `tests/Feature/SwimGameTest.php`(`RunGameTest.php` の複製。14件)。バックエンド全体テスト(1274件)も確認し、既存テストへの影響なし

**フロントエンド**(`frontend/src/components/games/swim/` ・ `frontend/src/app/games/spru-swim/`):
- `swim-api.ts`・`swim-flow.ts`(`run-api.ts`・`run-flow.ts` の複製)
- `swim-game.tsx`: `mode`("practice"|"real")・`ceiling`(本番はサーバー値)・`onQuit(state, sinceStartMs)` に対応。`ceilingForScreen()` を export
