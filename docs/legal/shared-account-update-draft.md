## 専門家に見てほしい点
1. 「関連アプリ」という言い方と、規約の適用関係（第7条の2 第2項）で、足りないところがないか。
2. 子どもの情報をアプリごとに分けて保存する、という書き方が、個人情報保護法・子どもの情報の扱いの考え方に合っているか。
3. 「どのアプリを使っているか」の記録を、プライバシーポリシーの目的（第3章）にどう書くのがよいか（いまは特典・お知らせに使わない前提）。
4. 既存の利用者に、画面で「同意する」を押してもらう方法（同意の取り直し）で足りるか。変更の事前告知の期間は要るか（規約第14条との関係）。
5. Tane（運営者が別に配信する静的サイト）のアクセスログ（IPなど）の扱いを、第5章（処理を任せる会社）に足す必要があるか（Tane も同じ AWS・同じサーバー）。

## 修正: 利用規約（`terms.md`）

### 第7条の次に、新しい条を足す

```
## 第7条の2（Spraのほかのアプリとアカウントの共通化）

1. 運営者は、本サービスのほかに、「Tane」など、運営者が提供するアプリ（以下「関連アプリ」）を提供します。家族アカウントは、同じメールアドレスとパスワードで、関連アプリでも使えます。
2. 関連アプリを使うときも、本規約とプライバシーポリシーが適用されます。関連アプリごとに別の定めがあるときは、その定めを優先します。
3. プレイヤーの学習とゲームの記録は、アプリごとに別々に保存します。ほかのアプリの画面には表示しません。
4. 家族アカウントを削除したときは、本サービスと関連アプリの、すべての記録が消えます。
```

（Owner決定により、「どのアプリを使っているかをもとにした、お知らせや特典の案内」の項は入れない。）

### 3. 使う目的
次の2つを足す（番号は続けて）。
```
- 関連アプリ（Tane）の保護者の画面に、プレイヤーの記録を表示するため
- どのアプリが使われているかを、サービス全体の統計として知り、サービスを良くするため（個人がわからない形にまとめます）
```
（「お知らせや特典に使う」は、Owner決定により書かない。）

### 7. 保存する期間
1. の「家族アカウントとプレイヤーの情報、学習とゲームの記録は」を「家族アカウントとプレイヤーの情報、本サービスと関連アプリの学習とゲームの記録は」に直す。

### 8. クッキー
項目を足す:
```
3. 関連アプリ（Tane）は、クッキーのかわりに、ブラウザの保存領域に、ログインを続けるための印と、遊んだ記録を保存します。広告やアクセスの分析には使いません。
```

### 新しい章（13章のあとに足す）
```
## 14. 関連アプリとの共通アカウント（制定日以降）

1. 家族アカウント（メールアドレス・パスワード）は、本サービスと、運営者が提供する関連アプリ（Tane）で共通です。
2. 学習とゲームの記録は、アプリごとに別々に保存し、アプリをまたいで混ぜません。運営者が、アプリをまたいで見るのは、「どのアプリを使っているか」と、使い始めた日・最後に使った日だけです。
3. 関連アプリ（Tane）の記録は、同じ家族アカウントの保護者だけが、保護者の画面で見られます（パスワードの入れ直しで確かめます）。ほかの家族アカウントの利用者には見せません。
4. 家族アカウントを削除すると、本サービスと関連アプリの、すべての記録を遅滞なく消します（法令で保存が求められるものを除きます）。
5. 関連アプリ（Tane）でも、お子さまの情報を、広告や、ほかの会社への提供のために使いません。
```
