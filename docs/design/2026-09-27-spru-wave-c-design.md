# 相棒・仲間の成長・仲間からの復習問題（C回）— 設計書

- 作成日: 2026-09-27
- ステータス: Owner合意済み（設計の各区切りを対話で確認）
- 前提: `docs/design/2026-09-26-world-town-design.md`（町・ポイントで買って置く）、`docs/design/2026-09-26-spru-wave-a-design.md`（表情・ポーズ・演出・時間帯と季節）、`docs/design/2026-09-27-spru-wave-b-design.md`（成長サイクル・水やり・仲間の誕生）。すべて実装済み

## 1. 背景と目的

A〜Eの5回で作る「仲間と成長」の3回目（A回の設計書1章の表を参照）。B回で生まれた仲間に役目を持たせ、毎日開く理由を増やす。仲間が「前にまちがえた問題」を出してくれることで、復習が自然に遊びの中に入る。これが、ワールド画面の設計書でいう③「復習を混ぜた出題（今日のレッスン）」の代わりになる。

- ループ: 学ぶ → 相棒のなかよし度が上がる → 次の日、相棒が「この前まちがえた問題」を出してくれる → 復習をやりきると、相棒ともっとなかよしになる
- 解いた直後にも、まちがえた問題だけをもう一度解ける（Ownerの提案。その場で「できた！」で終わらせるため）

## 2. 決定事項（Owner確認済み）

| 論点 | 決定 |
|---|---|
| 成長と相棒 | **相棒だけが育つ**。生まれた仲間から相棒を1人選ぶ。相棒でいる間に正解すると、その仲間の「なかよし度」が上がる。相棒を替えれば別の仲間も育てられる |
| 名前 | **子どもが自由に付ける**（1〜8文字、あとから変えられる。付けなければ元の名前）。見えるのは同じ家族アカウントの中だけ |
| 育ちの見せ方 | **ハート（最大5つ）＋新しいひとこと**。仲間の絵は1人1枚のため、絵は変えない。仲間ごとの表情・ポーズ集ができたら、絵の変化を後から足す |
| 復習の出し方 | **1日1回・最大5問**。まちがえた問題が残っていると、町で相棒の上に「！」が出る |
| 仲間がいないとき | **スプルが復習を出す**。相棒が決まったら相棒の役目になる |
| 解いた直後のやり直し | **C回に入れる**。結果の画面から、まちがえた問題だけをもう一度。ごほうびなし・HPも減らない。仲間の復習からは消えない |
| 作り方 | **クイズ画面の出題部分を共通の部品に切り出し**、ステージ・仲間の復習・やり直しの3つで使う |

### 今後の方針（B回から引き続き）

- コインで仲間を育てる・なかよし度を買う機能は作らない
- 仲間ごとの表情・ポーズ集は素材待ち（TASKS.md）

## 3. 遊びのルール

### 3-1. 相棒えらび

- 相棒は1人だけ。生まれた仲間から選ぶ
- **最初の仲間が生まれたとき**は、サーバーがその仲間を自動で相棒にする。お祝いの後に名前を付ける画面を出す（5-3）
- 2人目からの仲間は、生まれても相棒は替わらない。お祝いに「町でタップすると、相棒にできるよ」と添える
- 町で仲間をタップすると出る仲間のカード（5-2）から「相棒にする」で替えられる
- 相棒を替えても、なかよし度と名前は仲間ごとに残る
- 立ち位置: 相棒を先頭に、ほかの仲間は生まれた順に、仲間の立ち位置（`config/world.php` の `companion_spots`）を前から使う。先頭の (0,3) はスプル (1,3) の隣の道のマス。最初の仲間は自動で相棒になるので、相棒を替えない限り今の並びは変わらない

### 3-2. 名前

- 1〜8文字。前後の空白は取り除く。改行・タブなどの制御文字は入れられない
- 空にすると、元の名前（Lumiなど）に戻る
- 何度でも変えられる
- 名前が出るところ: 町の吹き出し・仲間のカード、復習の見出し、クイズのなかよし度のお祝い、復習の結果
- 見えるのは同じ家族アカウントの中だけなので、不適切な言葉のチェックはしない（D回の「家族の町を見に行く」も同じ家族アカウント内だけ）

### 3-3. なかよし度（ハート）

- 仲間ごとに「なかよし度」（数、0から）を持つ。ハートの数はなかよし度から計算する（保存しない）

| ハート | 呼び方 | 必要ななかよし度 |
|---|---|---|
| 1 | はじめまして | 0（生まれたとき） |
| 2 | なかよし | 20 |
| 3 | とってもなかよし | 50 |
| 4 | だいすき | 100 |
| 5 | しんゆう | 180 |

- 増え方:
  - 相棒でいる間に、ステージか復習で正解すると +1（難しさにかかわらず）
  - 仲間の復習をやりきると、相棒に +5（スプルが出した復習では誰にも足さない）
  - やり直しの正解では増えない
- 目安: 毎日20問ほど正解する子で、10日ほどでハート5つ
- ハート5つの後も数は増える（ハートは5つのまま）
- ハートが増えたとき: 正解の画面（または復習の結果の画面）で「〇〇とのなかよし度が上がった！」＋ハート＋新しいひとことを出す

### 3-4. ひとこと

- 仲間1人につき5つ。ハートの数だけ覚えている（ハート1つなら1つ目だけ）。1つ目はB回のひとこと
- 町でタップしたときは、覚えたひとことからランダムに1つ話す。生まれたときのお祝いは1つ目

### 3-5. 仲間からの復習

- **復習に出る問題**: ステージか復習でまちがえて、その後にまだ正解していない問題。答えの記録（`profile_currency_ledger`）の `answer_correct`・`answer_wrong` のうち、問題ごとに一番新しい記録が `answer_wrong` のもの
  - 同じ記録にある `combo_milestone`・`streak_milestone` などは見ない
  - 消された問題（記録の `question_id` が null）は出ない
  - やり直しは記録を残さないので、判定に影響しない
- **出す数と順**: まちがえたのが古い順（一番新しい `answer_wrong` の記録が古い順）に最大5問
- **「！」が出る条件**: 復習に出る問題が1問以上ある、かつ今日（日本時間）の復習をまだやりきっていない
- **出すのは**: 相棒。相棒がいなければスプル
- **始め方**:
  - 相棒が出すとき: 相棒をタップすると出る仲間のカードの一番上に「この前まちがえた問題、いっしょにやってみよう！（3問）［やってみる］」
  - スプルが出すとき: スプルをタップすると、同じ見た目の小さな復習カード（［やってみる］［あとで］）
  - ［やってみる］で復習の画面（`/review`）へ
- **答えたとき**: ふつうのステージと同じ（XP・学習ポイント・コイン、HPが減る、コンボ・連続日数、水やりの条件、なかよし度+1）。ステージクリアのごほうびは無い
- **やりきる**: 最後の問題まで答えると、今日の復習をやりきった記録を付け、相棒に+5
- **途中でやめたとき**: やりきった扱いにならず、また「！」が出る。正解した問題はもう出ない
- やりきった日は、その後にまちがえた問題が増えても「！」は出ない（次の日に出る）

### 3-6. 町のタップとスプルのひとこと

- スプルをタップしたとき（上から順に）:
  1. 寝ている → 起きる（A回どおり）
  2. 種がまける → 種まき（B回どおり）
  3. スプルが復習を出す日で「！」が出ている → 復習カード
  4. それ以外 → A回・B回どおりの反応
- スプルのふだんのひとことの優先順（B回の畑の案内に足す）:
  1. 種がまける: 「花が咲いたよ！タップして種をまこう」
  2. 今日の水やりができる: 「芽に水をあげよう！」
  3. 相棒が復習を出す日: 「〇〇が復習を用意してるよ」
  4. スプルが復習を出す日: 「この前の問題、いっしょに復習しよう！」
- 仲間をタップしたとき: 今までどおり跳ねて吹き出し（名前と、覚えたひとことから1つ）が3秒出て、仲間のカードが開く

### 3-7. 解いた直後のやり直し

- ステージと復習の結果の画面に、まちがえた問題があれば［まちがえたN問に もう一度チャレンジ］を出す（押すかは子どもが決める）
- まちがえた問題だけを、選択肢の順番を入れ替えて出す（問題そのものは最初に出したものを使う）
- やり直しの回答では、XP・学習ポイント・コイン・HP・コンボ・連続日数・なかよし度が変わらず、水やりの条件にもならない。HPが0でも遊べる
- やり直しでもまちがえた問題があれば、結果の画面からもう一度挑戦できる
- 仲間の復習に出る問題は変わらない（答えを見た直後の正解なので、次の日に仲間の復習で確かめる）
- ステージのクリアの記録と点数は、最初に解いたときのまま（やり直しでは送らない）

## 4. データとサーバー

### 4-1. テーブル

| テーブル | 変更 |
|---|---|
| `profile_companions` | `nickname`（string 8文字、null可。nullなら元の名前）、`bond`（なかよし度、unsigned int、既定0）を追加 |
| `user_profiles` | `partner_companion_key`（相棒の仲間のキー、string 32、null可）、`last_review_on`（復習をやりきった日、日本時間の日付、null可）を追加 |

- 相棒は外部キーにしない。プロフィールと仲間がお互いを指す形になり、プロフィールを消すときに削除の連動が循環するため。今の `companion_key` と同じくキーで持ち、「生まれた仲間か」は処理側で確かめる
- 更新時に、仲間がいて相棒がいないプロフィールは、最初に生まれた仲間（`profile_companions` の id が一番小さいもの）を相棒にする
- 「まちがえたままの問題」は列を作らず、答えの記録から求める（3-5）。今ある `user_profile_id` の索引で足りるため、索引は足さない

### 4-2. 設定

- `config/companions.php`:
  - 仲間の一覧の `line` を `lines`（5つ、3-4の表）に置き換える
  - `bond_hearts`: `[0, 20, 50, 100, 180]`（ハートn個に必要ななかよし度。n−1番目）
  - `heart_labels`: `['はじめまして', 'なかよし', 'とってもなかよし', 'だいすき', 'しんゆう']`
  - `bond_per_correct`: 1、`review_bonus`: 5
  - `review_size`: 5
  - `nickname_max`: 8
- `config/world.php`: 変更なし（`companion_spots` の使い方だけ3-1のとおり変わる）

### 4-3. サーバーの部品（`app/Support/`）

| 部品 | 役目 |
|---|---|
| `Bond`（新規） | なかよし度からハートの数・呼び方・覚えたひとことを求める。相棒になかよし度を足し、ハートが増えたかと新しいひとことを返す |
| `Review`（新規） | 復習に出る問題を古い順に選ぶ。「！」を出すか・問題数・出すのは誰かを返す。やりきった記録を付ける |
| `PlayableQuestion`（新規） | ステージの出題API（`stages.play`）の中にある「正解の手がかりを隠して出す」処理を切り出したもの。ステージと復習の両方で使う |
| `Garden`（変更） | 仲間の一覧に名前・ハートなどを足し、相棒を先頭に並べて立ち位置を決める。仲間が生まれたとき、相棒がいなければ相棒にする |

- 日本時間の「今日」は B回の `Garden::today()` を使う

### 4-4. API

- `GET /api/world`:
  - `companions` の各仲間: `{ key, name, official_name, nickname, trait, lines, hearts, heart_label, bond, next_heart_bond, is_partner, x, y }`
    - `name` は名前（付けていなければ元の名前）、`official_name` は元の名前
    - `lines` は覚えたひとこと（B回の `line` の代わり）
    - `next_heart_bond` は次のハートに必要ななかよし度（ハート5つならnull）
    - 並び順は、相棒が先頭、ほかは生まれた順
  - `review`: `{ available, count, giver: { kind: "companion"|"spru", key, name } }`（`count` は出す問題数で最大5。スプルなら `key` は null、`name` は「スプル」）
- `PATCH /api/world/companions/{key}`: `{ nickname }` で名前を変え、`{ companions, review }` を返す（復習を出す人の名前も変わるため）。まだ生まれていない仲間は404。前後の空白（全角の空白も）を取って9文字以上・制御文字を含むと422。空文字・空白だけ・nullは元の名前に戻す
- `POST /api/world/partner`: `{ key }` で相棒を替え、`{ companions, review }`（並び直した一覧と、出す人が替わった復習）を返す。まだ生まれていない仲間なら422（「まだ生まれていない仲間だよ」）
- `GET /api/review`: `{ giver, questions }` を返す。`questions` はステージの出題APIと同じ形（`PlayableQuestion` で正解を隠す）で、まちがえたのが古い順。今日すでにやりきっていれば422（「今日の復習はもう終わったよ。また明日ね」）、出す問題が無ければ422（「復習する問題はないよ」）
- `POST /api/review/complete`: 今日のやりきった記録を付け、相棒に+5して `{ bond_gained, partner }` を返す（`partner` は下の相棒の形、相棒がいなければ `bond_gained` 0・`partner` null）。今日すでにやりきっていれば422。最後の問題に正解して出す問題が0になった直後でも受け付ける
  - 答えずに送られても増えるのはなかよし度+5だけなので、「問題を解いたか」は確かめない
- 回答API（`POST /api/questions/{id}/answer`）:
  - `practice: true`（やり直し）: 正解かどうか（`correct`・`correct_choice_id`・`results`）だけを返し、`profile` は null。記録・HP・XPなどは何も変えない。HPが0でも答えられる
  - ふつうの回答: `profile.partner` を足す。相棒がいれば `{ key, name, hearts, heart_label, hearts_up, new_line }`、いなければ null。正解ならなかよし度+1してから返す。`hearts_up` はこの回答でハートが増えたか、`new_line` は増えたときの新しいひとこと（増えていなければ null）
- 水やりAPIの `born`（仲間）: 仲間の一覧と同じ形に `kind: "companion"` を付けたものにする（`line` の代わりに `lines`、`is_partner` で自動で相棒になったかが分かる）
- 相棒の変更・名前の変更・復習のやりきりは、種まきと同じくトランザクションの中でプロフィールを `lockForUpdate` してから行う（二重に押しても+5が2回にならない）。回答でのなかよし度+1は、DBの上で足す（`increment`。続けて答えても取りこぼさない）

## 5. 画面

### 5-1. 町の仲間

- 相棒の足元に小さな「相棒」の札を付ける
- 「！」が出る日は、出す人（相棒かスプル）の頭の上に、オレンジ色の丸い「！」を出してゆっくり跳ねさせる（夜22〜6時と動きを減らす設定では跳ねない）
- 仲間をタップすると、跳ねて吹き出し（3-6）を出し、仲間のカードを開く

### 5-2. 仲間のカード

- 下から出るカード（町のアイテムの操作カードと同じ出し方）
- 中身: 仲間の絵、名前（名前を付けていれば「元の名前: Momo」も）、紹介文、ハート（♥♥♥♡♡）と呼び方、「ハート4つまで あと12」（ハート5つなら「しんゆう！」）
- 相棒が復習を出す日で、この仲間が相棒なら、一番上に復習の案内と［やってみる］
- 相棒でなければ［相棒にする］、相棒なら「相棒」の札
- ［名前を変える］を押すと、カードの中に入力欄と［決める］［やめる］。まちがった入力は、その場でわけを出す（「8文字までにしてね」など）
- 置く場所を選んでいる間は、仲間もスプルも押せない（B回どおり）

### 5-3. 生まれたときのお祝いと名前付け

- 最初の仲間（生まれて自動で相棒になった仲間）: お祝いの［町にむかえる］の後に、名前を付ける画面を出す
  - 「相棒になってくれるって！名前をつけよう」＋仲間の絵＋入力欄（元の名前を薄く表示）＋［決める］［このままでいい］
- 2人目からの仲間: お祝いに「町でタップすると、相棒にできるよ」を添える
- お祝いのひとことは1つ目のひとこと

### 5-4. クイズの画面（共通の部品）

- 今のクイズ画面（`app/quiz/[stageId]/page.tsx`）の中身を `components/quiz/quiz-session.tsx` に移す。ステージの画面は、問題の読み込み先・見出し・終わったときの処理を渡して呼ぶだけにする。ステージの見た目と動きは変えない
- 画面から切り離せる計算（まちがえた問題の取り出し、選択肢の入れ替えなど）は別のファイルにしてテストする
- 正解・不正解の画面: スプルの隣に相棒を小さく出す（回答APIの `profile.partner` から。やり直しの間は、直前に分かっている相棒を出す）。ハートが増えたときは「〇〇とのなかよし度が上がった！」＋ハート＋新しいひとこと
- 結果の画面: スプルの隣に相棒。まちがえた問題があれば［まちがえたN問に もう一度チャレンジ］
  - ステージ: 今の［もう一度］［ホームに戻る］はそのまま
  - 復習: ［町にもどる］だけ（［もう一度］は出さない。正解した問題で2回ごほうびがもらえてしまうため）。「〇〇のなかよし度 +5」とハートが増えたときのお祝いを添える
  - やり直し: 「もう一度チャレンジ 2/3問正解」。［もう一度］はまだまちがえた問題があるときだけ
- やり直しの間: 見出しは「もう一度チャレンジ・問題1/2」。正解の画面にXP・コイン・ポイント・コンボ・連続日数を出さない

### 5-5. 復習の画面（`/review`）

- 開くと `GET /api/review` を読み、共通の部品で出す。見出しは「〇〇からの復習・問題1/3」（スプルなら「スプルからの復習」）
- ステージ開始のカードは出さない
- 最後の問題まで答えたら `POST /api/review/complete` を送り、結果の画面を出す
- 422のときは、スプルと「今日の復習はもう終わったよ。また明日ね」（または「復習する問題はないよ」）と［町にもどる］
- HPが0のときは、ステージと同じHP切れの画面

## 6. 素材

新しい素材は使わない。「！」・「相棒」の札・ハートは画面側で描く（CSS・文字）。

## 7. テスト

### バックエンド（Pest）

- なかよし度: ハートの数と呼び方が目安どおり。相棒がいるときだけ正解で+1。相棒でない仲間は増えない。ハートが増えた回答で `hearts_up` と `new_line`。やり直しでは増えない
- 相棒と名前: 最初の仲間は自動で相棒、2人目からは替わらない。相棒の替え方と、生まれていない仲間は422。相棒が先頭の立ち位置。名前の1〜8文字・前後の空白・制御文字・空で元に戻る。ほかのプロフィールの仲間は触れない。更新時に今いる仲間の最初の1人が相棒になる
- 復習: 最後がまちがえた問題だけ出る。後で正解したら出ない。やり直しは影響しない。古い順・最大5問。消された問題は出ない。出すのは相棒、いなければスプル。日本時間で1日1回。やりきると相棒に+5、スプルなら0。2回目のやりきりは422。やりきった日と出す問題が無い日の `GET /api/review` は422。町のAPIの `review`
- やり直しの回答: 記録が増えない。HP・XP・コイン・ポイント・コンボ・連続日数・`last_correct_on` が変わらない。HPが0でも答えられる
- ステージの出題APIの形が切り出しの前後で変わらない（今あるテストがそのまま通る）

### フロントエンド（Vitest）

- スプルをタップしたときの動きの順番（3-6）
- スプルのふだんのひとことの優先順（3-6）
- まちがえた問題の取り出しと、選択肢の入れ替え（問題の中身は変えない）
- 名前の入力チェック（1〜8文字、前後の空白、制御文字）
- 覚えたひとことからの選び方
- ハートの表示（♥と♡の並び、「ハート4つまで あと〇」）

## 8. やらないこと（C回の範囲外）

- 仲間ごとの表情・ポーズ、ハートによる絵の変化（素材待ち）
- 相棒以外の仲間が育つこと、仲間の一覧ページ・図鑑
- 名前の不適切な言葉のチェック
- 「つづきから学ぶ」の中に復習を混ぜること（今のまま残す）
- 今日のおつかい・にぎやか度・家族の町（D回）、土地の解放と旅（E回）

## 9. 完了の条件

- バックエンド・フロントの自動テストがすべて通り、本番ビルドが成功する
- スマホ幅とPC幅のブラウザで次を確かめる
  - 切り出し後も、ステージが今までどおり遊べる（4択と、もう1種類の形。正解・不正解・レベルアップ・結果・もう一度）
  - 最初の仲間が生まれる → 名前を付ける → 町で相棒の札・名前が出る。2人目を相棒に替える → 立ち位置が入れ替わる
  - まちがえた問題がある日に「！」→ 復習の最後まで → なかよし度+5 → 「！」が消える。途中でやめたときは「！」が残る
  - 相棒がいないときはスプルの上に「！」が出て、スプルから復習できる
  - ステージの結果からのやり直し。やり直しでXPなどが変わらない
  - 日付は、テスト用ブラウザの時計と、開発DBの記録（`last_review_on`）の調整で確かめる
- SPEC.md・TASKS.md を更新する（③「今日のレッスン」は仲間の復習で代わりにしたと書く）
