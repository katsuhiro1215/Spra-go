# マーケティング方針（骨子）

## 基本方針

独自のWebサイトを構築し、以下を軸に認知拡大・ユーザー獲得を図る。

- 公式Webサイト（サービス紹介・LP）
- ブログ（SEO、教育・言語学習・旅行に関心のある層への情報発信）
- SNS発信（ターゲット層に合わせて選定）

## 今後CEOが詰める論点

- Webサイトの構成・デザイン方針
- ブログのテーマ・更新頻度
- 活用するSNSチャネルの選定（X / Instagram / TikTok / YouTube等、ターゲット層に応じて）
- 集客〜有料転換までの導線設計

詳細な戦略・実行計画はマーケティング部門としてCEOが随時具体化し、Ownerに報告・確認する。
