# ミニゲーム「うちゅう旅行」— 設計書

- 作成日: 2026-10-09
- ステータス: 実装済み（2026-10-09。11章はすべて私のおすすめで決定）
- 前提: スプルキャッチ（`docs/design/2026-09-29-spru-catch-design.md`。記録・ごほうび・始める／終わるの形・結果の画面）、国旗キャッチ（`docs/design/2026-10-05-flag-catch-design.md`。設定だけ分けて、サーバーを共通にした）、宇宙クイズ（`docs/design/2026-10-09-space-quiz-design.md`。問題60問・絵の問題30問）
- 元の案（Owner）: ロケットに載ったSpruが、隕石をよけて、答えの門をくぐっていく（`TASKS.md` ミニゲーム2本目）

## 1. 目的

宇宙の問題で遊ぶ、2本目のミニゲーム。スプルキャッチ（答えを受け取る）とは違う手ごたえにする: **ロケットで宇宙を進み、隕石をよけ、星を集め、答えの門をくぐる**。遊ぶほど遠くの星へたどり着く。

**うまくいった目安**

1. ミニゲームの一覧に「うちゅう旅行」が出て、最初から遊べる（宇宙クイズが取り込まれていれば）
2. 上に問題が出て、答えの門が並んで近づいてくる。ロケットを左右に動かして、正しい門をくぐる。途中の隕石をよけて、星を集める
3. 10問で1回。ハート3つ。終わると、「ロケットが○○にたどりついたよ」と出る（正解が多いほど遠い星）
4. 1回目から、幼児でも遊べる（初級は2列でゆっくり。ぶつかってもハートは減らない）
5. 英語・国旗のスプルキャッチは、今までどおり動く。記録・ごほうびの仕組みは共通

## 2. 決定事項（私のおすすめ。Owner確認待ち）

| 項目 | 決定 |
|---|---|
| 遊び方 | 縦に進む画面。ロケット（スプル）は下にいて、列を左右に動く。上から、隕石・星・答えの門が順に来る（3章） |
| 操作 | 画面の下の「◀」「▶」・キーボードの ← →・列をタップ（その列へ動く）。スプルキャッチのように「タップで投げる」はない |
| 1回 | 10問。ハート3つ（まちがえた答えで1つ減る）。隕石にぶつかっても、ハートは減らない |
| 隕石 | ぶつかると、ロケットがゆれて、その問題で集めた星がなくなる（点にも入らない）。かならずよけられる道がある（3-3） |
| 星 | 1問につき最大3つ。集めた星は +1点ずつ（その問題で、最大 +3点）。ぶつかると、その問題の星はゼロ |
| 点数 | 英語と同じ決まり（正解 +10・コンボ3以上は +5）に、星を足す。全問正解・全部の星で 140 + 30 = 170点 |
| 到着する星 | 正解の数で決まる。0〜2＝月、3〜4＝火星、5〜6＝木星、7〜8＝土星、9＝海王星、10＝冥王星（結果の画面に、その星の絵を出す） |
| 問題 | 宇宙クイズと同じ問題（カテゴリー「宇宙」）。難しさで、初級・中級・上級の問題を使う。文字の問題も絵の問題も出る |
| 難しさ | 初級（2列・8秒・隕石1つ）・中級（3列・6秒・隕石1〜2つ）・上級（4列・4.5秒・隕石2つ）。3つとも最初から選べる |
| ごほうび | 1日の最初の3回まで。正解1問あたりの経験値と学習ポイントは、英語・国旗と同じ（初級3・中級4・上級5）。コインは出さない |
| 記録 | 遊んだ回は `profile_game_plays`（`game = space_trip`）。星の数を足す列を1つ足す |
| 絵・音 | 今は、仮の絵（SVGなど）で動かす。ロケットのスプル・隕石・星・門などは、絵が届いたら差し替える（8章） |

## 3. 遊び方

### 3-1. 1回の流れ

1. 難しさを選ぶ（スプルキャッチと同じ画面の作り）
2. 「3・2・1」のあと、1問目が始まる
3. 10問を終えるか、ハートが3つなくなったら終わる
4. 結果の画面（4章の「到着する星」つき）

### 3-2. 1問の流れ

1問は、上から下へ流れる1本の道（時間は難しさの `fall_ms`）。**時間の順に、次のものが同じ列の上から降りてくる。**

1. **隕石の区間**（前半）: 隕石が、列ごとに少しずつ時間をずらして降りてくる。星も、列に降りてくる。ロケットを動かして、隕石をよけ、星をくぐる
2. **門の区間**（後半）: 問題の答えの門が、列の数だけ横一列に並んで降りてくる。1つの列に1つの門（文字か絵。門の上に答えが書いてある）。ロケットが門のラインまで来たとき、いる列の門をくぐったことになる
3. 門をくぐったあと、短い間、○×を見せる（正解 0.8秒・まちがい 1.6秒。スプルキャッチと同じ）。正解の門は光る。次の問題へ（ロケットは同じ列から続ける。1問目は真ん中）

上に、問題文を出す（スプルキャッチの見せ方と同じ）。

### 3-3. 隕石と星の置き方

- 隕石と星の置き場所は、**回と問題の番号から決まる**（`play_id` と問題の番号を種にした計算。同じ回なら同じ並び。画面だけで決め、サーバーには送らない。星の数だけ送る）
- 隕石の区間を数段（初級2段・中級3段・上級4段）に分け、1段に隕石を最大「列の数−1」個まで置く（**どの段にも、かならず空いている列がある**。ロケットがすぐ横に動けば、よけられる）
- 星は、空いている列に置く。1問に最大3つ。星を取ると、きらっと光る。取らなくても、ハートは減らない
- 隕石にぶつかると、ロケットが短くゆれて、その問題で集めた星がゼロになる（「ぶつかった！」を出す。ハートは減らない）
- 動きを減らす設定のときは、隕石を出さず、星だけを置く（ゆっくり）

### 3-4. 難しさ

| | 初級 | 中級 | 上級 |
|---|---|---|---|
| 列の数 | 2 | 3 | 4 |
| 1問の時間（`fall_ms`） | 8秒 | 6秒 | 4.5秒 |
| 隕石の段 | 2 | 3 | 4 |
| 1段の隕石 | 0〜1 | 0〜2 | 1〜3 |
| 出す問題 | 宇宙の初級 | 宇宙の中級 | 宇宙の上級 |
| 1問あたりのごほうび | 経験値3・ポイント3 | 経験値4・ポイント3 | 経験値5・ポイント3 |

### 3-5. 点数

- 正解 +10。コンボが3以上の正解は、さらに +5（英語と同じ。コンボは正解の並びで決まり、隕石は関係しない）
- 星は、1問ごとに集めた数（0〜3）を足す。まちがえた問題の星も、点に入る（遊びの楽しさのため）
- 点数・最長コンボは、サーバーが、答えと星の数から計算し直した値だけを記録する。星の数は、問題ごとに 0〜3 の範囲だけを受け付ける（範囲外は 422）

## 4. 結果の画面

- 「ロケットが ○○ に たどりついたよ！」と、到着した星の絵を大きく出す（到着する星は、2章の表。宇宙クイズの絵を使う。絵が届くまでは、星の名前だけ）
- 点数・「正解 8/10」・集めた星の数・いちばん長いコンボ。自己ベストを超えたら「新記録！」
- ごほうび（スプルキャッチと同じ文言）。レベルが上がったら、レベルアップの画面を先に出す
- 「まちがえた問題」の一覧（問題文 → 正解の言葉）。絵の問題は、正解の絵の名前
- ボタン: 「もう一回」・「難しさを変える」・「学ぶにもどる」
- 答えの数が10未満（途中で終わった・問題が足りなかった）のときの到着する星は、「正解の数 ÷ 出した問題の数」を10問に換算して決める

## 5. 出す問題

- 使える問題: カテゴリー「宇宙」の、ステージに入っている問題のうち、**その難しさ（ステージの級）の問題**。4択（正解1つ・まちがい3つ）のものだけ（列の数が2〜4なので、まちがいから「列の数−1」個を選ぶ）。選択肢の長さの上限（`max_label_width`）は設けない（原稿が全角6文字以内のため）
- 出す順・覚え具合への記録・「最近まちがえた」と「復習の日が来た問題」を先に出す決まりは、スプルキャッチと同じ。ゲームの答えも、クイズと同じ問題ごとの覚え具合に残る
- 今の取り込み（絵なし）では、文字の問題だけなので、初級は8問・中級は14問・上級は8問（10問より少ないときは、ある分だけ出す。スプルキャッチと同じ）。絵が届くと、初級24問・中級24問・上級12問になる
- 選択肢の絵（絵の問題）は、門の中に絵を出す。名前（label）は、絵の下に小さく添える

## 6. サーバー

スプルキャッチ（`CatchGame`）を、設定を足して共通に使う。ゲームの名前は `space_trip`。

- `config/games.php` に `space_trip` を足す: `question_count` 10・`review_max` 6・`daily_rewarded_plays` 3・`category`（`宇宙`）・難しさごとの `lanes`・`fall_ms`・`obstacle_rows`・`reward`・`messages.empty`
- 問題の取り出し: 今は「英語を学ぶ」のカテゴリー名を `games.catch.category` から読んでいる。ゲームごとの `category` があれば、それを使う（なければ今のまま）。鍵の国（`Travel::lockedCountryIds`）は、宇宙には関係ない（ステージの `country_id` が空なので、そのまま通る）
- 始める: `POST /api/games/space-trip/plays` の返事に、`lanes`・`fall_ms`・`obstacle_rows`・`questions`（スプルキャッチと同じ形。絵つきの選択肢の `image` もそのまま）を返す
- 終える: `POST /api/games/space-trip/plays/{play}/finish` の本文は、スプルキャッチと同じ `answers`（`question_id`・`choice_id`）に、`stars`（その問題で集めた星の数。0〜3）を足す。サーバーが、答えと星の数から、点数・最長コンボ・正解の数を計算し直す。星が範囲外（負・4以上・数でない）なら 422
- 点数の計算: `CatchGame::score` を、星の数の並び（省略可）を受けるように拡張する（省略したときは、今までと同じ点数。英語・国旗は変わらない）
- 記録: `profile_game_plays` に `stars`（整数・空でもよい。集めた星の合計）を足す
- 結果の返事に、`stars` と `destination`（到着する星のキー: `moon`・`mars`・`jupiter`・`saturn`・`neptune`・`pluto`）を足す（到着する星は、サーバーで決める）
- ルートは、国旗キャッチと同じ形（`games/space-trip`）。ミニゲームの一覧の `MINI_GAMES` に1行足す

## 7. 画面

- `/games/space-trip`（選ぶ・遊ぶ・結果）。難しさを選ぶ・結果の画面は、スプルキャッチの部品を、とれる所だけ共通にする（切り出しは、実装の中で、必要な所だけ）
- ゲームの動きは、画面から切りはなした純粋な部品 `space-engine.ts`（隕石・星・門の置き方、当たり判定、点数）にする。スプルキャッチの `catch-engine.ts` とは別。テストで確かめる
- ゲームの画面: 上のバー（やめる・何問目・点数・星の数・ハート）・問題文のカード・遊ぶ場所（縦長。宇宙の背景）・ロケットのスプル・「◀」「▶」。背景は、問題が進むごとに、少しずつ暗く、星が増える（絵が届くまでは、グラデーション）
- 隕石・星・門・ロケットは、仮のSVG（円・星形・枠）で作る。絵が届いたら差し替える（8章）
- 動きを減らす設定・タブを離れたら止める・「やめる」の確認は、スプルキャッチと同じ
- アクセシビリティ: 隕石・星の色だけに頼らない（形も違う）。門の答えは、文字でも読める

## 8. 絵と音（後回し。画像は届いたら入れる）

必要な絵の一覧（依頼文は、画像を作るときに作る）:

| 絵 | 内容 |
|---|---|
| ロケットのスプル | 後ろ姿のスプルが、ロケットに乗っている（下から炎）。ぶつかったとき・喜ぶときの表情違いが、あれば |
| 隕石 | 大・小の2〜3種類（かわいい、とがりすぎない） |
| 星 | 集める星（光る黄色い星） |
| 門 | 答えを入れる、大きなアーチ型の枠（半透明に近い、文字や絵を入れる空間つき） |
| 背景 | 縦長の宇宙（グラデーション・星のまたたき。画面のスクロールで動かす） |
| 到着する星 | 月・火星・木星・土星・海王星・冥王星（宇宙クイズの絵と共通） |

音は、今ある効果音（正解・まちがい・全問正解）を使う。星を取る音・ぶつかる音は、あとで足す。

## 9. テスト

- サーバー（Pest）:
  - 設定: `space_trip` が3つの難しさを持つ。
  - 問題: 宇宙の問題から、難しさごとに選ぶ。4択でない問題や、まちがいが足りない問題は出さない。10問より少なくても始められる。0問なら422。
  - 点数: `score` に星の数を渡したときの点数（正解のコンボ・星の合計）。星を渡さないとき（英語・国旗）は今までと同じ。
  - 終える: 星の数の範囲チェック（負・4以上・数でない・答えの数と合わない配列は422）。記録に `stars`。到着する星の決まり（0〜2＝月 … 10＝冥王星、10問未満の換算）。
  - ごほうび・1日3回・覚え具合への記録は、スプルキャッチと同じ。英語・国旗は変わらない（既存のテスト）。
- 画面（Vitest）: `space-engine`（隕石の置き方〔どの段にも空きの列がある・同じ種で同じ並び〕・当たり判定・星の数・点数）、結果の画面の文言（到着する星）、APIの部品。
- ブラウザ: スマホ幅（375px）で、初級・中級・上級を遊ぶ。隕石をよける・星を取る・門をくぐる・ぶつかる・ハートが減る・結果・「やめる」・動きを減らす設定。確認用のプロフィールは、作って、確認後に消す。

## 10. やらないこと

- ランキング・対戦・3D・管理画面
- 隕石でハートが減ること、ロケットの強化・着せかえ
- BGM（あとで、音の方針が決まってから）
- 星の数をサーバーで確かめること（範囲だけ確かめる。ごほうびは正解の数だけで決まるので、影響は小さい）

## 11. 確認してほしいこと（すべて私のおすすめ）

1. **隕石でハートを減らさない**（ぶつかると、その問題の星がなくなるだけ）でよいか。幼児向けなので、減らさない案をおすすめする。ハードにしたければ、上級だけ減らす案もある。
2. **星の点数**（+1点ずつ）と、**点数の合計170点**でよいか。
3. **到着する星**（月・火星・木星・土星・海王星・冥王星）の決め方でよいか。
4. **操作**は、◀▶・矢印キー・列をタップ（その列へ動く）でよいか。スプルキャッチと違い、「タップで投げる」はない。
5. 絵は**仮のSVGで動かして、あとで差し替える**でよいか。

## 12. 実装の順序（実装計画で細かくする）

1. サーバー: 設定・問題の取り出し・星つきの点数・終える・記録の列・到着する星。
2. 画面の部品: `space-engine.ts`（純粋な計算とテスト）。
3. 画面: 選ぶ・ゲーム・結果、ミニゲームの一覧。仮のSVGで動かす。
4. ブラウザ確認、SPEC・TASKSの更新。絵が届いたら差し替え。
