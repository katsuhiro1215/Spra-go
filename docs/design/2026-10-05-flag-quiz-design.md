## 1. 背景と目的

Ownerの意見: 幼児は国旗クイズがとても好き。今の「国旗」は、英語のあいさつなどのデータの寄せ集めで、国旗の問題は1問しかない。

1. 国旗を見て「どこの国？」を、大陸ごとに答えられる
2. 「日の丸の国旗は？」のように、国名から国旗を選べる（中級・上級から）
3. 4つの国旗を、番号つきの枠にタップではめ込める
4. 似た国旗（チャドとルーマニアなど）は難しい側に置き、世界じゅうを混ぜたものが最難関
5. 作れば、ミニクイズの一覧に自動で出る（ステージが3つ以上）

**うまくいった目安**

- 幼児が、好きな大陸を選んで、初級から遊べる
- 初級は国旗の絵だけで答えられ、上級では似た国旗で迷う
- 国の一覧に1行足せば、画面を直さずに、ステージと問題が増える

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| 大陸の選び方 | **大陸ごとのコース**。国旗クイズを開く → 大陸を選ぶ → 級（初級・中級・上級）を選ぶ。進み具合はコースごとに別 |
| コース | アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニア・**世界ぜんぶ**（最難関）。どのコースも、初級・中級・上級を持つ |
| はめ込みの動き | 番号つきの国名の枠に、下の国旗をタップで入れる。4つ入ったら自動で答え合わせ |
| 国の範囲 | **国連加盟の193か国**。台湾・パレスチナ・コソボ・バチカンは入れない（あとから一覧に足せば、自動でステージが増える） |
| 今ある「国旗」（id 13） | 各国の学習用で、下に38の国のカテゴリーがあるため、**触らない**。国旗クイズは新しいカテゴリーにする |

## 3. 全体の形

### 3-1. カテゴリー

```
国旗クイズ（新しい大もと。is_course_group = true）
 ├ アジア        初級 → 中級 → 上級（各級の最後がボス）
 ├ ヨーロッパ    同上
 ├ アフリカ      同上
 ├ 北アメリカ    同上
 ├ 南アメリカ    同上
 ├ オセアニア    同上
 └ 世界ぜんぶ    同上（初級は よく知られた国だけ、上級は193か国＋似た国旗）
```

- 大もとの「国旗クイズ」は、自分のステージを持たない。子のカテゴリーが「コース」で、ステージは子の中にある
- 子のコースの `country_id` は空（鍵の国に当たらない）。ステージの進み方（前のステージをクリアすると次が開く、級はボスをクリアすると次が開く）は、今のまま

### 3-2. 仕組みの追加（小さく2つ）

1. **親カテゴリーの目印**: `categories.is_course_group`（真偽値・初期値は偽。マイグレーションは足すだけ）。真のカテゴリーは、子のカテゴリーを「コース」として選ばせる親
2. **ミニクイズの一覧**: 大もとのカテゴリーは、①自分のステージ（問題があり、鍵の国でない）が3つ以上ある、または ②`is_course_group` が真で、子のステージの合計が3つ以上ある、場合に出す。`stage_count` は数えたステージの合計。今ある「国旗」（id 13）は目印が偽なので、これまでどおり出ない

### 3-3. 画面の流れ

1. 引き出しのミニクイズに「国旗クイズ」→ `/play/{id}`
2. 目印が真のカテゴリーなら、級の選択の代わりに**コースの選択**（子のカテゴリーのカード。進み具合〔クリアしたステージ/全部〕つき）
3. コースを選ぶと、今までの `/play/{コースのid}`（初級・中級・上級の選択 → ステージ）

## 4. 級ごとの問題

1ステージは10問。国の一覧（5章）からコードで自動生成する。

| 級 | 出す国 | 内容 |
|---|---|---|
| 初級 | そのコースの、**よく知られた国**（知名度の段階1・2） | 国旗を見て「どこの国？」の4択。選択肢はそのコースの国名。国名→国旗は出さない |
| 中級 | そのコースの**すべての国** | 8問は、国名から国旗を選ぶ（4択が国旗の絵）。2問は、はめ込み。**ステージの3問目と8問目**がはめ込み |
| 上級 | そのコースの**すべての国** | 中級と同じ並びで、まちがいの選択肢に**似た国旗**が入る。国旗→国名と国名→国旗が交ざる。はめ込みも似た国旗の組み合わせ |

- **ステージの数**: 級に出す国の数を10で割った切り上げの数だけ、国をなるべく均等に分ける（1ステージ7〜10か国。小さなステージができない）。そのうえで、級の最後に**ボスのステージ**を1つ足す（その級の全部の国から10問・称号つき）。ボスをクリアすると次の級が開く
- **世界ぜんぶ**: 初級は、知名度1・2の国（世界から）、中級は知名度1・2・3の全部、上級も全部＋似た国旗。選択肢は世界じゅうの国から選ぶ
- **ボスのステージ**: その級の問題の並びと同じ形で、その級の全部の国から10問（初級は国旗→国名10問、中級・上級は3問目と8問目がはめ込み）
- **まちがいの選択肢**: 初級・中級は、コースの国からランダムに。上級は、その国の「似ている国」から（足りなければ、同じコースの国で足す）。問題ごとに、まちがいの候補を多めに持たせ、出すときに今の仕組みが3つをランダムに選ぶ（`PlayableQuestion`）。上級だけは、似た国旗が確実に選択肢に入るよう、候補を「似ている国（最大4）＋足りないぶんだけ、同じコースの国」に絞る（最低3つ。3つのときは全部が選択肢に出る）
- **国と問題の対応**: 各級で、どの国も、最低1回は正解として出る

### 似た国旗の例

チャド/ルーマニア/アンドラ/モルドバ、インドネシア/モナコ/ポーランド、アイルランド/コートジボワール/イタリア、オランダ/ルクセンブルク、オーストラリア/ニュージーランド、ベネズエラ/コロンビア/エクアドル、スロバキア/スロベニア/ロシア、ノルウェー/アイスランド/デンマーク/フィンランド/スウェーデン、マリ/ギニア/セネガル、など。国ごとに最大4か国。互いに似ている関係は、一覧のテストで「片方だけ」にならないようにそろえる。

## 5. データ（国の一覧）

- ファイル: `database/data/flag-countries.php`（193件の配列）
- 1件の項目: `key`（`public/flag/` のファイル名から `.svg` を除いたもの。例 `Japan`）、`name`（日本語の国名。例「日本」）、`continent`（asia・europe・africa・north-america・south-america・oceania）、`tier`（知名度 1〜3）、`similar`（似ている国の `key` の配列）
- **Ownerの確認が要る内容**: 国名の表記（略称・正式名称）、知名度の段階、似ている国。最初の版は私が書き、公開前にOwnerが目を通す（`TASKS.md` に足す）
- 国旗のファイルは、絵が実在するものだけを使う（名前に綴りの違い〔`Isreal`・`Kenia`・`Swaziland`・`Cote-d-Ivoire-Ivory-Coast` など〕があるので、`key` はファイル名のとおりにする）

## 6. 問題とデータの作り方

### 6-1. 問題の形

| 内容 | type | データ |
|---|---|---|
| 国旗→国名 | `multiple_choice` | 問題の `meta.image` に国旗の絵。選択肢は国名（`label`） |
| 国名→国旗 | `multiple_choice` | 選択肢の `meta.image` に国旗の絵（`label` は国名。読み上げと、答えたあとの表示に使う） |
| はめ込み | `matching` | 今のマッチングと同じデータ。国旗4つが `meta.items`、国名4つが選択肢（`meta.item_id` で正解を結ぶ）。`meta.layout = "slots"` で、はめ込みの見せ方にする |

- バックエンドの採点・出題は、**変えない**（マッチングは、4つ全部合っていて正解）
- 問題の `country_id` は空。進み具合・おさらい・「へん？」の報告・Ownerの編集は、今の仕組みのまま

### 6-2. 自動生成

- 純粋な計算（`app/Support/FlagQuiz/`）が、国の一覧から、コース・級・ステージ・問題の「計画」を作る。データベースには触らない。ここをテストする
- 計画をデータベースに書くのは、Seeder（`FlagQuizSeeder`）。**何度実行しても重複しない**ように、ステージと問題に決まった名前（例 `flag:asia:beginner:2`、問題は `…:q3`）を `meta` に持たせ、あれば更新、なければ作る。国の一覧の誤りを直して再実行すれば、問題の文・選択肢が直る（進み具合は、ステージ・問題の番号を保つので消えない）
- 開発データベースへの登録は、足すだけ（`migrate:fresh` は使わない）

## 7. 画面

### 7-1. 国旗の選択肢

- 国旗→国名: 問題文の上に、国旗を大きく（3:2）。選択肢は今までどおり国名のボタン
- 国名→国旗: 問題文は国名。選択肢は、国旗の絵のボタンを2×2に並べる。答えたあとの正解・不正解の色づけは、今の仕組み（選択肢の番号で決まる）のまま。絵の読み上げ（`alt`）は国名

### 7-2. はめ込み（`matching` で `meta.layout = "slots"`）

- 上に、番号つきの国名の枠（①〜④）。下に、国旗が4つ（並びはばらばら。問題ごとに固定）
- 国旗をタップ → いちばん上の空いている枠に入る。入れた国旗をタップ → 下に戻る
- 4つ入ったら、自動で答え合わせ（今のマッチングの採点の窓口に、4つの組を送る）。枠ごとに○×を出し、まちがいの枠には、正しい国旗を出す
- 答え合わせのあとは、今のマッチングと同じで「次へ」
- 答えをサーバーに隠しているので、1つずつ即座に○×は出さない（4つ入れてから）

### 7-3. コースの選択（`/play/{id}`）

- `is_course_group` が真のカテゴリーのとき、級の選択の代わりに、コースのカードを並べる（アジア〜世界ぜんぶ）。カードは、コースの名前と、進み具合（クリアしたステージ/全部）。世界ぜんぶは最後で、「ちょうむずかしい」のひと言を添える
- コースの一覧と進み具合は、新しい窓口 `GET /api/categories/{id}/courses`（ログイン済み）で返す。`is_course_group` が偽のカテゴリーは404。進み具合は、今のプレイヤーがクリアしたステージの数と、問題のあるステージの数

## 8. テスト

- **サーバー（Pest）**: ミニクイズの一覧（コース親の合計・目印が偽の親は数えない・今の「国旗」が出ない）、コースの窓口（進み具合・順番・コースでないカテゴリーは404）、国の一覧と計画の確認（国旗のファイルが実在・重複なし・国が大陸にちょうど1つ・似ている関係がそろっている・どのステージも10問・各級でどの国も1回は正解・まちがいの候補が足りている・上級の選択肢に似た国旗が入る・はめ込みの4つが重ならない）、Seederの二重実行で増えない
- **画面（Vitest）**: はめ込みの入れ方・戻し方・全部入った判定・結果の枠への当てはめ、国旗の選択肢の描き分けの判定、コースの進み具合の文
- **ブラウザ**: 引き出しに「国旗クイズ」が出る、コースを選ぶ、初級の国旗→国名、中級の国名→国旗、はめ込みの動き、ボスで次の級が開く、世界ぜんぶ

## 9. やらないこと

- 国旗キャッチ（④）
- 国名の読み上げ（声）。幼児に効果は高いが、別の設計にする
- 台湾・パレスチナ・コソボ・バチカン（Owner決定。193か国のみ）
- 国旗のファイル名が答えの手がかりになることの対策（子ども向けのため許容）
- Owner管理画面での `is_course_group` の切り替え（今回は、Seederで設定する）
- 国旗クイズ専用の成績画面・称号の絵
