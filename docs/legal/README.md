## 5. 専門家に見てもらいたいこと

1. **未成年者の取り消しで返金する範囲**（refund 2章）: 使ってしまったコインも返金の対象になるか
2. **外国の会社（Stripe など）に処理を任せることの書き方**（privacy 5章）: 個人情報保護法の外国にある第三者への提供として、何をどこまで書くか
3. **資金決済法**（memo）: 有償コインが前払式支払手段に当たるか、返金ポリシーの返金が「払戻しの原則禁止」に当たらないか
4. **責任の制限**（terms 第11条）: 消費者契約法に照らして有効な書き方か
5. **購入の記録の保存期間**（privacy 7章）: 7年でよいか
6. **特定商取引法の住所・電話の省略**（tokushoho）: 個人事業で「請求があれば開示」にしてよいか。Stripe の審査で公開の住所・電話を求められないか

## 6. 公開までに、画面と仕組みで必要なこと

下書きが確定したら、次を別の仕事として設計・実装する。

1. **規約のページ**: `/terms`・`/privacy`・`/refund`・`/tokushoho` を作り、LP・ログイン・登録・「じぶん」のパネル・ショップから行けるようにする（置き場所は、ブランドとドメインの設計〔spra.jp の紹介サイトか、アプリの中か〕で決める）
2. **登録のときの同意**: 登録の画面に「利用規約とプライバシーポリシーに同意する」を足し、同意した日時と版を記録する
3. **購入の最終確認の画面**（特定商取引法12条の6）: コインのパックを押したあと、Stripe の画面に移る前に、数量・価格・支払の時期と方法・コインが付く時期・キャンセルの扱いを表示する
4. **有償と無償のコインを分けて数える仕組み**と、基準日の未使用残高を出す仕組み（memo 4章）
5. **家族アカウントの削除**: 画面を作るか、問い合わせ窓口で受け付ける手順を決める（terms 第7条2項）
6. **購入前の追加の確認**（パスワードの入力など。`TASKS.md` の公開前必須の仕事。未成年者の購入を防ぐ）
7. **お問い合わせの窓口**: メールアドレスを用意し、受け付ける手順を決める
