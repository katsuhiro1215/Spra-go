# 街づくり — 広がる地図・雲の区画・大きな建物（E回）— 設計書

- 作成日: 2026-09-27
- ステータス: Owner合意済み（設計の各区切りを対話で確認）
- 前提: `docs/design/2026-09-26-world-town-design.md`（町・ポイントで買って置く）、`docs/design/2026-09-26-spru-wave-a-design.md` 〜 `docs/design/2026-09-27-spru-wave-d-design.md`（A〜D回）。すべて実装済み
- 参考モックアップ: https://claude.ai/artifact/JJNrVbfAxEz1q7h6Tadbw9 （ワールド画面の設計のときのもの。Lv.4で雲に隠れた「竹林エリア」が開く、など）

## 1. 背景と目的

2026-09-26のコンセプト「学ぶほど世界が広がる」の②「レベルによる土地の解放と、新しい国への旅」にあたる。当初はE回1回で「土地の解放と旅・おみやげ」を作る予定だったが、Ownerの構想（「スマホの画面からはみ出してもよい。どんどん用地が広がって、城やタワーが建てられる、シムシティのような街づくりにしたい」）を受けて、次の2回に分ける。

- **E回（本書）: 街づくり** — 1枚につながった大きな地図、レベルで雲が晴れて広がる区画、城やタワーなど2×2マスの大きな建物
- **F回: 旅とおみやげ** — 旅のハブ・国の画面・旅のじゅんび・国ごとのおみやげ（決まっている方針は9章に残す）

E回を先にするのは、F回の船旅の出発点（海辺の桟橋）がE回の区画にあるため。

## 2. 決定事項（Owner確認済み）

| 論点 | 決定 |
|---|---|
| 土地の広げ方 | **1枚につながった大きな地図**。画面からはみ出た部分はドラッグで見る。区画ごとに別の画面へ切り替える形にはしない |
| 区画の開き方 | **レベルで自動**（A案）。区画ごとに必要レベルがあり、届くと雲が晴れて置けるようになる。ポイントで開拓する形・1マスずつ買う形にはしない |
| 大きな建物 | **2×2マスまで**。城・タワーなど。3×3以上は作らない |
| 地図の動かし方 | **ドラッグ＋「スプルの家へ戻る」ボタン**。拡大・縮小はしない |
| 大きな建物の置き方 | **下見してから「ここに建てる」**の2段階（値段が高いので置き間違いを防ぐ）。1マスのアイテムは今までどおりタップ1回 |
| 新しいアイテム | 1マス4つ・2×2が4つ（3-5の表）。置き場所は区画で縛らない |
| 回の分け方 | E回＝街づくり、F回＝旅とおみやげ |

### 今後の方針（D回から引き続き）

- コインで回すガチャ、コインで育つのを早める機能は作らない
- 有料の素材は使わない。アイテム・目印の絵は画面側でSVGで描く

## 3. 遊びのルール

### 3-1. 地図と区画

地図は全部で12×12マス。今の町（7×7）を奥の端に置き、手前（xとyが大きくなる向き）へ広げる。今の町の座標は変わらないので、置いてあるアイテム・スプル・仲間・畑の位置はそのまま使える。

```
                 はじまりの町（x0-6, y0-6）
               ╱                         ╲
   海辺 Lv.7（x0-6, y7-11）      竹林 Lv.4（x7-11, y0-6）
               ╲                         ╱
                    丘 Lv.10（x7-11, y7-11）
```

| キー | 名前 | 位置（x, y） | 大きさ（w×h） | 必要レベル | 地面 | 目印・道 |
|---|---|---|---|---|---|---|
| `town` | はじまりの町 | 0, 0 | 7×7 | 1 | `grass`（今の芝生） | 今のまま（スプルの家・鳥居・灯籠・畑・道） |
| `bamboo` | 竹林 | 7, 0 | 5×7 | 4 | `bamboo`（深い緑） | 道: 町の道（y=3の列）の続き (7,3)〜(11,3)。竹やぶ（`bamboo_grove`）: (8,0)・(10,1)・(11,5) |
| `beach` | 海辺 | 0, 7 | 7×5 | 7 | `sand`（砂浜） | 桟橋（`pier`）: (2,11)。F回で船旅の出発点にする |
| `hill` | 丘 | 7, 7 | 5×5 | 10 | `hill`（明るい緑） | なし（大きな建物のために広く空けておく） |

- 区画・目印・道は設定ファイル（`config/world.php`）に書く。区画を足すときは設定を足すだけで済むようにする（地図の大きさは区画から計算する）
- 土地の形は全員同じで、DBには持たない。人によって違うのは「どこまで開いているか」だけ（その人のレベルで決まる）
- 開いている区画の目印・道のマスには置けない（今と同じ）。雲の区画のマスにも置けない
- スプル・仲間・畑は町（`town`）に置いたまま。新しい区画には行かない

### 3-2. 雲と、区画が開いたときのお祝い

- まだ開いていない区画は、海の上に浮かぶ雲で隠す。雲の上に「竹林 Lv.4で解放」の札を出す
- 雲（札）を押すと、スプルが「レベル4になると雲が晴れるよ」と言う（吹き出し。今のスプルのひとことと同じ出し方）
- レベルはふつう問題を解いている間に上がるので、区画が開いたことは **次に町を開いたとき** に祝う
  - 「開いているのに、まだ祝っていない区画」（`plots_new`）があれば、お祝いのカードを出す: 「竹林エリアが広がったよ！」（喜ぶスプル）と［見に行く］
  - ［見に行く］でカードを閉じ、地図をその区画まで動かし、区画の上の雲が晴れる（散っていく）演出を出す。そのあと祝った印をサーバーに送る
  - 祝った区画はサーバーに記録する（別の端末でも二度出ない）
  - 一度に2つ以上ある（すでにLv.7以上の人が初めてE回の町を開いた、など）ときは、1枚のカードにまとめて名前を並べ（「竹林・海辺が広がったよ！」）、いちばん必要レベルの高い区画へ地図を動かす
  - `town` は最初から開いているので祝わない
- 町を開いたときに重なって出るものの順番: 最初の100pt → **区画のお祝い** → 家族から届いたあいさつ → 季節のあいさつ（前のものを閉じてから次を出す）
- 動きを減らす設定のときは、地図は動かさずにその場へ切り替え、雲は散らさずに消す

### 3-3. 地図の見方

- 縮尺は、今の町（7×7）の描く範囲が枠の横幅にちょうど収まる大きさ（今と同じ見た目）。地図全体（12×12）はその縮尺で描くので、横は約1.7倍、縦は約1.4倍になり、枠からはみ出す
- 枠（地図が見えている部分）の高さは、今の町の絵の高さと同じ。最初に町を開いたときは、今と同じく町（7×7）がちょうど枠に収まる位置から始まる
- 動かし方
  - スマホ: 指でドラッグ（ふつうのスクロール）
  - PC: マウスでドラッグ、ホイール、矢印キー（枠を選んだ状態で）
  - マウスでドラッグしたときは、指を離したときのタップ（アイテムを押した扱い）を起こさない。少し（6px以上）動いたらドラッグとみなす
- 町の中心が枠から外れたら、枠の右下に［スプルの家へ戻る］を出す。押すと最初の位置へ戻る（動きを減らす設定ではすぐ切り替える）
- 置く場所を選んでいるとき、枠の外にも置けるマスがあれば、案内に「地図を動かすと、ほかの場所も見られるよ」を足す
- 家族の町も同じ枠で見る。見えるのはその人のレベルで開いている区画（雲の札は押しても何も起きない）
- にぎやか度の飾り（鳥・ちょうちょ・旗・風船・花火）と時間帯の空の演出は、地図と一緒には動かさず、枠の上に重ねる（空の飾りなので、見えている範囲に出ればよい）

### 3-4. 大きな建物（2×2マス）

- 2×2マス使うかどうかは **絵で決まる**。設定ファイルに「2×2の絵」の一覧を持ち、アイテムはその絵（`asset_key`）を使っていれば2×2になる。Ownerが管理画面で1マスの絵を2×2にする（またはその逆）ことはできない
- 位置は「いちばん奥のマス」（xとyがいちばん小さいマス）で記録する。建物は (x, y)・(x+1, y)・(x, y+1)・(x+1, y+1) の4マスを使う。今の `x`・`y` 列をそのまま使い、DBの列は増やさない
- 置ける条件（4マスすべて）
  - 地図の中にある
  - 開いている区画にある
  - 目印・道のマスでない
  - ほかのアイテムと重ならない（ほかの2×2の建物は、その4マスすべてで比べる）
- 動かすときは、自分がいま使っている4マスとは重なってよい（1マスずらす、など）
- 絵の重なり順は、建物の手前のマス（x+1, y+1）で決める。建物の前に置いた木などは、建物より手前に見える
- にぎやか度は2倍で数える（3-6）
- ショップ・バッグのカードに「2×2マス」と出す。場所が足りなくても買える（バッグに入る。今と同じ）
- 置き方（5-3）: 置ける場所（建物の奥のマスにできるマス）が光る → タップすると建つ4マスが光り、建物がうすく見える（下見） → ［ここに建てる］で決まる。下見中にほかの光っているマスを押すと下見が移る

### 3-5. 新しいアイテム

| アイテム | 絵のキー | 大きさ | 必要レベル | 値段 |
|---|---|---|---|---|
| 石灯籠 | `stone_lantern` | 1マス | 3 | 30pt |
| 竹 | `bamboo` | 1マス | 4 | 25pt |
| 噴水 | `fountain` | 2×2 | 5 | 150pt |
| ヤシの木 | `palm` | 1マス | 7 | 40pt |
| ビーチパラソル | `parasol` | 1マス | 7 | 35pt |
| 五重塔 | `pagoda` | 2×2 | 9 | 300pt |
| お城 | `castle` | 2×2 | 10 | 400pt |
| タワー | `tower` | 2×2 | 12 | 500pt |

- 区画が開くレベル（竹林Lv.4・海辺Lv.7・丘Lv.10）に合わせて、その土地に似合うアイテムが買えるようになる。置き場所は区画で縛らない（開いている土地ならどこでも）
- 石灯籠は、町の目印の灯籠と同じ絵を使う
- 既存の8種類（ベンチ〜屋台）は変えない
- 品ぞろえはシーダー（`WorldItemSeeder`）に足す。何度実行しても重複しない

### 3-6. にぎやか度の見直し

- 置いた大きな建物（2×2）は、種類ごとに1つ目 **+6**・2つ目から **+2**（1マスのアイテムの2倍）。仲間は今と同じ1人+3
- 段階の必要数（0・6・15・27・42）は変えない（D回の設計書で「E回で見直す」としていたもの。土地が広がって置ける数は増えるが、種類を集める手間は変わらないため、据え置く）

## 4. データとサーバー

### 4-1. テーブル

| テーブル | 変更 |
|---|---|
| `user_profiles` | `world_plots_seen`（JSON、null可）を足す。祝った区画のキーの一覧（例: `["bamboo"]`） |

- 追加だけで、既存のデータは変えない。適用は通常の `php artisan migrate`（`migrate:fresh` は使わない）
- 区画・土地の形はDBに持たない（設定ファイル）
- `profile_world_items` は変えない。一意の制約（プロフィール＋x＋y）はそのまま残す（2×2の建物どうしの重なりは、4-3のチェックとプロフィールのロックで防ぐ）

### 4-2. 設定（`config/world.php`）

- `land` を次の形にする

```php
'land' => [
    'plots' => [
        ['key' => 'town', 'name' => 'はじまりの町', 'x' => 0, 'y' => 0, 'w' => 7, 'h' => 7, 'min_level' => 1, 'ground' => 'grass'],
        ['key' => 'bamboo', 'name' => '竹林', 'x' => 7, 'y' => 0, 'w' => 5, 'h' => 7, 'min_level' => 4, 'ground' => 'bamboo'],
        ['key' => 'beach', 'name' => '海辺', 'x' => 0, 'y' => 7, 'w' => 7, 'h' => 5, 'min_level' => 7, 'ground' => 'sand'],
        ['key' => 'hill', 'name' => '丘', 'x' => 7, 'y' => 7, 'w' => 5, 'h' => 5, 'min_level' => 10, 'ground' => 'hill'],
    ],
    'landmarks' => [ /* 今の5つ ＋ bamboo_grove 3つ・pier 1つ */ ],
    'paths' => [ /* 今の道 ＋ (7,3)〜(11,3) */ ],
    'spru' => ['x' => 1, 'y' => 3],
],
```

- 目印・道がどの区画のものかは、座標がどの区画に入っているかで決める（設定に区画のキーは書かない）
- `asset_keys` に `stone_lantern`・`bamboo`・`fountain`・`palm`・`parasol`・`pagoda`・`castle`・`tower` を足す（管理画面のショップ編集の絵の選択肢にも増える）
- `asset_footprints` を足す: `['fountain' => 2, 'pagoda' => 2, 'castle' => 2, 'tower' => 2]`（書いていない絵は1）

### 4-3. サーバーの部品

| 部品 | 役目 |
|---|---|
| `WorldLand`（作り直し） | レベルを受け取り、そのレベルで開いている区画・目印・道・置けないマスを返す。地図の大きさ（区画から計算）、マスがどの区画か、開いているか、を判定する |
| `WorldPlacement`（新規） | アイテムを (x, y) に置けるかを確かめる。使うマス（1マスか4マス）を出し、4-4の順にチェックして、だめなら422を返す |
| `ShopItem::footprint()`（新規） | 絵から大きさ（1か2）を返す |
| `ProfileWorldItem::toWorldArray()` | `footprint` を足す |

- 置けるかのチェックは、使うマスすべてについて次の順に調べ、最初に当てはまったものを返す（1つ目の条件を全マスで調べてから2つ目へ）
  1. 地図の外 → 「土地の外には置けません。」
  2. 雲の区画 → 「まだ雲に隠れているよ。」
  3. 目印・道 → 「そこには置けません。」
  4. ほかのアイテムと重なる（自分自身は除く） → 「そこにはもう置いてあります。」

### 4-4. API

- `GET /api/world`
  - `land` を次の形にする: `{ width, height, plots: [{ key, name, x, y, w, h, min_level, ground, unlocked }], landmarks, paths, blocked, spru }`
    - `width`・`height` は地図全体の大きさ（今は12×12）。今の `size` はなくす
    - `plots` は雲の区画も含めてすべて返す（雲の札を出すため）
    - `landmarks`・`paths`・`blocked` は開いている区画のものだけ
  - `items`・`bag` の各アイテムに `footprint`（1か2）を足す
  - `plots_new` を足す: 開いているが、まだ祝っていない区画のキー（`town` は入らない。必要レベルの低い順）
- `POST /api/world/plots/seen`（新規）: `{ keys: string[] }` のうち、開いている区画だけを祝った印として記録し、`{ plots_new }` を返す
  - 雲の区画・知らないキーは記録しない（エラーにもしない）
  - トランザクションの中でプロフィールを `lockForUpdate` してから行う
- `PATCH /api/world/items/{id}`
  - トランザクションの中でプロフィールを `lockForUpdate` してから、`WorldPlacement` でチェックする（2か所から同時に置いても、4マスが重ならない）
  - 一意の制約にぶつかったときの「そこにはもう置いてあります。」は残す
- `GET /api/shop`: 町のアイテムに `footprint` を足す
- `GET /api/family/{profile}`: `land` をその人のレベルで返す。`items` に `footprint` を足す
- 回答API・ステージクリア・購入・おつかい・種まき・水やりのAPIは変えない（レベルが上がったことの知らせは今のまま。区画が開いたことは町を開いたときに `plots_new` でわかる）

## 5. 画面

### 5-1. 町の画面の地図の枠

- 新しい部品 `town-map.tsx`（地図の枠）で、今の `WorldScene` を包む
  - 枠の高さ・最初の位置・縮尺は3-3のとおり。枠は横にも縦にもスクロールできる
  - マウスのドラッグ、矢印キー（枠に `tabIndex=0` と読み上げ用のラベル「町の地図。矢印キーで動かせます」）、［スプルの家へ戻る］
  - 外から「この区画を見せて」と頼まれたら、その区画の真ん中が枠の真ん中に来るように動く（区画のお祝いで使う）
- `WorldScene` は、四角でない土地を描けるようにする
  - 海は地図全体の下に描く。土地の側面は、手前に土地が続かないマスごとに描く（開いている区画の形に沿う）
  - マスの色は区画の地面（`grass`・`bamboo`・`sand`・`hill`）で変える。道のマスは今と同じ色
  - 雲の区画は、地面を描かずに雲を重ね、札（「竹林 Lv.4で解放」）を押せるボタンにする（ふりがなが付くよう、札の文字はSVGでなくHTMLで出す）
  - 2×2の建物は4マスの真ん中に描き、押せる範囲も大きくする
- 町の上に出るもの（名前の札・おつかい・にぎやか度・家族の町・つづきから学ぶ）は枠の外にあり、スクロールしても動かない

### 5-2. 雲とお祝い

- お祝いのカード `plot-unlock-card.tsx`: 喜ぶスプル（`cheer`）、「竹林エリアが広がったよ！」、区画ごとのひとこと（竹林「竹がさらさら鳴ってるよ」、海辺「海のにおいがするね！」、丘「ここなら大きな建物が建てられそう！」）、［見に行く］
- ［見に行く］→ カードを閉じる → 地図を区画へ動かす（約0.6秒）→ 雲が散る（約1.2秒）→ `POST /api/world/plots/seen` に祝った区画のキーを送る
  - 送るのに失敗しても画面はそのまま（次に町を開いたときにもう一度祝うだけ）
- 雲が晴れた直後、スプルが「竹林に行けるようになったよ！」と言う

### 5-3. 大きな建物の下見

- 置く場所を選ぶ状態（今の `PlacementBar`）で、2×2の建物のときは次のように変わる
  - 光るマス: 建物の奥のマスにできるマス（4マスが置ける条件を満たすところ）
  - 光るマスを押す → 4マスが別の色で光り、建物の絵がうすく出る（下見）。案内は「ここに建てる？」、ボタンは［ここに建てる］［やめる］
  - ［ここに建てる］→ 今の1マスのときと同じく、先に画面へ反映してからAPIを呼ぶ。失敗したら元に戻して理由を出す
- 1マスのアイテムの置き方は変えない

### 5-4. ショップ・バッグ

- 2×2の建物のカードに「2×2マス」の小さな札を出す
- 並び順・買い方・レベル不足／ポイント不足の出し方は今のまま

### 5-5. 家族の町

- 地図の枠で見る（その人の開いている区画・その人の建物）。雲の札は押せない（見るだけ）
- お祝いのカードは出さない

## 6. 素材

- アイテムの絵（`components/world/item-art.tsx`、SVG）: 竹・噴水・ヤシの木・ビーチパラソル・五重塔・お城・タワーの7つを新しく描く。石灯籠は目印の灯籠の絵を使う
- 目印の絵（`components/world/landmark-art.tsx`、SVG）: 竹やぶ（`bamboo_grove`）・桟橋（`pier`）を新しく描く
- 雲: SVGで描く（区画の大きさに合わせて、いくつかの丸を重ねた形）
- スプル: 今ある画像（`cheer` など）を使う。新しい画像は使わない
- 有料の素材は使わない

## 7. テスト

### バックエンド（Pest）
