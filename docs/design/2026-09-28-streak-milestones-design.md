## 1. 背景と目的

連続プレイ（毎日遊んだ日数）は、1日の最初の答えで1つ伸び、7日ごとに50コインがもらえる。今は答えのカードに「N日連続プレイ！」の1行が出るだけで、しかも正解のときしか出ないため、1日の最初の答えをまちがえると連続が伸びたことに気づけない。

Ownerが mascot-11 に「連続プレイの節目」のバッジ（3日・7日・30日の炎）を用意した。節目に届いた日を全画面でお祝いし、もらったバッジをパスポートに残して、「毎日つづけるとうれしい」をゲームらしく見せる。

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| お祝いを出す場所 | 答えのカードで「つぎへ」を押したあと、レベルアップと同じような全画面で出す。正解でも不正解でも出す |
| ごほうび | 今のまま（7日ごとに50コイン）。お祝いの画面ではバッジと、もらえる日はコインも見せる。コインの入り方は変えない |
| 2回目以降 | 連続が途切れて、もう一度節目に届いたときも毎回お祝いする。初めては「バッジをゲット！」、2回目からは「またN日つづいたね！」と言い分ける |
| 作り方 | 案A: 節目の判定と「初めてか」をサーバーで決めて返す。DBは変えない |
| 節目 | 3日・7日・30日の3つだけ（素材が3つのため）。30日より先の節目は今回は作らない |

## 3. サーバー側

### 3-1. 節目の決めごと

- 節目の日数は `UserProfile` の連続プレイの決めごと（`STREAK_TIMEZONE` など）の並びに、`public const STREAK_MILESTONES = [3, 7, 30];` として1か所に書く。パスポートのAPIもこれを読む

### 3-2. 連続が伸びたとき（`registerDailyStreak()`）

- 返す配列に次の2つを足す
  - `milestone`（`int|null`）: 伸びたあとの連続日数が節目なら、その日数。ほかは `null`
  - `milestone_first`（`bool`）: 初めてその節目に届いたか。**伸びる前の**いちばん長い連続（`best_streak`）が節目より短ければ `true`
- 例: いちばん長い連続が10日の人が、途切れたあとにまた7日に届いたら `milestone = 7`、`milestone_first = false`
- 同じ日の2問目からは連続が伸びないので、`milestone = null`、`milestone_first = false`
- 7日ごとの50コイン（`milestone_bonus_coin`）の決め方は変えない

### 3-3. 答えのAPI（`POST /api/questions/{question}/answer`、`routes/api.php`）

- 返す `profile` に `streak_milestone`（`int|null`）と `streak_milestone_first`（`bool`）を足す。ほかの項目は変えない

### 3-4. パスポートのAPI（`GET /api/passport`）

- 次の2つを足す
  - `best_streak`（`int`）: いちばん長い連続。プロフィールを選んでいなければ 0
  - `streak_milestones`: 節目ごとに `{ "days": 3, "earned": true }` の配列（3日・7日・30日の順）。`earned` は「いちばん長い連続が節目以上」。一度もらったバッジは、連続が途切れても消えない
- DBは変えない（`best_streak` はもとから記録している）

## 4. 画面

### 4-1. バッジの画像

`tools/spru-assets/crops.json` の `badges` に、mascot-11 の3段目の文字入りの炎を3つ足す（キーは `BadgeKey` になる）。文字なしの炎は今回は使わない。

| キー | 素材 | 範囲 [左, 上, 右, 下] | 縮小 |
|---|---|---|---|
| `streak-3` | m11 | [226, 490, 372, 628] | 0.85 |
| `streak-7` | m11 | [408, 478, 564, 628] | 0.85 |
| `streak-30` | m11 | [600, 466, 784, 630] | 0.85 |

### 4-2. 計算だけの部品（Vitestでテストする）

`frontend/src/components/quiz/streak-milestone.ts`

- `streakMilestoneBadge(days)`: 3→`"streak-3"`、7→`"streak-7"`、30→`"streak-30"`、ほかは `null`
- `streakMilestoneLine(days, first)`: 初めては「バッジをゲット！パスポートに入れたよ」、2回目からは「また{days}日つづいたね！」

### 4-3. お祝いの画面（`StreakMilestoneOverlay`、新規）

`frontend/src/components/quiz/streak-milestone-overlay.tsx`。見た目は `LevelUpOverlay` にそろえる（暗めの幕の上にクリーム色のカード、`z-[60]`、`role="dialog"`）。

- 大きなバッジ（`BadgeImage`、高さ120px、ポンと出る動き）と、横で応援するスプル（`SpruFigure` の `cheer`）
- 見出し「{days}日連続プレイ！」
- その下に `streakMilestoneLine(days, first)`（ふりがな付き）
- 7日ごと（ボーナスコインがある日）は「ボーナス +50Coin」
- いちばん下に「つづける」ボタン。開くときにレベルアップと同じ音（`allCorrect`）を鳴らす

### 4-4. クイズの流れ（`quiz-session.tsx`）

- 答えの結果に `streak_milestone` があれば、「節目のお祝い待ち」として覚えておく（日数・初めてか・ボーナスコイン）
- 「つぎへ」を押したときの順番: レベルアップ（あれば）→ 節目のお祝い（あれば）→ 次の問題（最後なら結果画面）
- 「つづける」で閉じたら「お祝い待ち」を消す。「もう一度」・やり直しでも消す
- 答えのカードの「N日連続プレイ！」の行は、正解・不正解のどちらでも出す（今は正解のときだけ）

### 4-5. パスポート（`/passport`）

- 国スタンプと称号の間に「連続プレイのバッジ」の欄を足す
- 3つのバッジを横に並べる（高さ72px）。もらったものはカラー、まだのものは国スタンプと同じく白黒で薄く出す
- 画像の説明文は「3日連続のバッジ（もらった）」「…（まだ）」のようにする
- 下に「いちばん長い連続: N日」
- 「あとN日」は出さない。今の連続日数は次に答えるまで更新されないため、途切れたあとは数字がずれる

## 5. テスト

### バックエンド（Pest）

- 連続が3日・7日・30日に伸びた日は、その日数が返る。2日・4日・14日は `null`
- 初めて届いたときは `milestone_first = true`、いちばん長い連続がすでに節目以上なら `false`
- 同じ日の2問目は `milestone = null`
- 答えのAPIの `profile` に `streak_milestone` と `streak_milestone_first` が入る
- パスポートのAPIに `best_streak` と `streak_milestones`（`earned` の正しさ）が入る

### フロントエンド（Vitest）

- `streakMilestoneBadge` と `streakMilestoneLine`

### ブラウザでの確認（Playwright、390px と 1280px）

- 開発DBの「町テスト」を一時的に「きのう遊んだ・連続2日」にして、答えたら3日のお祝いが出る（初めての言い方）。不正解でも出る
- レベルアップと重なったときの順番
- パスポートの「連続プレイのバッジ」の欄（カラー・白黒）
- 確認のあと、開発DBを元に戻す

## 6. やらないこと

- 30日より先の節目（60日・100日など）
- 節目でのコインの追加（今の7日ごとの50コインのまま）
- ヘッダーの炎を連続日数に合わせて変えること
- バッジをもらった日の記録（DBの表を足す案Cは採らない）
- パスポートの「あとN日」

## 7. 完了の条件

- 3日・7日・30日に届いた日に、全画面のお祝いが出る（正解・不正解のどちらでも、初めてと2回目以降で言い分ける）
- パスポートに、もらった連続プレイのバッジが残る
- テストがすべて通り、型チェックとlintも通る
- `SPEC.md` と `TASKS.md` を更新する
