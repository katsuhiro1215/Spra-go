## 1. 背景と目的

今は3つのタブが別々のルールで進む。

- 「学ぶ」: コンテンツのある国がすべて最初から開いている（2026-07-31に「入口は自由・国のロックは採用しない」と決めた、`SPEC.md` 4-3）
- 「旅する」: 日本の島から インドネシア(Lv.7) → 韓国(Lv.9) → アメリカ(Lv.11) → イギリス(Lv.13) → フランス(Lv.15) の1本道。行くにはレベル・町のアイテム・前の国のボスのおみやげがいる
- 「世界」（真ん中）: 自分の町

英語を学びたい人がいちばん多いのに、アメリカに「着く」のはLv.11・3か国目。学ぶタブではもうアメリカの英語を学べるのに旅では行けない、というねじれがある。行き先を選ぶ楽しさもない。また「世界」タブは町で、国の地図は「旅する」タブにあり、名前がまぎらわしい。

2026-09-26のコンセプト「学ぶほど、世界が広がる（学ぶ → レベルアップ → 新しい国が開く）」に合わせ、**日本から始めて、クイズで手に入れたチケットで好きな国へ行く**形に作り直す。学ぶタブも旅に合わせ、進め方を1本にそろえる。7月の「入口は自由」は、このコンセプトより前の決めごとなので改める。

当面は国内（日本語話者）向けとし、世界展開は範囲に入れない。

## 3. 遊びのルール

### 3-1. 国の状態

- **日本**: はじまりの国（`config/travel.php` の `home`）。最初から学べる。旅の行き先には入らない
- **旅の行き先（5か国）**: 次の2つの状態だけ
  - **着いた国**（`visited`）: 一度出発した国。いつでも行け、いつでも学べる
  - **まだの国**（`unvisited`）: まだ出発していない国。チケットがあれば出発できる
- F回の「次の行き先（`next`）は1つだけ」「まだ先の国（`later`）」はなくす

### 3-2. チケット

- **もらえるとき**: 「学べる国」（日本と着いた国）で、初級のボス（どのカテゴリーでもよい）を初めて倒したとき1枚。1か国1枚まで
- **使うとき**: まだの国へ出発すると1枚減る。着いた国へは何度でもチケットなしで行ける
- **数え方（A案）**:
  - もらった数 ＝ 学べる国のうち、初級のボスをクリアした国の数
  - 使った数 ＝ 着いた国の数（`profile_trips` の行の数）
  - 持っている数 ＝ max(0, もらった数 − 使った数)
- まだの国が残っていないとき（5か国ぜんぶ着いた）は、チケットが余っても画面に出さない（`tickets` は 0 として返す）
- 学ぶタブで先にクリアしていても数える（クリアの記録は1つ）。ただし鍵の国は学べないので、実際には学べる国のクリアだけが数に入る

### 3-3. やめる条件

- 行き先ごとの必要レベル・町のアイテム・前の国の2個目のおみやげは、旅の条件でなくなる
- 小さな船・自転車・大きな船・お城・タワーは、町のアイテムとして残る（ショップの「旅じたく」の札だけ外す）
- 町のスプルの「旅のじゅんびがそろったよ」はなくし、チケットの知らせに変える（5-7）

### 3-4. おみやげ

- 今のまま。1個目＝その国のステージを1つクリア（1マス）、2個目＝その国の初級のボスをクリア（2×2）。着いた国のおみやげ屋さんで受け取る
- 旅の条件ではなくなり、ごほうびだけになる

### 3-5. 乗り物

| 行き先 | 乗り物 |
|---|---|
| 韓国・インドネシア | 船（`ship`） |
| アメリカ・イギリス・フランス | 飛行機（`plane`） |

- 変わるのは出発の場面と、カード・パスポートのアイコンだけ。チケットは同じ1種類

### 3-6. 学ぶタブの鍵

- 学ぶタブに並ぶのは、日本と旅の行き先の国（コンテンツがあるものだけ）。日本が先頭、そのあと `config/travel.php` の並び順
- **鍵の国** ＝ 旅の行き先のうち、まだ着いていない国
- 鍵の国のステージは、サーバーでも遊べない（国・地域の画面、ステージを開く、ステージを終える、のどれも断る）。ミニアプリのステージ一覧からも外す
- 旅の行き先に入っていない国（今はテスト用のイタリアの地域のステージ1つだけ）は、学ぶタブに出さず、鍵もかけない。国のないステージにも鍵をかけない
- 未ログインのお試しクイズ（`/world/[code]`）は今のまま（だれでも3問遊べる）

### 3-7. 今のデータ

- 公開前だが、テストのプレイヤーが困らないように、すでにステージをクリアしている行き先の国は「着いた国」として記録する（着いた日＝その国で最初にクリアした日）。行を足すだけで、今のデータは消さない
- 2026-09-28時点で当てはまるのは、かっちゃん（id 2）のアメリカだけ。町テスト・検証太郎がクリアしているのはイタリア（行き先でない）なので変わらない
- 使った数が多くなっても、持っている数は 0 で止まる

### 3-8. 流れの例（新しいプレイヤー）

1. 日本の初級1〜4をクリアし、ボスを倒す
2. クイズの結果に「チケットを手に入れた！」
3. 「せかい」でアメリカを選び、飛行機で出発する
4. アメリカで英語を学ぶ
5. アメリカの初級のボスを倒して2枚目をもらい、次の国を選ぶ

## 4. 設定とサーバー

### 4-1. 設定（`config/travel.php`）

- `home` を足す: `['key' => 'jp', 'name' => '日本', 'country_code' => 'jp']`
- 各行き先から `min_level`・`items` を消し、`transport`（`'ship'` か `'plane'`）を足す
- おみやげの行の形（1行1つ）は今のまま（画面の `art-keys.test.ts` が読む）

### 4-2. 旅の計算（`app/Support/Travel.php`）

| 関数 | 中身 |
|---|---|
| `homeCountryId()` | 日本の国のid（なければ null） |
| `learnableCountryIds(?UserProfile)` | 日本と着いた国の国のid |
| `lockedCountryIds(?UserProfile)` | 旅の行き先のうち、まだ着いていない国の国のid（プロフィールがなければ行き先ぜんぶ） |
| `abortIfLocked(?UserProfile, ?int $countryId)` | 鍵の国なら 403「まだこの国に着いていません。」。国のid が null なら何もしない |
| `earnedTickets(UserProfile)` | もらった数（0で止めない。「新しく増えたか」の判定に使う） |
| `tickets(UserProfile)` | 持っている数（3-2。まだの国がなければ 0） |
| `ticketHint(UserProfile)` | 学べる国のうち、初級のボスをまだ倒していない最初の国の名前（日本が先、そのあと行き先の順）。なければ null |
| `state(UserProfile)` | 行き先の一覧（4-3） |
| `depart(UserProfile, $key)` | 着いた国なら `first: false`。まだの国はチケットが1枚以上なければ 422「チケットがありません。」。あれば `profile_trips` に1行足す（プロフィールはロック済みで呼ぶ） |
| `receive(...)` | 今のまま |
| `recordTripsForClearedCountries()` | 3-7 のデータの記録（マイグレーションから呼ぶ。着いていない行き先の国だけ足す） |

- 消すもの: `checklist`・`ready`・`nextIndex`・`gearAssetKeys`・`shop_levels` の計算

### 4-3. API

| API | 変更 |
|---|---|
| `GET /api/travel` | `{ level, tickets, ticket_hint, destinations }`。行き先は `key, name, country_id, code, flag, transport, state(visited/unvisited), can_depart, souvenirs, souvenir_count, gift_ready, greeting`。まだの国の `souvenirs` は空の配列（名前を返さない）、`souvenir_count` は2。`can_depart` はまだの国でチケットが1枚以上のとき true。`checklist`・`ready`・`min_level` は消す |
| `GET /api/travel/{key}` | 今のまま（着いた国だけ） |
| `POST /api/travel/{key}/depart` | 4-2 の `depart`。今と同じくトランザクションとプロフィールのロックの中で数えるので、連打しても2枚減らない |
| `GET /api/countries` | 日本と行き先の国（コンテンツがあるもの）だけ。日本が先頭、そのあと行き先の順。各国に `locked` を足す。`is_suggested`（Accept-Languageから推定）と、それによる並べ替えはやめる |
| `GET /api/countries/{country}` | 鍵の国なら 403 |
| `GET /api/regions/{region}` | 地域の国が鍵の国なら 403 |
| `GET /api/stages/{stage}` | ステージの国が鍵の国なら 403 |
| `POST /api/stages/{stage}/complete` | ステージの国が鍵の国なら 403。応答に `ticket_earned`（このクリアで `earnedTickets` が増え、まだの国が残っているとき true）を足す |
| `GET /api/categories/{category}/stages` | 鍵の国のステージを外す（ミニアプリ） |
| `GET /api/world` | `travel_ready` をやめ、`tickets`（持っている数）を返す |
| `GET /api/shop`（町のアイテムの一覧） | `travel_gear` をやめる |
| `GET /api/passport` | `trips`（着いた国: `key, name, flag, transport, arrived_at`、着いた順）を足す |

- 鍵の判定は、そのとき選んでいるプロフィール（セッションの `active_profile_id`）で行う。プロフィールがなければ、行き先の国はすべて鍵
- 未ログインのお試しクイズ（`/api/public/...`）は変えない

### 4-4. データ

- 新しい表・列は作らない
- マイグレーション `2026_09_28_000002_record_trips_for_cleared_countries`: `Travel::recordTripsForClearedCountries()` を呼ぶ。行を足すだけ（戻すときは何もしない）

## 6. テスト

### 6-1. サーバー（Pest）

- チケット: 日本の初級ボスで1枚／着いた国の初級ボスで1枚増える／同じ国で2つ目の初級ボスを倒しても増えない／中級のボスや普通のステージでは増えない／出発すると減る／0より少なくならない／ぜんぶ着いたら 0
- `ticket_hint`: 日本のボス前は「日本」／日本を倒してアメリカに着いたら「アメリカ」
- 出発: チケットがあれば出発でき `first: true`／なければ 422／着いた国への2回目は `first: false` でチケットが減らない／ない行き先は 404
- 一覧: まだの国はおみやげの名前を返さない／`can_depart` がチケットの有無で変わる
- 学ぶの鍵: 国の一覧が日本 → 行き先の順／鍵の印／イタリアを出さない
- 鍵の国: 国の画面・地域の画面・ステージを開く・ステージを終えるが 403／日本・着いた国・行き先でない国・国のないステージは遊べる
- ミニアプリ: 鍵の国のステージが一覧に出ない
- `ticket_earned`: 日本の初級ボスを初めて倒したとき true／2回目・普通のステージ・ぜんぶ着いたあとは false
- まち: `tickets` を返す。パスポート: `trips` を着いた順に返す。ショップ: `travel_gear` がない
- データの記録: クリアした行き先の国が着いた国になる（着いた日＝最初のクリア）／行き先でない国は足さない／もう着いている国は足さない
- F回の旅のテスト（`TravelTest.php`・`TravelActionsTest.php`、旅のじゅんびリストが前提のもの）は新しいルールに書き直す

### 6-2. 画面（Vitest）

- スプルのひとこと（`hubLine`）の4つの順番
- 島の札（`islandTag`）と読み上げ用のラベル（`islandLabel`）
- 出発の場面の文（船・飛行機）
- 学ぶタブの鍵の国の並べ分け
- メニューの名前（「せかい」「まち」）
- まちのスプルのひとこと（チケットがあるとき）

### 6-3. ブラウザでの確認

- スマホ（390px・320px）とパソコン（1280px）
- 一時的に作ったプレイヤーで: 学ぶタブの鍵 → 日本の初級ボス → 結果の「チケットを手に入れた！」→ せかいでアメリカ → 飛行機の場面 → アメリカの英語、の流れ
- 鍵の国のURLを直接開いたときの案内
- 終わったら一時的なプレイヤーを消し、町テストのデータ（連続・XP・コイン・HP・ポイント・アバター・おつかい）がもとのままかを確かめる

## 7. やらないこと

- 世界展開（日本以外の国から始める）
- チケットの表（B案）。イベントや親からのプレゼントなど、ほかの手に入れ方を足すときに移る
- 行き先の国を増やすこと（今の5か国のまま）
- 「今いる国」や移動にかかる時間（F回と同じく持たない）
