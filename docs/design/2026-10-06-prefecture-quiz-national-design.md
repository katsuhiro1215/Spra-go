# 都道府県クイズ「全国」（段階3）— 設計書

- 作成日: 2026-10-06
- ステータス: 案（Ownerの承認待ち）。Owner合意済み（都道府県クイズの設計、2026-10-05）: 全国は、47県を混ぜた最難関で、3級とも称号あり。ステージの分け方・知名度の使い方・問題の形は、この設計書で決める
- 前提: 都道府県クイズ（`docs/design/2026-10-05-prefecture-quiz-design.md` 5-3）、国旗クイズの「世界ぜんぶ」（`docs/design/2026-10-05-flag-quiz-design.md` 4章）、地方まるごと（`PrefectureQuizPlanner::regionLevels`）
- 対応するタスク: `TASKS.md` 都道府県クイズ 段階3

## 1. 目的

都道府県クイズの最後のコース「全国」を作る。県のコース・地方まるごとで覚えた知識を、47県を混ぜて試す、いちばん難しいコース（メインゲームになるコース）。

**うまくいった目安**

1. 都道府県クイズを開くと、6つの地方のあとに「全国（ちょうむずかしい）」が出る
2. 初級・中級・上級を、順に進める。各級は、複数のステージを順にクリアし、最後のボスで次の級が開く
3. 初級は、知られた県（知名度の高い県）だけ。中級・上級は47県すべて
4. 各級のボスを全問正解すると、称号がもらえる（全国みならい・全国めいじん・全国はかせ）
5. データ表を直して再実行すると、問題が直る（画面は直さない）

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 場所 | 大もと「都道府県クイズ」の直下のコース（地方と同じ階。`is_course_group` ではない）。名前「全国」、地方のあとの最後（`order` 7）。コースの選択に、「ちょうむずかしい」のひと言（国旗クイズの「世界ぜんぶ」と同じ） |
| 出す条件 | 47県すべてに、事実がそろったときだけ（今はそろっている） |
| 級 | 初級・中級・上級。各級は、**複数のステージ（各10問）＋最後のボス（10問）** |
| ステージの数 | 級に出す県の数を10で割った切り上げの数だけ、県をなるべく均等に分ける（1ステージ9〜10県）。初級は知名度1・2の30県 → 3ステージ＋ボス。中級・上級は47県 → 5ステージ＋ボス |
| 知名度 | データ表に `tier`（1＝とてもよく知られた県、2＝よく知られた県、3＝あまり知られていない県）を足す。初級は `tier` 1・2だけ。ステージの順は、`tier` の小さい県（知られた県）から先、同じ `tier` はデータ表の順 |
| ボス | その級の県から、名前から決まる順に10県（同じ表からは同じ計画）。ステージと同じ形の問い |
| 称号 | **3級とも、ボスに付く**: 初級「全国みならい」・中級「全国めいじん」・上級「全国はかせ」（国旗クイズの「◯◯の国旗みならい／めいじん／はかせ」と同じ呼び方）。バッジの絵は、ない（称号の文字だけ） |
| 問題のもと | 地方まるごとと同じ。県のデータ表から、純粋な計算が作る |

## 3. 問題の形

地方まるごと（`PrefectureQuizPlanner::regionForm`）と同じ「アンカーの県を1つずつ決めて、その県の問いを1問」の作り。10問に足りない（9県の）ステージは、1県が2回当たる（2回目は形を替える）。

| 級 | 1〜10問目 | まちがいの選択肢 |
|---|---|---|
| 初級 | 奇数番＝逆（名物から県）、偶数番＝逆（名所から県）、9問目＝何地方か、10問目＝逆（お祭りなど） | 全県から（ぜんぜんちがう県） |
| 中級 | 3・8問目＝はめ込み、1・6問目＝県庁所在地、2・7問目＝県庁所在地の逆、4・9問目＝何地方か、5・10問目＝となりの県 | 同じ地方の県から |
| 上級 | 3・8問目＝はめ込み、1・4・7・10問目＝難読地名、2・5・9問目＝となりの県、6問目＝逆（お祭りなど） | となりの県から（足りなければ同じ地方、全県） |

- 同じ県が2回当たるとき（ステージの9県、ボス）は、2回目（`round`＝1）に、事実・難読地名の番号を替える。同じ問いは、1ステージに2回出ない（今の予備の仕組みで守る）
- ボスは `round`＝1 を使い、ステージ（`round`＝0）とは、別の事実・難読地名の問いになりやすくする
- 作れない形（となりのない北海道・沖縄の「となり」、同じ文字が2県にある事実の逆）は、今の予備の問いに替える

## 4. 計画・書き込み

- `PrefectureQuizPlanner::plan()` が返す一覧の最後に、全国のコース（`group` なし。`key = national`・`name = 全国`・`order = 7`）を足す。47県すべてが `isReady` のときだけ
- 級の計画は、`nationalLevels`（新設）。県の並び（初級は `tier` ≤ 2）を、`tier`・データ表の順に並べ、`ceil(n/10)` の組に均等に分け、各組が1ステージ。最後に、ボスのステージを足す。ボスは `title_reward`（上のとおり）
- 問題の目印は `pref:national:{級}:{ステージ}:q{番号}`
- 書き込み（`FlagQuizWriter::writeTree`）は、直下のコース（`group` なし）を今でも書けるので、変えない

## 5. 画面

- 「全国」のカードは、「ちょうむずかしい」の札つき（今の `WORLD_COURSE_NOTE` の仕組みに、名前「全国」を足す）。絵はなし（県のバッジの形ではないため）。あとで絵が届いたら、`COURSE_IMAGES` に足すだけで出る
- 称号の表示（結果のカード）は、今のまま（「称号『全国はかせ』を獲得しました！」。バッジの絵は付かない）
- ほかの画面（パスポートの称号の一覧など）は、変えない

## 7. テスト

- **サーバー（Pest）**: データ表（47県すべてに `tier` が1〜3・数は 14・16・17）、計画（全国のコースが最後に出る・47県そろっていなければ出ない・3級・初級は3ステージ＋ボス、中級・上級は5ステージ＋ボス・どのステージも10問・称号は3級のボスだけ「全国みならい／めいじん／はかせ」・初級は `tier` ≤ 2 の県だけがアンカー・中級・上級は47県すべてが、ステージのどこかでアンカーになる・同じ問いが1ステージに2回出ない・正解が1つ・同じ表から同じ計画・はめ込みが3・8問目・上級に難読地名が4問）、書き込み（直下のコースとして書かれる・二重実行で増えない・ステージの順と鍵）、コースの窓口（全国が `group = false`・`title = 全国はかせ`）、ミニクイズの数え方
- **ふりがな**: 計画に出る文字の漢字が、辞書で読める（今のテストが、全国の問いも確かめる）
- **画面（Vitest）**: 「全国」に札が出る判定
- **ブラウザ**: 都道府県クイズに「全国」が出る・初級→ステージの鍵（1つ目だけ開く）・ボスで次の級が開く・称号。確認のあと、開発用のデータを元に戻す
