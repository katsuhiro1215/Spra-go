# 道を道路らしく描く（縁・曲がり角・道のしるし）— 設計書

- 作成日: 2026-10-09
- ステータス: 実装済み（2026-10-09）。Owner合意済み（2026-10-09。順番は ①縁→③国ごとの縁→②道のしるし。日本の道は土の道のまま、縁なしで草となじませる）
- 前提: `docs/design/2026-10-05-road-style-design.md`（国の道）。クレヨンしんちゃんのゲーム・Global Cityの道を目安に、できるだけ現実の道路に近づける

## 1. 目的

今の道は、平らな絵を道のマスに貼っただけで、縁がなく、曲がり角が角ばっている。道を1本のつながった道路として見せる。絵（路面）は今のまま使い、**描き方だけ**を変える（新しい絵は作らない）。

## 2. 今の描き方

- 道のマスを1マスずつ、路面の絵（`road_*`）で塗る（`world-scene.tsx`）。縁は、道が草地に接する辺に、薄い茶色の細い線を引くだけ（`ground.ts` の `pathEdges`）。

## 3. 決定事項

| 段階 | 中身 |
|---|---|
| ① 縁 | 道が草地に接する辺に、**縁の帯**（道の内側）と**細い外線**を引く。線の端と曲がり角は丸くする。帯と線は、道のマスの内側だけに描く（草にはみ出さない）。マスごとの塗りの継ぎ目が出ないよう、塗りの縁を少し重ねる |
| ③ 国ごとの縁 | 縁の色・太さは道の種類で決める（`components/travel/road.ts` の `roadEdge`）。日本・インドネシア＝縁の帯なし（土の道。今までの薄い茶色の線だけ）。アメリカ＝明るい灰色の歩道＋濃い灰色の外線。韓国＝灰色の石の縁。イギリス＝濃い青灰の石の縁。フランス＝ベージュの石の縁 |
| ② 道のしるし | アスファルトの道（アメリカ）だけ、道の真ん中に白い破線。交差点（3方向以上につながるマス）の手前に横断歩道。道の中心線は、つながる道のマスの中心を結ぶ |

## 4. やらないこと

- 新しい絵（道の部品の絵）。描き方で足りなければ、「区画ごとの絵と道の部品」の作業で考える。
- 道の幅を広げる、道の位置を変える、歩く人や車。
- 写真のような質感（汚れ・影）。

## 5. テスト

- `roadEdge(style)`: 種類ごとの縁（帯の有無・色・太さ）。知らない種類は日本と同じ。
- ②の線: 中心線と横断歩道を作る純粋な関数（1本道・曲がり・T字・十字・行き止まり）。
- ブラウザ: 日本の道（縁の帯なし）・アメリカ（縁・破線・横断歩道）・石畳の国で見る。スマホ幅。確認用のプロフィールは作って、確認後に消す。

## 6. 実装の順序

1. `roadEdge`（①③）と描画の差し替え、ブラウザ確認。
2. 道のしるし（②）と描画、ブラウザ確認。
3. SPEC・TASKSの更新。
