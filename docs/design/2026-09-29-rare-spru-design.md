## 1. 背景と目的

Owner が、レアスプル10色と仲間5人の新しい設定画を用意した。1体ずつ「種・芽・つぼみ・花」の絵がある。これを使って、**長く続ける目標**と**集める楽しさ**を足す。

B回の設計で決めた「お金でくじを引く形にしない」を守る。レアスプルは確率では出さず、**がんばった記念に必ずもらえる「特別な種」**から生まれる。

- ループ: 学ぶ・続ける・旅する → 条件を満たす → 特別な種をもらう → 畑にまく → 毎日学んで水をあげる → その色のレアスプルが生まれる → 相棒にする

**うまくいった目安**

1. 条件を満たすと、町を開いたときに特別な種がもらえ、畑でその色の種・芽・つぼみが育つ
2. 3回の水やりで、その色のレアスプルが生まれ、仲間と同じように相棒にできる
3. 「なかま」の一覧で、まだ手に入れていないレアスプルの条件と、あと何日・何回かが分かる
4. 町に立つのは5体までで、子どもが町に出す子を選べる
5. 仲間の種は、今までどおり生まれるまで誰か分からない

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| 手に入れ方 | **がんばった記念に「特別な種」をもらう**。条件を満たせば必ずもらえる。確率は使わない |
| 条件 | 10色それぞれに1つ（3-1）。**試験用の数字で入れ、触ってから調整する**。数字は設定ファイルで変えられる。一度渡した種は、条件を厳しくしても取り上げない |
| 生まれた後 | **仲間5人と同じあつかい**（町に立つ・なかよし度・名前を付ける・相棒にする・相棒の復習・家族の町に出る） |
| 町に立つ数 | **5体まで**。相棒はいつも町にいる。残りは「おうち」で休む |
| なかまの一覧 | 町のボタンに「なかま」を足す。生まれた子・まだの仲間・まだのレアスプル（条件と進み具合）を並べ、町に出す子を選ぶ |
| 畑での見た目 | **レアスプルはその色で育つ。仲間の種は、ふつうのスプル（緑）の種・芽・つぼみで育ち、生まれるまで誰か分からない** |
| 仲間5人 | 今のまま。まだいない仲間からランダムに1人、5つ目で全員そろう。そろった後のスプルの種からは「スプルの花」 |
| 作り方 | **今の仲間のしくみを広げる**。レアスプルは仲間の一覧（`config/companions.php`）に「レア」の印と条件を付けて足す |
| 仲間5人の絵 | 新しい設定画の正面の絵に差し替える（レアスプルと大きさ・描き方をそろえる） |
| 呼び名 | 「〇〇スプル」（ルビースプルなど） |
| リリ | 使わない。一覧にも出さない |

| 種類 | 満たしたかどうか | 一覧の「今の数」 | 単位 |
|---|---|---|---|
| `streak` | いちばん長い連続（`best_streak`）が目標以上 | 今の連続。昨日も今日も学んでいなければ0 | 日 |
| `trips` | 着いた国（`profile_trips`）の数 | 同じ | か国 |

- 「今の数」が目標以上になったら、目標の数で止める（一覧の棒があふれないように）
- `reviews` だけは今まで数えていなかったので、公開した日から数え始める。ほかは今ある記録で数えるので、公開前から満たしている子にもすぐ渡る

### 3-2. 特別な種をもらう

- 町を開いたとき（`GET /api/world`）と、なかまの一覧を開いたとき（`GET /api/world/roster`）に、10色の条件を確かめる
- 満たしていて、まだもらっていない色の種を渡す。**1色につき1回だけ**
- 新しく渡した種は、その返事の `new_seeds` に入れ、画面がお祝いを出す（5-2）。お祝いを見のがしても、種はふくろに残る
- もらった種は「種のふくろ」に入り、まくまでなくならない
- 家族の町を見ても、その人の条件は確かめない（見ている本人の町ではないため）

### 3-3. 畑にまく

- 畑は1つのまま
- まける種は2種類
  - **スプルの種**: スプルの育ち具合（レベルアップ3回）でできる。今までどおり
  - **特別な種**: ふくろの中の種。スプルの育ち具合に関係なく、いつでもまける。まいても育ち具合は戻らない
- 畑が空いているとき
  - ふくろに特別な種があれば、畑をタップすると「どの種をまく？」を出す（5-3）
  - ふくろが空で、スプルの種ができていれば、今までどおりすぐまく
  - スプルをタップしたときは、今までどおりスプルの種をまく（スプルの種ができているときだけ）
- 生まれるもの
  - スプルの種: 今までどおり。まだいない仲間からランダムに1人。5人そろった後は「スプルの花」
  - 特別な種: その色のレアスプル
- 畑が育っている間にもらった種は、ふくろで待つ

### 3-4. 水やりと見た目

水やりのルールは変えない（1日1回、その日に1問正解したら、3回で生まれる。休んでも枯れない）。

| 水やり | 状態（今のまま） | スプルの種（なぞ） | 特別な種 |
|---|---|---|---|
| 0回 | `seed` | 緑の種 | その色の種 |
| 1回 | `sprout` | 緑の芽 | その色の芽 |
| 2回 | `sprout_big` | 緑のつぼみ | その色のつぼみ |
| 3回 | （生まれる） | 花が咲いて生まれる | その色の花が咲いて生まれる |

- サーバーは畑の見た目を `look` で返す。スプルの種は、生まれる子にかかわらず `spru`（誰が生まれるかは出さない）。特別な種はその色のキー
- 「スプルの花」になる種も `spru` の見た目で育つ

### 3-5. 町となかまの一覧

- 町に立つのは5体まで（`config/companions.php` の `town_limit`）
- 相棒はいつも町にいる。**相棒にできるのは町にいる子だけ**
- 生まれた子は、町に空きがあれば町に立ち、いっぱいならおうちで休む
- 今いる仲間（最大5人）は、全員「町にいる」から始める
- 町に立つ順は今のまま（相棒が先頭、ほかは生まれた順）。町にいる子だけで、前から立ち位置を使う
- 一覧で「町に出す／おうちで休む」を切り替える
  - 町が5体でいっぱいなら、町に出せない
  - 相棒は休ませられない
- にぎやか度は、おうちで休んでいる子も含めて、生まれた全員で数える（今のまま）
- 家族の町には、町にいる子だけが立つ

## 4. データとサーバー

### 4-1. 表

**`profile_special_seeds`（新規）** — もらった特別な種

| 列 | 型 | 説明 |
|---|---|---|
| `id` | bigint | |
| `user_profile_id` | bigint | プロフィールが消えたら一緒に消す |
| `rare_key` | string | 色のキー（`ruby` など） |
| `granted_at` | timestamp | もらった日時 |
| `planted_at` | timestamp null | まいた日時。空ならふくろの中 |
| `created_at` / `updated_at` | timestamp | |

- `user_profile_id` と `rare_key` の組み合わせは1つだけ（同じ色が2回渡らない）

**`profile_companions`** — `in_town`（真偽、ふつうは真）を足す。今ある行は全部真

**`user_profiles`** — `reviews_completed`（0以上の整数、ふつうは0）を足す。`Review::complete` で1増やす

**`profile_seeds`** — 変えない。特別な種をまくと、`result_key` にその色のキーを入れた行を作る

### 4-2. 設定（`config/companions.php`）

- `list` にレアスプル10色を足す。1行の形:

```php
'ruby' => ['name' => 'ルビースプル', 'trait' => '赤・がんばる心', 'weight' => 0, 'rare' => true,
    'condition' => ['type' => 'streak', 'target' => 7], 'lines' => [ /* 3-6 の5つ */ ]],
```

- `weight` が0なので、スプルの種から選ばれることはない（今の `Garden::pickResult` は重みが0の子を外す）
- 並び順は 3-1 の表の順（一覧の並びに使う）
- `town_limit` => 5 を足す
- 条件の文とお祝いの一言（3-6）は、種類ごとに `condition_texts` にまとめる

### 4-3. 条件の係（`app/Support/RareSeeds.php`、新規）

- `progress(UserProfile)`: 10色それぞれの `key`・`type`・`target`・`current`（目標で止める）・`met` を返す
- `grant(UserProfile)`: 満たしていて、まだもらっていない色の種を作り、新しく渡した色の一覧を返す。プロフィールを `lockForUpdate` してから行う（同時に開いても2回渡らない）
- `bag(UserProfile)`: ふくろの中（`planted_at` が空）の色を、一覧の順で返す
- `isRare(string $key)`: 設定で `rare` が付いているか

### 4-4. 畑（`app/Support/Garden.php`）

- `state` に足すもの
  - `look`: 育っている種の見た目。`spru`・色のキー・空の畑なら `null`
  - `spru_seed_ready`: スプルの種ができているか（今の「育ち具合が3」）
  - `seed_bag`: ふくろの中 `[{ key, name }]`
  - `can_sow`: 畑が空いていて、スプルの種ができているかふくろに種がある
- `sow(UserProfile, string $seed = 'spru')`
  - `spru`: 今までどおり（育ち具合が3でなければ 422「まだ種ができていないよ」）
  - 色のキー: ふくろになければ 422「その種は持っていないよ」。`planted_at` を入れ、`result_key` がその色の種を畑に作る。育ち具合は戻さない
  - どちらも、畑に種があれば 422「畑に芽が育っているよ」（今のまま）
- `bloom`: 仲間を作るとき、町にいる子が `town_limit` より少なければ `in_town` を真、いっぱいなら偽にする。最初の仲間が自動で相棒になるのは今のまま
- `companions`: 全員を返し、各子に `rare`・`in_town` を足す。立ち位置（`x`・`y`）は町にいる子だけに、相棒を先頭にして前から付ける。おうちの子は `null`

### 4-5. API

どれもログインが必要（`auth:sanctum`）。遊んでいるプロフィールがなければ今と同じ扱い。

**`GET /api/world`**（変更）— 先に `RareSeeds::grant` を呼ぶ。足すもの:

```json
{
  "garden": {
    "state": "seed", "look": "ruby", "waterings": 0,
    "spru_seed_ready": false,
    "seed_bag": [{ "key": "silver", "name": "シルバースプル" }],
    "can_sow": false
  },
  "companions": [{ "key": "lumi", "rare": false, "in_town": true, "x": 0, "y": 3 }],
  "new_seeds": [{ "key": "ruby", "name": "ルビースプル", "reason": "7日続けて学んだね" }]
}
```

（`garden` と `companions` の今ある項目は省略）

**`POST /api/world/garden/sow`**（変更）— `seed` を受け取る（なし・`spru`・色のキーのどれか。ほかは 422）。返事は今と同じ

**`GET /api/world/roster`**（新規）— なかまの一覧。先に `RareSeeds::grant` を呼ぶ

```json
{
  "town_limit": 5,
  "town_count": 3,
  "members": [
    { "key": "lumi", "name": "Lumi", "rare": false, "status": "born", "in_town": true, "is_partner": true, "hearts": 2, "condition": null },
    { "key": "kuru", "name": "Kuru", "rare": false, "status": "waiting", "in_town": false, "is_partner": false, "hearts": 0, "condition": null },
    { "key": "ruby", "name": "ルビースプル", "rare": true, "status": "waiting", "in_town": false, "is_partner": false, "hearts": 0,
      "condition": { "text": "7日続けて学ぶ", "current": 4, "target": 7, "unit": "日" } }
  ],
  "new_seeds": []
}
```

- `status`: `born`（生まれた）・`growing`（畑で育っている）・`in_bag`（ふくろにある）・`waiting`（まだ）
- 仲間の `growing` は出さない（誰が育っているか分かってしまうため）。仲間は `born` か `waiting` だけ
- 名前は、生まれた子は付けた名前（なければ元の名前）。まだの仲間は元の名前も出さず `？？？`（生まれたときのお楽しみ）。レアスプルは、まだでも名前を出す（目標にするため）
- 並び: 仲間5人（設定の順）→ レアスプル10色（3-1 の順）

**`POST /api/world/companions/{key}/town`**（新規）— `in_town`（真偽、必須）

- 生まれていない子は 404
- 町が `town_limit` でいっぱいのとき町に出すと 422「町はいっぱいだよ。だれかをおうちで休ませてね」
- 相棒を休ませると 422「相棒はいつも町にいるよ」
- 返事: `{ companions, review }`（今の名前を付ける API と同じ形）

**`POST /api/world/partner`**（変更）— 町にいない子を選ぶと 422「町にいる仲間だけ相棒にできるよ」

**`POST /api/review/complete`**（変更）— やりきったとき `reviews_completed` を1増やす

## 5. 画面

### 5-1. 町のボタン

`town-buttons.tsx` の、おつかい・にぎやか度・家族の並びに「なかま」を足す。押すと、なかまの一覧（5-5）を開く。

### 5-2. 種をもらったお祝い

- `new_seeds` が空でなければ、町の上に出す
- 見出し「特別な種をもらった！」、種ごとに種の絵・「ルビーの種」・一言（`reason`）
- 下に「畑にまいてみよう」、ボタン「つづける」
- 生まれたときのお祝いなど、ほかのお祝いと重なるときは、ほかのお祝いの後に出す

### 5-3. どの種をまく？

- 畑が空いていて、ふくろに種があるとき、畑をタップすると下から出るカード
- 並び: 「スプルの種（なにが生まれるかな？）」（スプルの種ができているときだけ、緑の種の絵）→ ふくろの種（その色の種の絵と「ルビーの種」）→「やめる」
- 選ぶと種をまく。スプルの種は、今までどおりスプルが頭を振って種が飛ぶ。特別な種は、畑に種が植わる動きだけ

### 5-4. 畑と生まれたときのお祝い

- 畑の絵は `look` と状態で決める（3-4）
- 畑が光る（押せる合図）のは今のまま `can_sow` か `can_water` のとき
- 町のスプルをタップしたときの種まきと、スプルのふだんのひとこと「花が咲いたよ！タップして種をまこう」は、`spru_seed_ready` のときだけにする（特別な種だけのときに、スプルの花の話をしないため）
- スプルの種がなく、畑が空いていて、ふくろに種があるときのふだんのひとことは「特別な種を畑にまいてみよう！」
- 生まれたときのお祝い（`born-overlay.tsx`）
  - まずその子の花の絵が咲き（約0.8秒）、その後に本人が出る。仲間は緑の花、レアスプルはその色の花。動きを減らす設定のときは、花を飛ばしてすぐ本人
  - 見出しは今のまま「〇〇が生まれた！」
  - おうちで休む子なら、「町がいっぱいだから、おうちで休んでいるよ。なかまの一覧で町に出せるよ」を足す

### 5-5. なかまの一覧

- 町の上に下から全体に出るカード。見出し「なかま」と「町にいるのは 3/5」
- 「仲間」と「レアスプル」の2段。スマホで3列
- カード
  - `born`: 正面の絵・名前・ハート・「町にいる／おうち」を切り替えるボタン（町がいっぱいなら「町に出す」は押せず、相棒は切り替えられない）。カードをタップすると、今の仲間のカード（`companion-sheet.tsx`）を開く
  - `waiting` の仲間: 黒い影・`？？？`・「畑で生まれるよ」
  - `waiting` のレアスプル: 黒い影・名前・条件の文・細い棒・「あと3日」
  - `in_bag`: その色の種の絵・名前・「種のふくろにあるよ」
  - `growing`: その色の芽の絵・名前・「畑で育っているよ」
- 黒い影は、正面の絵を画面で黒く塗って見せる（影の絵は作らない）
- 仲間のカードで、おうちにいる子は「相棒にする」を押せず、「町に出すと相棒にできるよ」と出す

### 5-6. 絵

切り抜きの道具（`tools/spru-assets/extract.py`・`crops.json`）で、新しい設定画から作る。

## 7. テスト

### 7-1. サーバー（Pest）

- 条件の種類7つそれぞれ: 満たす・満たさない境目、`current` が目標で止まる
- `streak` の今の数: 昨日も今日も学んでいなければ0
- `catch_perfect`: 全問正解の回だけ数える。途中で終わった回・終えていない回は数えない
- `advanced_stages`: 上級のクリアだけ数える。クリアしていない進み具合は数えない
- `grant`: 満たした色だけ渡る、2回呼んでも1つ、新しく渡した色だけ返す、公開前の記録でも渡る
- `GET /api/world`: `new_seeds` が1回目だけ入る。家族の町を見ても渡らない
- 種をまく: 特別な種で `planted_at` が入り、畑の `look` がその色、育ち具合は戻らない。ふくろにない色・まいた色・知らないキーは 422。スプルの種がないのに `spru` は 422。畑に種があれば 422
- スプルの種の `look` は、生まれる子にかかわらず `spru`
- 特別な種に3回水をあげると、そのレアスプルが生まれ、`rare` が真
- スプルの種からレアスプルは生まれない。仲間5人の後は「スプルの花」
- 町に立つ数: 6体目はおうち、立ち位置は町にいる子だけで相棒が先頭
- 町に出す／休ませる: いっぱいなら 422、相棒は 422、生まれていない子は 404、ほかのプロフィールの子は触れない
- 相棒にする: おうちの子は 422
- 今日の復習をやりきると `reviews_completed` が1増える
- なかまの一覧: 状態4つ、仲間の名前は生まれるまで `？？？`、仲間は `growing` にならない、並び順

### 7-2. 画面（Vitest）

- `roster.ts`: 「あと3日」「あと2レベル」、目標に届いたときの文、状態ごとの文
- `garden.ts`: ふくろに種があるときは「どの種をまく？」、ふくろが空でスプルの種があればすぐまく、畑の絵が `look` と状態で決まる
- 生まれたときのお祝いの文（おうちで休む子）

### 7-3. ブラウザでの確認

- スマホの幅で、種をもらうお祝い → どの種をまく？ → 3日分の水やり（日付を進めて確かめる）→ 花が咲いてレアスプルが生まれる
- 6体目がおうちで休み、一覧で町に出す・休ませる・相棒にする
- 一覧の黒い影・条件・棒の見え方
- 仲間の種はなぞのまま（緑）で育つ
- 確かめたあと、開発用のデータを元の状態に戻す

- 確率で出るレアスプル
- 期間限定の種
