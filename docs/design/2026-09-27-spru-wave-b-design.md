# スプルの成長サイクル・水やり・仲間の誕生（B回）— 設計書

- 作成日: 2026-09-27
- ステータス: Owner合意済み（設計の各区切りを対話で確認）
- 前提: `docs/design/2026-09-26-world-town-design.md`（町・ポイントで買って置く）、`docs/design/2026-09-26-spru-wave-a-design.md`（表情・ポーズ・演出・時間帯と季節）。どちらも実装済み

## 1. 背景と目的

A〜Eの5回で作る「仲間と成長」の2回目（A回の設計書1章の表を参照）。学ぶことが「スプルが花を咲かせる」「自分で育てた種から仲間が生まれる」につながり、毎日開きたくなる流れを作る。

- ループ: 学ぶ → レベルアップ → スプルにつぼみ → 花 → 種ができる → 町の畑にまく → 毎日学んで水をあげる → 仲間が生まれる
- 相棒えらび・仲間ごとの成長・仲間からの復習問題はC回で作る

## 2. 決定事項（Owner確認済み）

| 論点 | 決定 |
|---|---|
| 正式な仲間 | **mascot-4・6の5人**: Lumi（光・ひらめき）、Momo（花・やさしさ）、Kuru（木の実・知識）、Piko（葉・冒険）、Ruru（水・知恵）。mascot-2の色違い（ルミ・ミナ・モモ・グロウ）は使わない |
| スプルが育つもの | **レベルアップ1回で1段階**。ふつう → つぼみ → 花 → 種ができた（3回で種1つ） |
| レベルの上がり方 | **だんだん上がりにくくする**（次のレベルまで100から1レベルごとに+20、上限300）。**正解のXPは難しさで変える**（初級10・中級15・上級20）。学習ポイントは10のまま |
| 生まれる仲間 | **まだ生まれていない仲間からランダムに1人**。5つ目の種で必ず全員そろう |
| 水やり | **その日に1問でも正解したら、町で1日1回水やりできる**。3回（3日分）で生まれる。休んでも枯れない |
| 5人そろった後の種 | **「スプルの花」（町に置けるアイテム、非売品）が咲く** |
| 作り方 | **記録はサーバーに持ち、育ち具合はレベルから計算する**（育ち具合そのものは保存しない） |
| 置き場所 | **畑はスプルの家の前のマス**（スプルの隣）。**仲間は横長の道に、生まれた順に並ぶ** |

### 今後の方針（Owner確認済み、B回では作らない）

- 金色などの特別な仲間は、後から追加できるようにする。仲間の一覧に「出やすさ」を持たせる
- 確率は子どもが届く範囲にする（例: 5%＋「種10個目までに必ず出る」天井）。目標達成で必ずもらえる「記念の仲間」も検討する。数字は追加するときに決める
- **コインで種を買う・育つのを早める・生まれる仲間を選び直す機能は作らない**（お金でくじを引く形にしないため）。確率で出る仲間を公開する前に専門家へ確認する

## 3. 遊びのルール

### 3-1. スプルが育つ

育ち具合（growth）＝ min(今のレベル − 前に種をまいたときのレベル, 3)。

| growth | スプル | レベルアップのお祝いに足すひとこと |
|---|---|---|
| 0 | ふつう | なし |
| 1 | Sの先につぼみ | 「スプルにつぼみがついた！」 |
| 2 | 花が咲く | 「スプルの花が咲いた！」 |
| 3 | 花＋種ができた | 畑が空いていれば「種ができた！町でまいてみよう」、畑に種があれば「畑の芽が育ったら、種をまけるよ」 |

- 種ができた後にさらにレベルが上がっても、growthは3のまま（種を持ったまま待つ）
- 今あるプロフィールは、更新時に「前に種をまいたときのレベル」を今のレベルにする（growth 0から始まる）。新しいプロフィールは1

### 3-2. 種をまく

- 条件: growth が3、かつ畑に育っている種が無い
- スプルか畑をタップすると、スプルが頭を振って種が飛び、畑に種が植わる。「前に種をまいたときのレベル」を今のレベルにする（growth 0に戻る）
- 生まれるものは種をまいた時点でサーバーが決め、生まれるまで画面に送らない
  - まだ生まれていない仲間から、「出やすさ」の重みでランダムに1人（B回は5人とも同じ重み）
  - 全員生まれていれば「スプルの花」

### 3-3. 水やり

- 条件: 畑に種がある、今日（日本時間）1問以上正解している、今日まだ水をあげていない
- 畑をタップすると、スプルが水をあげ、畑の芽が一段育つ。3回目で生まれる
- 休んでも枯れない（育つのが止まるだけ）。日の切り替えは日本時間0時（連続日数と同じ）

| 畑の状態 | 水やりの回数 | 見た目 |
|---|---|---|
| empty | （種なし） | 土の畝 |
| seed | 0 | 種 |
| sprout | 1 | 小さな芽 |
| sprout_big | 2 | 大きな芽 |

### 3-4. 畑とスプルのひとこと

| 状況 | 畑をタップ | スプルの画像 | ひとこと |
|---|---|---|---|
| 種がまける | 種まき | 頭を振る → 種が飛ぶ | 「種をまいたよ！毎日水をあげて育てよう」 |
| 空の畑で、まだ種ができていない | 何もしない | 考え中 | 「レベルが上がると、スプルに花が咲くよ」 |
| 水をあげられる | 水やり | 水やり | 「大きくなあれ！」 |
| 今日まだ正解していない | 何もしない | 考え中 | 「今日1問正解したら、水をあげられるよ」 |
| 今日もう水をあげた | 何もしない | にっこり | 「今日はもう水をあげたよ。また明日ね」 |

- 置く場所を選んでいる間は、畑もスプルも押せない
- スプルのふだんのひとこと（できごと・夜の眠り・座る・寝るの後、A回の時間帯のあいさつの前）:
  - 種がまける: 「花が咲いたよ！タップして種をまこう」
  - 今日の水やりができる: 「芽に水をあげよう！」
- スプルをタップしたとき: 種がまけるなら種まき。それ以外はA回どおりの反応で、ひとことの候補の先頭に「畑に水をあげよう！」（今日の水やりができるとき）を足す

### 3-5. 仲間が生まれる

- 3回目の水やりで、画面全体のお祝いを出す
  - 仲間: 「〇〇が生まれた！」＋仲間の絵＋紹介文＋ひとこと＋「町にむかえる」ボタン
  - スプルの花: 「スプルの花が咲いた！バッグに入れたよ」＋花の絵＋「つづける」ボタン（バッグに入り、町に置ける）
- 仲間は生まれた順に道の決まった位置に立つ。タップすると跳ねて、頭の上に吹き出し（名前とひとこと）が3秒出る

| 仲間 | 紹介文 | ひとこと |
|---|---|---|
| Lumi | 光・ひらめき | 「ひらめいた！いっしょに学ぼう」 |
| Momo | 花・やさしさ | 「お花、きれいだね」 |
| Kuru | 木の実・知識 | 「ものしりになりたいな」 |
| Piko | 葉・冒険 | 「冒険に行こうよ！」 |
| Ruru | 水・知恵 | 「じっくり考えるのが好き」 |

- 夜22〜6時と、動きを減らす設定のときは、仲間はゆれない

### 3-6. レベルの上がり方

- 次のレベルまでに必要なXP: min(100 + 20 × (今のレベル − 1), 300)
- レベルに届くまでの合計XP: Lv.2=100、Lv.3=220、Lv.4=360、Lv.5=520、Lv.6=700、Lv.7=900、Lv.8=1120、Lv.9=1360、Lv.10=1620、Lv.11=1900、Lv.12=2200、以降は300ずつ
- 正解のXP: 問題（`questions.quiz_id` → `quizzes.difficulty`）が初級10・中級15・上級20。難しさが無い・不明なら10。ステージの難しさと問題の難しさは全件一致している（2026-09-27確認）
- レベルは下がらない（新しい計算のレベルが今の保存値より低い間は、今のレベルのまま。次のレベルは新しい計算で届いたときに上がる）
- レベルアップ時のHP全回復など、今の動きは変えない

## 4. データとサーバー

### 4-1. テーブル

| テーブル | 変更 |
|---|---|
| `user_profiles` | `bloom_base_level`（前に種をまいたときのレベル、unsigned smallint、既定1。更新時に今の `level` を入れる）、`last_correct_on`（最後に正解した日、日本時間の日付、null可）を追加 |
| `profile_seeds`（新規） | `id`、`user_profile_id`（削除連動）、`result_key`（仲間のキーか `spru_flower`）、`waterings`（0〜3）、`last_watered_on`（日本時間の日付、null可）、`bloomed_at`（咲いた日時、null可）、timestamps。`bloomed_at` が null の行が「育っている種」で、1人1つまで（処理側で保証） |
| `profile_companions`（新規） | `id`、`user_profile_id`（削除連動）、`companion_key`、timestamps（`created_at` が生まれた日時）。(`user_profile_id`, `companion_key`) は一意 |
| `shop_items` | 「スプルの花」を1件登録（type `decoration`、currency `point`、price 0、min_level 1、meta `{"asset_key": "spru_flower", "not_for_sale": true}`） |
| `profile_world_items` | 更新時に、畑のマス（x=1, y=2）に置かれているアイテムを全員分バッグへ戻す（x・y を null） |

### 4-2. 設定

- `config/companions.php`（新規）: 仲間の一覧（キー → 名前・紹介文・ひとこと・出やすさ）、生まれるまでの水やり回数（3）、種がまけるgrowth（3）、全員そろった後の結果キー（`spru_flower`）
- `config/world.php`:
  - `land.landmarks` に `['key' => 'garden', 'x' => 1, 'y' => 2]` を追加（目印なので置けないマスになる）
  - `companion_spots`: 仲間の立ち位置（道のマス）`[[0,3],[2,3],[4,3],[5,3],[6,3]]`。6人目以降を足すときは位置も足す（位置が足りない仲間は、町のAPIで x・y を null にして町には描かない）
  - `rewards.xp_by_difficulty`: `['初級' => 10, '中級' => 15, '上級' => 20]`
  - `level_curve`: `['base' => 100, 'step' => 20, 'max' => 300]`

### 4-3. API

- `GET /api/world` に追加:
  - `spru`: `{ growth: 0|1|2|3 }`
  - `garden`: `{ x, y, state: "empty"|"seed"|"sprout"|"sprout_big", waterings, learned_today, watered_today, can_sow, can_water }`（`result_key` は含めない）
  - `companions`: `[{ key, name, trait, line, x, y }]`（生まれた順）
  - `profile.level_xp`: `{ floor, next }`（今のレベルに届いた合計XPと、次のレベルに必要な合計XP。町の上のバーに使う）
- `POST /api/world/garden/sow`: 条件を満たせば種を植え、`{ spru, garden }` を返す。満たさなければ422（「まだ種ができていないよ」「畑に芽が育っているよ」）
- `POST /api/world/garden/water`: 条件を満たせば水やりし、`{ garden, born }` を返す。`born` は null、`{ kind: "companion", key, name, trait, line, x, y }`、`{ kind: "item", world_item }` のどれか。満たさなければ422（「畑に種がないよ」「今日1問正解したら、水をあげられるよ」「今日はもう水をあげたよ。また明日ね」）
- 回答API（`POST /api/questions/{id}/answer`）: XPを難しさで決める。正解したら `last_correct_on` を日本時間の今日にする。`profile` に `spru_growth`・`garden_busy`（育っている種があるか）・`level_xp` を足す
- ショップ一覧: `not_for_sale` のアイテムは出さない。購入APIも422で断る。Ownerの町のアイテム一覧では「非売品」と表示する
- 種まき・水やりは購入と同じく、トランザクションの中でプロフィールを `lockForUpdate` してから確かめる（二重に押しても2回にならない）

## 5. 画面

### 5-1. 町のスプル

- growth 1はつぼみ、2・3は花を、A回のどの画像でもSの先に重ねて描く（種まきの2枚は花が描かれているので重ねない）
- ひとことの優先順とタップの動きは3-4のとおり。種まき・水やり・畑の案内はA回の「できごと」の仕組みに足す
  - 種まき: 「頭を振る」1.2秒 →「種が飛ぶ」1.2秒
  - 水やり・案内: 2.6秒（吹き出しの言葉はA回と同じく8秒残る）

### 5-2. 畑

- 目印として描く（土の畝＋状態の絵）。種がまける・今日の水やりができるときは、置き場所を選ぶときと同じく光る
- 畑のボタンはアイテムのボタンと同じく奥から順に並べる。置く場所を選んでいる間は押せない

### 5-3. 仲間

- 立ち位置に仲間の絵を置き、少しずつずれたタイミングでゆっくりゆれる。タップで跳ねて吹き出し3秒
- 夜22〜6時と動きを減らす設定ではゆれない

### 5-4. 生まれたときのお祝い

- A回のレベルアップの演出と同じ見た目の全画面表示（3-5の内容）

### 5-5. 町の上のバー

| growth | 右側の表示 |
|---|---|
| 0 | 「つぼみまで あと〇XP」 |
| 1 | 「花まで あと〇XP」 |
| 2 | 「種まで あと〇XP」 |
| 3 | 「種ができた！」 |

- バーの長さと残りXPは `profile.level_xp` から計算する（今の「XP100ごと」の計算はやめる）

### 5-6. クイズ

- レベルアップのお祝いに、3-1のひとことと、つぼみ・花の付いたスプルを足す
- 正解・不正解・結果の画面のスプルにも、回答APIの `spru_growth` に合わせてつぼみ・花を付ける（まだ1問も答えていないHP切れの画面は付けない）

## 7. テスト

### バックエンド（Pest）
- growthがレベルアップの回数どおりに変わり、3で止まる
- 種まきの条件と422。まくとgrowthが0に戻る
- 生まれるものが、まだいない仲間から選ばれる。全員いれば `spru_flower`
- 水やりの条件（種がある、今日正解した、1日1回）と、日本時間0時の切り替え
- 3回目で仲間が生まれ、町のAPIに立ち位置つきで出る。`spru_flower` はバッグに入り、ショップ一覧に出ず、買えない
- 回答APIの `result_key` が漏れない（町のAPIにも出ない）
- レベルの上がり方（各レベルの合計XP、上限300）、難しさごとのXP、レベルが下がらない
- 畑のマスにあったアイテムがバッグに戻る

### フロントエンド（Vitest）
- 畑をタップしたときの動き（3-4の表）
- スプルのふだんのひとことの優先順
- 町の上のバーの表示（5-5の表）
- タップしたときのひとことの候補の追加分

## 8. やらないこと（B回の範囲外）

- 相棒えらび、仲間ごとの成長、仲間からの復習問題（C回）
- 特別な仲間・記念の仲間・天井（一覧に「出やすさ」を持たせるところまで）
- 仲間の表情・ポーズ（絵が1人1枚のため）
- 仲間の一覧ページ・図鑑
- 畑を2つ以上にすること、種をためておくこと
- ショップ・バッグ画面にスプルや仲間を出すこと
- Ownerの管理画面から仲間を登録すること（設定ファイルで管理）
