- 作成日: 2026-10-10
- ステータス: 実装済み（2026-10-10。地図・ずかん。絵と壁紙は届いてから。方向はOwner合意済み 2026-10-10: 宇宙ぼうけんマップ＋うちゅうずかん。行き先は月〜冥王星の9つ）
- 前提: ミニゲーム「うちゅう旅行」（`docs/design/2026-10-09-space-trip-design.md`。到着する星の仕組みあり）、宇宙の問題（`docs/design/2026-10-09-space-quiz-design.md`。絵の問題35種は届き次第）、小出し（`docs/design/2026-10-09-minigame-rollout-design.md`）
- きっかけ: Ownerの提案（2026-10-10）。今の宇宙のゲームは「1回遊んで終わり」。星を順にたどる地図と、集めるずかんで、続ける理由を作る

## 1. 目的
宇宙のゲームを、**進む楽しさ**（地図の星を順に開く）と、**集める楽しさ**（ずかんのカードが増える）で、何日も続けて遊べるようにする。

**遊び方**
1. うちゅう旅行を開くと、**宇宙の地図**が出る。星が順に並び、ロケットが今いる星にいる。開いている星をタップすると、そこへ向かって遊べる
2. 星ごとに、10問の旅（今のうちゅう旅行と同じ遊び）。**6問以上正解**でクリア。クリアすると、次の星が開く。星の評価は、正解の数で ⭐1〜3
3. くり返し遊んで、⭐を増やせる
4. **うちゅうずかん**: 宇宙の絵（35種）のカード。一度でも**正解した**絵が、カードとして開く。地図の星をクリアしたら、その星のカードが「新しく手に入った！」と知らせる

**うまくいった目安**
- 最初は月だけ開いている。クリアすると、水星・金星…と順に開く（9つ。最後は冥王星）
- 星ごとに、いちばんよい⭐が残る。くり返して⭐3にできる
- ずかんは、宇宙の絵の問題に正解するたびに、自然に埋まる（クイズ・うちゅう旅行・スライドパズルのどれで正解しても）
- 今のうちゅう旅行の遊び・ごほうびの決まりは変えない

## 2. 決定事項
| 項目 | 決定 |
|---|---|
| 行き先 | 9つ: 月 → 水星 → 金星 → 火星 → 木星 → 土星 → 天王星 → 海王星 → 冥王星（最後。「準惑星」のおまけ）。太陽・地球は行き先にしない（ずかんのカードとして、最初から持っている） |
| 難しさ | 星の順で決まる: 月・水星・金星 = 初級／火星・木星・土星 = 中級／天王星・海王星・冥王星 = 上級（今の難しさの設定を使う） |
| クリア | 出た問題のうち、6割以上の正解（10問なら6問）。星の評価は、6割以上 ⭐1、8割以上 ⭐2、全問正解 ⭐3。問題の数が少ないとき（絵の問題が届くまで、初級は8問）も、割合で決まる |
| 開く順 | 前の星をクリアすると、次の星が開く。いちばん最初（月）は、最初から開いている |
| 遊び方 | 今のうちゅう旅行の遊び（隕石をよけ、答えの門をくぐる）。問題の選び方も今のまま（まちがえた問題・出す日が来た問題を先に） |
| ごほうび | 1回ごとの経験値・ポイントは今のまま（1日3回・全ゲーム合計6回の上限も同じ）。加えて、**はじめてクリアした星**に、経験値30・ポイント30のボーナスを1回だけ（上限とは別） |
| ずかんのカード | 宇宙の絵（`pictures.csv` の全種類）。一度でも、その絵を正解の選択肢とする問題に正解したら開く（開いた日を `profile_space_cards` に残す。あとでまちがえても消えない）。カードに、絵・名前・ひとこと（`pictures.csv` の説明）。開いていないカードは、シルエットと「？」 |
| 地図からの遊び方 | 「うちゅう旅行」の最初の画面を、難しさの選択から地図に替える。今の難しさの選択は、地図の下の「れんしゅう」から（⭐やクリアの記録には入らない） |
| 絵が届くまで | 地図は、星の名前と色のついた丸で出す（今の「到着する星」と同じ）。ずかんは、絵が届いてから出す |

## 3. 設計
### 3-1. サーバー
- DB: `profile_space_stops`（`user_profile_id`・`stop`（星のキー）・`stars`（0〜3の最高）・`cleared_on`・一意 `(profile, stop)`）
- DB: `profile_game_plays.stop`（地図から始めた回の星のキー。なければ null）
- 設定 `config/space_map.php`: 星の順番・星のキー・難しさ・クリアの基準（6問）・星の基準・はじめてのボーナス・各星のひとこと
- `SpaceMap`（新規）: `state(profile)` が、各星の状態（開いている/クリア・⭐）、今いる星、はじめてクリアした星のボーナスを返す。`record(profile, play, correctCount)` が、地図から始めた回の結果を、星の記録に書く（最高の⭐だけ更新。はじめてのクリアはボーナス）
- API:
  - `GET /api/games/space-trip/map`: 地図の状態
  - `POST /api/games/space-trip/plays` に `stop`（任意）。開いていない星はエラー。難しさは星から決める（`difficulty` は送らなくてもよい）
  - `finish` の返事に、地図から始めた回なら `map`（その星のクリア・⭐・新しく開いた星・はじめてのボーナス・新しいカード）を足す
- `SpaceCards`（新規）: `list(profile)`（全カードと、開いているか）。開く条件は、問題ごとの覚え具合（`profile_question_memories`）で、その問題の正解の選択肢の絵が、`pictures.csv` のどの絵か、で決める。新しく手に入ったカード＝この回の答えで、はじめて開いたもの
- API: `GET /api/space/cards`

### 3-2. フロント
- 地図の画面: 縦にスクロールする道に、星を順に並べる。今いる星にロケット。クリアした星は⭐つき、開いている星は光る、閉じた星は暗くて鍵。星をタップすると、星の名前・ひとこと・⭐・「出発！」
- 結果の画面: クリアしたら「クリア！次の星が開いたよ」。新しいカードがあれば、カードのお祝い
- ずかんの画面: カードの一覧（絵・名前・ひとこと）
- 壁紙は、`company/spra/spra-world/prompts/ready/171-space-wallpaper-portrait.md` の2枚。届くまでは、今の背景

## 4. テスト
- Pest: 最初は月だけ開いている／6問以上でクリア・5問以下は未クリア／クリアで次の星が開く／⭐は最高のものだけ残る／はじめてのクリアだけボーナス／開いていない星は始められない／星から難しさが決まる／地図から始めない回（れんしゅう）は記録に入らない／ずかん: 正解した絵だけ開く・まちがえただけでは開かない／新しいカードは、はじめて開いた回の返事にだけ入る
- Vitest: 地図の状態の組み立て／星の評価の表示／ずかんの表示
- 確認: スマホ幅（375px）で、地図・遊ぶ・結果・ずかん

## 5. 問題の数についての注意
今ある宇宙の問題は文字の問題が30問だけで、絵の問題（35問）は絵待ちです。9つの星で、同じ問題が何度も出る。**星のテーマに合う問題を足す**（Codexに依頼）ことと、絵の問題が入ること（ずかんも埋まる）が、この遊びの本番です。設計は、問題の数に依存しないように作る（星ごとの専用の問題は、あとで足せる）

## 6. やらないこと
- 星ごとの専用の問題（今回は今の問題の混ぜ合わせ。足りなければ、あとでCodexに依頼）
- ボス・ストーリー・キャラクターのセリフ
- ほかの子との星の数の競争（家族の合計の目標は、あとで）
- 太陽・地球を行き先にすること
