# MVP要件定義

> **2026-07-31時点の最新の仕様・決定事項は `SPEC.md` を参照。** 本ドキュメントは当初のMVPスコープ検討の記録として残すが、「1ヶ月でリリース」等の一部内容はスコープ拡大（Stripe決済・法務文書・アクセシビリティ対応・対象国拡大）により`SPEC.md`で更新されている。

このドキュメントは「最初に一般公開する版（MVP）」に何を含み、何を含まないかを定義する。事業目標（月商100万円）に対し、機能を無限に広げるのではなく、まず動く冒険ループを世に出し、ユーザーの反応を見ながら育てることを優先する。

## 現状棚卸し（2026-07-29時点、CEO確認）

### 実装済み

| 領域 | 内容 |
|---|---|
| 認証 | Owner / Admin / User の独立マルチログイン（Laravel Breeze） |
| プロフィール | UserSchema（家族単位）→ UserProfile（プレイヤー、Netflix型） |
| マスタ管理（Owner画面） | Category, Quiz, Question/Choice, QuestionTheme, Stage, Region, Country, Language, ShopItem, Event, Content, Admin, User |
| 冒険ループ | Country一覧 → Region → Stage一覧（`travel/[countryId]`）→ クイズ回答（`quiz/[stageId]`, `play/[id]`） |
| 経済ロジック | 正解/不正解でHP・XP・Coin増減、ステージクリアでCoin付与（サーバー側`applyEconomy`で計算、台帳記録あり） |
| ショップ | コインでのアイテム購入・HP回復（`shop/page.tsx`、購入API） |
| 称号 | `title_reward` / `profile_titles` はデータモデル・API上は存在 |

### 未実装・薄い部分

| 領域 | 状態 |
|---|---|
| AI機能（Owner画面の「AI」タブ） | ほぼ未着手（スタブのみ） |
| 自動テスト | Breeze標準（認証/メール確認/パスワードリセット）のみ。**クイズ回答・ステージクリア・ショップ購入などお金に直結するロジックのテストが0件** |
| コンテンツ量 | 国マスタ（国名・国旗）は世界規模で用意済みだが、実際にプレイできる**ステージ・問題文はごく少数**（デモ相当）。現状の最大のボトルネックはエンジニアリングではなく**コンテンツ制作** |
| パスポート専用画面 | 未着手（`profile_stage_progress`からの導出想定、`docs/StageDesign.md`参照） |
| 旅演出（国到着シーン等） | 未着手 |
| 有料メンバーシップ | 価格・機能差分とも未確定 |
| Webサイト・ブログ・SNS | 未着手（`docs/company/MarketingPlan.md`） |

## MVPに含む機能（スコープイン）

- User登録・ログイン、プロフィール選択（家族単位）
- 冒険ループ一式: 国選択 → ステージ挑戦 → クイズ回答 → HP/XP/Coin増減 → ステージクリア → 次の国へ
- ショップでの簡易な回復アイテム購入
- ボスステージクリアによる称号付与（既存表示の範囲でよい、専用パスポート画面は不要）
- **絞り込んだ初期コンテンツセット**（全世界ではなく数ヶ国分、質を優先）

## MVPに含まない機能（スコープアウト、将来フェーズ）

- AI問題生成・AI先生・AI会話
- 有料メンバーシップの課金導線
- パスポート専用画面、旅演出（国到着シーンなど）
- フレンド機能、家族ランキング、学校向け・企業向けプラン
- スマホアプリ化
- 公式Webサイト本格運用・ブログ・SNS（マーケティングは別トラックで並行検討）

## 非機能要件（最低限）

- 経済ロジック（XP/Coin/HP、ショップ購入）は自動テスト必須（お金・ゲームバランスに直結するため最優先）
- 主要ユーザーフロー（国選択→クイズ→ステージクリア→報酬）が一気通貫で動作すること
- 認証情報の取り扱いはLaravel標準機能に準拠

## Owner確定事項（2026-07-29）

1. **コンテンツ規模**: 少数国に絞って質重視。`docs/MainQuiz.md`が最初に想定していた「日本・アメリカ・フランス・イギリス」の4ヶ国程度を軸に、各国は初級ステージ中心でしっかり問題数を確保する。世界規模の国マスタはそのまま残すが、MVPで実際にプレイできるのはこの少数国のみに絞る。
2. **公開時期**: できるだけ早く、1ヶ月程度を目標とする。
3. **課金導線**: MVPは無料のみで先行公開する。有料メンバーシップの導線設計はMVP範囲外（後続フェーズ）。

この確定により、MVPスコープから以下を明確に除外できる：有料課金導線一式、パスポート専用画面、旅演出、AI機能、フレンド/ランキング機能。

## 次のアクション

1. 経済ロジック（回答・ステージクリア・ショップ購入）の自動テストを実装する（1ヶ月という短い期間で品質を保つため最優先）
2. 対象4ヶ国分のステージ・問題文のコンテンツ制作計画を立てる（現状最大のボトルネック）
3. 上記2点と並行して、基本設計・詳細設計の過不足（`docs/StageDesign.md`との差分）を棚卸しする
