# 画面のまわりを整える — ヘッダー・下のメニュー・「じぶん」・右下のボタン — 設計書

- 作成日: 2026-09-28
- ステータス: Owner合意済み（ヘッダー・下のメニュー・クイズ中のヘッダーはブラウザの見本で選び、「じぶん」の中身・画面ごとの出し分け・部品の作りを対話で確認）
- 前提: UIパレット（`docs/design/2026-09-28-ui-palette-design.md`、クリーム色の部品・バッジ画像）。実装済み
- 対応するタスク: `TASKS.md` 開発部門（この設計で新しく足す）

## 1. 背景と目的

右上に 連続・ポイント・コイン・体力・アバター の5つが1列に並び、スマホ幅では窮屈で、体力ゲージはバーを省いている。右下には「文A」（文字の大きさ・ふりがな）と音のボタンが浮いていて、中身に重なる。クイズ中もロゴや連続・ポイント・コインが出ているが、クイズをやめるボタンはない。

ゲームそのものではなく、画面のまわり（ヘッダー・下のメニュー・設定の置き場所・右下のボタン）を整えて、すっきり見せる。見た目の配色（UIパレット）は変えない。

## 2. 決定事項（Owner確認済み）

| 項目 | 決定 |
|---|---|
| ふつうの画面のヘッダー | 案A: 左にロゴのマークだけ（「SpraGo」の文字なし）。右に縦2段で、上に体力ゲージ（スマホでもバー付き）、下に小さく連続・ポイント・コイン。右上のアバターはなくす |
| 下のメニュー | 案B: 学ぶ・旅する・**世界**（真ん中に丸く大きく）・ショップ・じぶん の5つ。バッグはメニューから外す |
| 「じぶん」 | 押すと今の画面の上に下からパネルが出る。名前とレベル、バッグ、パスポート、ふりがな、文字の大きさ、プロフィールを切り替える、ログアウト |
| クイズ中のヘッダー | 案A: やめる（✕）・文A・体力ゲージだけ。ロゴと連続・ポイント・コインは消す |
| 音のボタン | 右下に浮いたまま。見た目をスプルの顔にする |
| アイコン | 下のメニューと「じぶん」の中は、今は線のアイコンで作り、Ownerがスプルのアイコン画像を用意したら差し替える |

## 4. 部品

### 4-1. ふつうの画面のヘッダー（`components/app/app-header.tsx` を直す）

- 左: ロゴのマークだけ（`/logo.svg`、丸いクリーム色の土台）。押すと町（`/`）へ
- 右: 縦2段
  - 上: 体力ゲージ（`HpGauge`）。スマホでもバーを出す（今はスマホ幅でバーを隠している）
  - 下: 連続（0日のときは出さない）・ポイント・コインの小さなピル
- アバター・プロフィールのメニュー・ログアウトは外す（ログアウトは「じぶん」へ）
- ヘッダーの高さは今とほぼ同じ（1段ぶん＋少し）

### 4-2. クイズ中のヘッダー（`components/quiz/game-header.tsx`、新規）

- `quiz-session.tsx` の、問題に答えている間の画面だけで `AppHeader` の代わりに出す。結果画面・体力がなくなった画面・読み込み中やエラーの画面は、ふつうの画面のヘッダー（4-1）のまま
- 左から ✕（やめる）・文A・体力ゲージ（横いっぱい）
- ✕: 確かめの小窓（`components/ui/alert-dialog.tsx`）で「クイズをやめる？」「ここまでのポイントやコインはそのまま残るよ」、ボタンは「やめる」「つづける」。やめるは1つ前の画面へ戻る（`router.back()`）。1つ前が無い（直接開いた）ときは「学ぶ」（`/learn`）へ
- 文A: 押すと、ヘッダーの下に表示の設定（4-3）の小さなパネルを出す。もう一度押すか外側をタップで閉じる

### 4-3. 表示の設定（`components/app/display-settings.tsx`、新規の共通部品）

- ふりがな（オン・オフの切り替え）と、文字の大きさ（標準・大・特大）を1つにまとめる。中身は今の `AccessibilityControls` のパネルと同じ働き（`useAccessibility()` の `furigana`・`toggleFurigana`・`fontScale`・`setFontScale`）
- 見た目はクリーム色の新配色（見本のとおり、切り替えはスイッチ、大きさは3つの丸いボタン）
- 「じぶん」のパネル・クイズ中の「文A」・右下に残る「文A」の3か所で使う

### 4-4. 「じぶん」のパネル（`components/app/me-sheet.tsx`、新規）

- `components/ui/dialog.tsx`（Radix）を、画面の下から出るパネルの形にして使う。外側のタップ・Esc で閉じる。開いている間はパネルの中だけをキーボードで行き来できる
- 中身（上から）
  - 名前（頭文字の丸）とレベル（`useProfile()` の `name`・`level`）
  - バッグ（`/bag`）・パスポート（`/passport`）
  - 表示の設定（4-3）
  - プロフィールを切り替える（`/profiles`）
  - ログアウト（今の `AppHeader` の `handleLogout` と同じ: `POST /logout` のあと `/login` へ）
- 行を選んでページを移るときはパネルを閉じる

### 4-5. 下のメニュー（`components/app/bottom-nav.tsx` を直す）

- 並び: 学ぶ（`/learn`）・旅する（`/trip`）・世界（`/`、真ん中で丸く大きく、メニューの上にはみ出す）・ショップ（`/shop`）・じぶん（パネルを開くボタン、ページは移らない）
- 「じぶん」のアイコンは、今のアバターと同じ頭文字の丸
- 選択中の光らせ方は今と同じ（世界は `/` のときだけ、ほかはそのページとその下）。「じぶん」はパネルが開いている間だけ選択中にする
- バッグとパスポートのページでは、どれも選択中にしない

### 4-6. 町の画面（`components/world/world-hud.tsx`）

- 1段目のロゴから「SpraGo」の文字を外す（マークだけ）
- 1段目の右端（ハート・ポイントの右）に、バッグ（`/bag`）へのボタンを足す

### 4-7. 右下のボタン

- 「新しいメニューが出ているか」を覚える小さな仕組み（`components/app/menu-presence.ts`、新規）を作る。下のメニューとクイズ中のヘッダーが、出ている間だけ「出ている」と知らせる（出た数を数え、0より多ければ出ている）
- 右下の「文A」（`AccessibilityControls`）は、新しいメニューが出ていない画面だけで出す。パネルの中身は表示の設定（4-3）を使う
- 音のボタン（`SoundControls`）
  - 見た目: スプルの顔の丸。オンは笑顔（`SPRU_FACES.laugh`）に ♪、オフはふつうの顔（`SPRU_FACES.normal`）を少し薄くして ✕。専用のアイコンができたら差し替える
  - 位置: 右下の「文A」が出ている画面では今の位置（その上）、出ていない画面では1段下（下のメニューのすぐ上）

### 4-8. 計算だけの部品（Vitestでテストする）

- 下のメニューの並び（`NAV_ITEMS` の順番と行き先）と、選択中の決め方（`isNavActive(pathname, href)`）。`bottom-nav.tsx` から、画面を描かない部分を `components/app/nav-items.ts` に分ける
- 新しいメニューが出ているかの数え方（`menu-presence.ts`: 出す・消す・今の状態）
- 音のボタンの絵の選び方（`soundFace(enabled)`: オン→ `laugh` と ♪、オフ→ `normal` と ✕）
