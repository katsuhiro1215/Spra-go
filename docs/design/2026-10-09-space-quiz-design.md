## 1. 目的

宇宙の問題60問を、アプリに取り込む。同じ問題を、**クイズ（学ぶ→ミニクイズ）**と、**ミニゲーム（次の設計）**の両方で使えるようにする。幼児向けに、半分（30問）は「絵を選ぶ問題」にする。

**うまくいった目安**

1. 1つのコマンドで、CSVから、クイズの問題とステージが作られる。何度流しても重複しない
2. ミニクイズの一覧に「宇宙」が自動で出る（ステージが3つ以上）
3. 絵の問題は、4つの絵から選べる。絵がまだ無い問題は、出さない（絵が届いて、もう一度流すと増える）
4. CSVを直して再取り込みすれば、問題が直る

## 2. 今の状態

- 「宇宙」のカテゴリーは、種として入っているが、問題は0件（`CategorySeeder`）。
- 国旗クイズで、次の部品がすでに動いている: 大もとのカテゴリー（`is_course_group`）の下に、コース・級・ステージ・ボスを書く `FlagQuizWriter::writeTree`、選択肢に絵（`meta.image`）を付ける仕組み、重複しない書き込み（問題を `meta.flag_key` で見つける）。画面（クイズ・ゲームの選択肢）も、絵つきの選択肢に対応済み。
- 英語のスプルキャッチは、「英語を学ぶ」のステージの問題から、難しさ・4択・選択肢の短さで選んでいる。

## 3. 決定事項

| 項目 | 決定 |
|---|---|
| 取り込みの方法 | `php artisan space:import`（CSV→クイズ）。国旗クイズのシーダーと同じく、何度流しても重複しない。書き込みは `FlagQuizWriter` を共通に使う（名前は変えない。キーの `meta.flag_key` も、そのまま使う） |
| 計画の作り方 | `SpaceQuizPlanner`（CSVの行→コース・ステージ・問題の計画。データベースに触らない純粋な計算。国旗の `FlagQuizPlanner` と同じ形） |
| カテゴリー | 今ある「宇宙」を、大もと（`is_course_group`）にして使う。コースは1つ（9章の案）。級は 初級・中級・上級 |
| ステージ | 初級24問 → 3ステージ（8問）、中級24問 → 3ステージ（8問）、上級12問 → 2ステージ（6問）。各級の最後のステージがボス。前のステージをクリアすると次が開く（今の決まり） |
| 問題の順番 | CSVの順番（テーマごとにまとまっている）。ステージの中は、今の仕組みで選択肢の位置だけ混ぜる |
| 絵 | 選択肢に `meta.image = /space/{キー}.webp`。絵は `frontend/public/space/` に置く。キーは `pictures.csv` に足す英字の名前（4章） |
| 絵がまだ無い問題 | 取り込まない（選択肢の絵の1つでも無ければ、その問題は出さない）。ファイルの有無を見て決め、何問あとで増えるかを、コマンドの結果に出す |
| 解説 | `questions.explanation.summary` に入れる（英語と同じ） |
| ミニゲームの問題 | クイズと同じ問題を使う（国旗キャッチのような専用の問題は作らない）。次の設計で、遊びと選び方を決める。そのため、問題に `meta.space = true`・`meta.difficulty` などの目印は付けず、カテゴリー「宇宙」の問題を難しさ（ステージの級）で選べばよい |

## 5. 取り込みの流れ

1. `company/` はコンテナから見えないので、CSVを `database/data/space/` にコピーする（`tools/space/sync.sh`。英語の `tools/english/sync.sh` と同じ）。
2. `space:import` が、`questions.csv`・`pictures.csv` を読み、形を検証する。
   - 検証: 全問で、選択肢4つ・重複なし・全角6文字以内・難しさが3つのどれか・絵の問題は4つとも `pictures.csv` にある、のどれかが崩れていたら、止めて、行番号を出す（何も書かない）。
3. 絵のファイルの有無を見て、取り込める問題を決める（絵が無い問題は外す）。
4. `SpaceQuizPlanner` が、難しさごとに、取り込める問題を、ステージの大きさ（8問・6問）で区切る。端数は最後のステージに足す。最後のステージはボス。
5. `FlagQuizWriter::writeTree('宇宙', ...)` で書く。結果に「コース1・ステージN・問題N（絵が無くて外した問題: N）」を出す。

`--dry-run` で、検証と件数だけ見られる（書かない）。

### 問題の形

| CSVの形 | 問題の種類 | 選択肢 |
|---|---|---|
| `4択` | 4択（文字） | 文字の選択肢 |
| `絵4択` | 4択（絵） | 名前（label）と絵（`meta.image`）。画面は絵を大きく見せ、名前は小さく添える（国旗クイズと同じ） |

## 6. 画面

- **クイズ**: 画面の変更は、ほぼ要らない。学ぶ→ミニクイズに「宇宙」が自動で出る（ステージが3つ以上）。ステージの絵（カテゴリーのアイコン）は、あとで足す（なければ、今の既定の絵）。
- **絵の選択肢**: 国旗クイズで動いている「絵つきの選択肢」を、そのまま使う。絵が正方形（国旗は横長）なので、枠の大きさ・見え方だけ、実装で確かめる（スマホ幅375px）。

## 7. テスト

- サーバー（Pest）:
  - `SpaceQuizPlanner`: 難しさごとの問題数・ステージの区切り（8・8・8／8・8・8／6・6）・ボス・端数、絵が無い問題が外れる、絵の問題の選択肢に `image` が付く。
  - `space:import`: 件数、再実行で増えない、CSVを直して再実行すると問題が直る、不正なCSV（選択肢の重複・6文字超え・知らない絵の名前）で止まる、`--dry-run` は書かない。
  - 実際の `questions.csv`・`pictures.csv`（60問・35種）が検証を通る。
- フロント（Vitest）: 絵の選択肢の大きさ・並び（必要なら）。
- 確認: 取り込み後、ミニクイズに「宇宙」が出て、初級のステージ1を、スマホ幅（375px）で遊べる（絵が無い間は、文字の問題だけ）。確認後、検証用のプロフィールを元に戻す。

## 8. 確認してほしいこと

1. **コースの数**: 「宇宙」の下は、コース1つ（初級・中級・上級）でよいか。幼児向けに、「えを みて あてよう」と「ちしき」の2コースに分ける案もある（絵の問題が30問と、文字の問題が30問ずつ。1コースあたりのステージが減る）。私のおすすめは1コース。
2. **ボスの称号**: 各級のボスをクリアしたときに、称号を出すか（例: 「うちゅうたんけんたい」「うちゅうはかせ」）。英語のコースにはある。
3. **絵が揃うまでの扱い**: 絵が無い問題を外す形でよいか（初めは、文字の問題30問だけで動き、絵が届くたびに、もう一度流して増える。公開前なので、ステージの区切りが変わっても影響がない）。
4. **ミニゲームの問題**: クイズと同じ問題を使う形でよいか（問題ごとの覚え具合が共有される。国旗キャッチは、専用の問題を作っていた）。

## 9. 実装の順序（実装計画で細かくする）

1. `SpaceQuizPlanner`（純粋な計算）とテスト。
2. `space:import`（検証・絵の有無・書き込み）とテスト。`tools/space/sync.sh`。
3. `pictures.csv` にキーを足す。
4. 取り込み（絵なし）と、画面の確認。
5. 絵が届いたら、絵の選択肢の見え方の確認と、取り込み直し。SPEC・TASKSの更新。
