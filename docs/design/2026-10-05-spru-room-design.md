## 1. 背景と目的

今のスプルは、夜は、町の道の上で寝ている（「すやすや…」）。家の中のベッドで寝る形にしたい。町のスプルの家をタップすると、家の中をのぞける部屋が開き、昼は手を振る・座るスプル、夜はベッドで眠るスプルが見える。育てる・置く機能は入れない（Spra-worldの役目）。

**うまくいった目安**

1. 町のスプルの家をタップすると、部屋の画面が開く。「もどる」で町へ戻る
2. 昼は、部屋に起きているスプルがいて、タップすると手を振る。しばらく触らないと座る
3. 夜（スプルが寝る時間）は、ベッドで眠るスプルの絵になる。部屋は少し暗くなる
4. 町では、夜、スプルが道の上で寝る姿がなくなり、スプルの家のところに、眠っているしるし（ふきだし）が出る
5. 家具・部屋・スプルが、スマホ幅でも切れずに、きれいに重なる

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 入口 | 町のスプルの家（目印 `spru_house`）をタップ。家そのものがタップできる（別のしるしは出さない） |
| 部屋の中身 | 部屋の絵＋ベッド・テーブル・椅子（固定）。家具は動かせない・買えない |
| スプル（昼） | 起きたスプル。初めは立った姿（待機）。タップで手を振る（1.6秒）、触らずに8秒たつと座る。タップすると、また手を振る。ひとこと（ふきだし）も出る |
| スプル（夜） | ベッドで眠る一体の絵（空のベッドと入れ替える）。起きているスプルは出ない。タップすると、「すやすや…」のふきだし |
| 昼・夜 | 今のスプルが寝る時間（`isSpruSleepTime`）と同じ。部屋を開いたまま時刻が変わったら、変わる |
| 町のスプル | 夜（寝る時間）は、町の道の上のスプルを描かない。家のところに「z z z」のしるし。昼は、今のまま（町にスプルがいる。部屋は、のぞくだけで、昼の部屋にもスプルがいるが、気にしない） |
| 向き | 左下向き1方向だけ（今ある絵）。ほかの向きの待機絵は、今回は使わない |
| ルミ・ほかの仲間 | 変えない（ルミの新しい絵は、今回は使わない。TASKS に残す） |
| 画面の作り | 町の上に重ねる全画面のカード（ほかのカードと同じ）。新しいページは作らない |

## 3. 絵の取り込み（`tools/room-assets/make_room.py`）

- 元の絵（1254×1254・透過）を、透明の余白を詰めて切り抜き、WebPにして `frontend/public/spru/room/` に出す。出す物と大きさ（長い方の辺）: `room`（1024）、`bed`・`bed_sleeping`・`table`・`chair`（512）、`spru_idle`・`spru_wave`・`spru_sit`（384）
- 配置は、**元の1254×1254の座標**で決める（切り抜く前の位置を基準にすれば、絵どうしの大きさの比が、そのまま使える）。そのため、出力と一緒に、各絵の切り抜き位置（元の絵の中の左上の位置と幅・高さ）を、`frontend/src/components/room/room-assets.ts`（スクリプトが書き出す。手で直さない）に書く
- 合計は、400KB以内

## 4. 配置（`components/room/room-layout.ts`）

部屋は、元の1254×1254の座標で組む。各物は、**足元の中心の位置（`cx`・`bottom`）と倍率（`scale`）**で置く。手前の物が奥の物に重なるよう、奥から手前の順に描く。

| 物 | 倍率 | 足元の中心 `(cx, bottom)` | 備考 |
|---|---|---|---|
| 部屋 | 1 | — | 背景 |
| ベッド（昼）／眠るスプル入りのベッド（夜） | 0.34／0.30 | (900, 820) | 窓の下、右の奥の壁ぎわ。夜は絵が入れ替わる |
| テーブル | 0.27 | (560, 920) | 部屋の中ほど |
| 椅子 | 0.19 | (430, 1000) | テーブルの手前の左 |
| スプル（昼） | 0.20 | (700, 1040) | 部屋の手前の床。待機・手を振る・座る |

- 数字は、試作の合成で決めた初期値。ブラウザで見て、微調整する（`room-layout.ts` の値だけを直す）
- 夜は、全体を少し暗くする（`filter: brightness(0.8) saturate(0.9)`）。窓の光は、今のスプルの家と同じ、あたたかい色の光の輪（半透明）を、窓の位置（部屋の絵の右奥の丸窓）に重ねる

## 5. 動き（純粋な関数 `components/room/room-state.ts`）

- `roomMode(date: Date): "day" | "night"` — `isSpruSleepTime(date)` が真なら夜
- `roomSpruPose(state: { lastTapAt: number | null; openedAt: number }, now: number): "idle" | "wave" | "sit"` — `lastTapAt` から1.6秒以内は `wave`。それが過ぎて、`lastTapAt`（なければ `openedAt`）から8秒以上たったら `sit`。それ以外は `idle`
- ふきだしのひとこと: 昼は「やっほー！」「おかえり！」「きょうも いい日だね」のどれか（タップのたびに、順に回す）。夜は「すやすや…」
- 時刻は、1秒ごとに見直す（町と同じ。部屋が開いている間だけ）

## 6. 町の変更（`world-scene.tsx` ほか）

- スプルの家（目印）に、タップの範囲を足す（町の畑 `garden` のタップと同じ作り）。タップで、部屋を開く（`onHouseTap`）
- 夜（`spru.sleeping`）は、町のスプル（`kind: "spru"` の描画）を出さず、家の上に「z z z」のしるし（SVGの小さな文字）を出す。昼は今のまま
- 部屋を開いている間も、町は、後ろで今までどおり動く（アニメーションは止めなくてよい）

## 7. テスト

- **画面（Vitest、純粋な関数）**: `roomMode`（寝る時間の境）、`roomSpruPose`（手を振る1.6秒・8秒で座る・タップで戻る）、`room-layout`（すべての物が1254×1254の中に収まる・夜はベッドが入れ替わる・奥から手前の順）
- **ブラウザ**: 町の家をタップ→部屋→「もどる」。昼は手を振る→座る。夜（寝る時間。確認のため、手元で時刻を変える）はベッドで眠る・町に寝るスプルがいない・家のしるし。デスクトップ幅・スマホ幅。確かめたあと、開発用のデータを元に戻す
- サーバーは変えない

## 8. やらないこと

- 家具を買う・置く・動かす（Spra-worldの役目）
- スプル以外の仲間の部屋（ルミのポーズ・家は、あとで）
- スプルの向きを変える（4方向の待機絵）、歩き回る
- 部屋の画面での、学習・ごほうび・おつかいとの連携
- 音
