# ミニゲーム「スライドパズル」（テーマ違いで出す）— 設計書

- 作成日: 2026-10-09
- ステータス: 実装済み（2026-10-09。国旗パズルをブラウザで確認。宇宙パズルは絵が届いてから。Ownerの発案・方針合意 2026-10-09。1回3枚・難しさ3段・テーマごとに別のゲームとして出す）
- 前提: ミニゲームの共通部分（`app/Support/CatchGame.php`・`config/games.php`）、小出し（`docs/design/2026-10-09-minigame-rollout-design.md`）、国旗の問題（`国旗キャッチ` の絵つきの選択肢）、宇宙の絵の問題（`docs/design/2026-10-09-space-quiz-design.md`。絵は届き次第）

## 1. 目的
今の3本（落ちてくる答えを選ぶ）と違う、**手を動かして考える**ミニゲームを足す。絵を、バラバラの状態からスライドさせて完成させ、「これはなんでしょう」に答えてゴールする。かかった時間も残す。

**遊び方**
1. 上に、完成した絵（見本）。下に、切ったピースのパズル（1つは空きマス）
2. 空きマスの隣のピースをタップすると、そこへ滑る。同じ列・行のピースは、まとめて滑る
3. 絵が完成すると、1枚の絵につながり、「これはなんでしょう」と4択が出る
4. 3枚（3つのパズル）で1回。最後に、時間・正解の数・ごほうび

**うまくいった目安**
- 必ず解ける並びで始まる。最初から揃っていない
- 2×2・3×2・3×3の3段の難しさ。スマホ幅（375px）で、ピースが指でタップできる大きさ
- 時間は、パズルごとと合計。自己ベストが残る（ほかの子との順位はつけない）
- 国旗のパズルが、今ある問題だけで遊べる。宇宙のパズルは、絵が届いたら出せる
- 小出しの仕組み（出す日・NEW・今週のゲーム・ごほうびの上限）に、そのまま載る

## 2. 決定事項
| 項目 | 決定 |
|---|---|
| 出し方 | テーマごとに別のゲーム（`puzzle_flag`・`puzzle_space`）。仕組みは1つ。テーマは絵と名前のセット。今のスプルキャッチ（英語・こっき）と同じ作り |
| 1回 | 初級3枚・中級2枚・上級1枚。1枚ごとに「パズル → 最後のピースを入れる → 4択」（Owner 2026-10-10: 簡単な2×2は3枚、難しい3×3は2枚、4×4は1枚でストレスがないように） |
| 難しさ | 初級 2×2／中級 3×3／上級 4×4（3×2はやめた。Owner 2026-10-10）。最後のピース（右下の絵）は盤の右横に置き、ほかが並んだらタップして入れると完成 |
| 動かし方 | 空きマスと同じ行・列のピースをタップすると、そこまでまとめて滑る。見た目が同じピースは入れ替わっていてもよい（見た目が合えば「ならんだ」） |
| 出す国旗 | ピースの見た目の種類が少なすぎる旗（ハンガリー・イタリア・フランス・ドイツなど、同じ色のピースばかりになるもの）は出さない。盤の大きさごとに、使える旗の一覧を作る（`tools/puzzle/flag-allowlist.mjs` → `database/data/puzzle/flags.json`。2×2は203枚・3×3は126枚・4×4は65枚）。そのうちからランダム |
| 夜の画面 | 空の上の文字は、時間帯で色を変える部品（`SkyText`）を使う |
| 並べ方 | 完成形から、ランダムに合法な手を何手か動かして作る（必ず解ける）。簡単すぎない（ピースが元の場所から離れた合計が、2×2で3・3×3で8・4×4で14以上） |
| 時間 | 最初に動かしてから、完成までの時間（パズルのみ。4択を考える時間は入れない）。合計と自己ベスト（難しさごと）。ごほうびは時間で決めない |
| 4択 | 正解の名前＋その問題のまちがい3つ（今の問題の選択肢の名前）。ふりがな付き。まちがえたときは、正解を見せる |
| 点数・ごほうび | `CatchGame` の共通（正解1問あたりの経験値・ポイントは難しさごと）。1日3回・全ゲーム合計6回の上限も共通。答えは問題ごとの覚え具合に残る |
| 問題の出どころ | 国旗: `国旗キャッチ 初級・中級・上級` の問題の、正解の国旗と国名。宇宙: 宇宙のカテゴリの「絵の問題」（正解の選択肢に絵があるもの） |
| 出す日 | 国旗パズルを先に。宇宙パズルは、絵が届いてから（問題が0のときは「じゅんびちゅうだよ」） |

## 3. 設計
### 3-1. サーバー
- `config/games.php`: `puzzle_flag`（`quiz` で難しさごとの問題を指す）・`puzzle_space`（`category: 宇宙`）。どちらも `question_count: 3`、`review_max: 2`、`daily_rewarded_plays: 3`、難しさごとに `lanes: 4`（選択肢の数）・`grid: [列, 行]`・`reward`。`image_required: true`（正解の選択肢に絵があるものだけ使う）。`catalog` は `released_on: null`
- `CatchGame`: 
  - `fits` に `image_required` の条件を足す
  - `start` と `summary` に `grid` を返す。`summary` に難しさごとの `best_ms`（自己ベスト）を足す
  - `finish` が `elapsed_ms`（パズルにかかった合計の時間）を受けて保存する。`finish` の返事に `elapsed_ms`・`best_ms`・`new_best_time`
- 画面の名前: `puzzle-flag`・`puzzle-space`。`GameRollout::PATHS`・ルート・`rollout.php` の一覧に足す
- DB: `profile_game_plays.elapsed_ms`（符号なし整数・null可）
- 検証: `elapsed_ms` は 0〜3,600,000

### 3-2. フロント
- `frontend/src/lib/slide-puzzle.ts`（画面を描かない部分）: 並べ方・動かし方・完成の判定・時間の整形
- `frontend/src/components/games/puzzle/`: 盤（絵を背景として切る。透過の絵は星空の背景の上に置く）・ページ（選択 → 3枚 → 結果）・結果
- ゲームの一覧（`MINI_GAMES`）に、国旗パズルを足す。ふりがなは自動

### 3-3. 絵の見せ方
- 見本の絵（上）は小さめ。パズルの盤は、絵の縦横の比率（国旗 3:2、宇宙 1:1）で、横幅いっぱい（最大 360px）
- ピースの境目は細い線で見せる。空きマスは、ふちだけの枠
- 完成したら、線を消して1枚の絵にしてから、4択を出す

## 4. テスト
- Pest: 国旗パズルの問題が、絵つきのものだけで3問出る（初級・中級・上級）／選択肢は4つ（正解＋まちがい3）／宇宙パズルは、絵つきの問題がなければ「じゅんびちゅうだよ」／finish で `elapsed_ms` と自己ベストが保存・更新される／ごほうびは1日3回・全体6回の共通／出す日の前は404
- Vitest: 並べ方が必ず解ける（何度でも）・完成形と違う／同じ行・列のピースがまとめて滑る／完成の判定／時間の整形
- 確認: スマホ幅（375px）で、国旗の初級・中級・上級を遊ぶ

## 5. やらないこと
- ほかの子との時間の順位・ランキング
- ヒント機能（完成の見本は常に上に出している）
- 音・効果音（あとで）
- 宇宙以外のテーマの追加（どうぶつ・たべものは、絵ができてから）
