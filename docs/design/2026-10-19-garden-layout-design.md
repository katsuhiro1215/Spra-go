# 畑と家の位置の入れかえ・畑の前で水をあげる — 設計書

- 作成日: 2026-10-19
- ステータス: **Ownerの指示で実装**(2026-10-19。段階3の前に行う)。ブランチ `feature/garden-layout`
- きっかけ: Ownerの提案。(1) 畑を十字の道に面させ、その左側にSpruの家を置く。(2) 水やり・種まきは、Spruがいる所でなく、**畑の前に来て「水をあげますか？」と聞く**形にする。全ユーザー共通

## 1. 位置

| | 今 | 新しい |
|---|---|---|
| Spruの家(2×2) | (1,1)〜(2,2) | **(0,1)〜(1,2)**(畑の左側) |
| 畑 | (0,2) | **(2,2)**(右の(3,2)と手前の(2,3)が十字の道) |
| 仲間の最初の立ち位置 | (3,2) | **(3,4)**(畑の前の(3,2)は、Spruが水やりに立つので空ける) |

- 十字の道(x=3・y=3)・鳥居・石灯籠・Spruのいつもの場所(4,3)は変えない。
- 設定は `config/world.php` の `land.landmarks`・`companion_spots` だけ。画面は `land` の座標をそのまま使うので、画面の絵の位置は変わる。
- **すでにある町への影響**: 新しく目印になる(0,1)・(0,2)・(1,1)・(1,2)・(2,2)のうち、アイテムが置かれうるのは(0,1)だけ。引いた道(段階2a)がかかっているマスもありうる。
  - 置き物 → `world:repair` が、置けなくなった物をバッグに戻す(消さない。今までの仕組み)。
  - 引いた道 → `world:repair` が、目印にかかった道を消す(バッグがないので消す)。`WorldRepair::roads()` を足した。
  - 古い家(1,1)〜(2,2)・畑(0,2)のあとで、あいたマス(2,1)・(0,2)・(2,2)の一部は、置ける・引ける場所になる。

## 2. 畑の前で聞く

1. 畑をタップ(または、種をまける状態でSpruをタップ)すると、**Spruが畑の前のマスまで歩く**。畑の前は、右のマス(x+1, y)と手前のマス(x, y+1)で、経路がいちばん短いほう。
2. 着いたら、画面の下に「**水をあげますか？** [あげる][やめる]」(種まきは「種をまきますか？ [まく][やめる]」)。
3. 「あげる」で、今までのAPIを呼び、畑の前で水やりの絵・ひとこと(「大きくなあれ！」)が出る。「やめる」でそのまま。
4. 種をえらぶとき(特別な種がある)は、着いたら種の一覧を出す(聞かない)。言葉だけの返事(「今日はもう水をあげたよ」など)のときは、歩かない。
5. 途中で別のマスをタップ・道具を出す・アイテムを動かすときは、用事をやめる。夜に家で寝ているSpruは歩かず、その場で聞く。

- サーバーのAPI(`/api/world/garden/sow`・`water`)・水やりの決まり・育ち方は変えない。

## 3. テスト

- Pest: 家(0,1)・畑(2,2)・畑の両わきが道・家のとなりのあき(2,1)・畑の座標(家族の町)・仲間の立ち位置・置けない場所の表・`world:repair`(置き物と、引いた道)。
- Vitest: 畑の前のマス(`gardenFrontTiles`)・聞き方(`gardenAsk`)・いちばん近い行き先(`nearestRoute`)。
- 画面(Playwright・スマホ幅): 畑をタップ→Spruが歩く→「水をあげますか？」→あげる(水やりのAPIを1回)→札が消える。

## 4. 本番に出すとき

- デプロイのあと、サーバーで **`world:repair --dry-run`**(戻る物・消える道を確かめる)→ **`world:repair`**(`production:bootstrap` にも入っているので、流せば同じ)。
