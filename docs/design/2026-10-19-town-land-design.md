## 1. 目的

- 町を、17×17(289マス)から、32×32(1,024マス)へ広げる。置く場所が足りなくなってきているので、長く遊べるようにする。
- 広げても、がらんとしないよう、外側の新しい区画には、**置けない自然の景色**(木・岩・茂み)を、少し入れる。
- 今の町の座標は変えない。**置いたアイテム・引いた道・畑・家は、移し替えなしで、そのまま使える**。

## 2. 今の町(読んだ結果)

- 地図は17×17。区画は7つ(はじまりの町7×7・竹林・海辺・丘・川辺・高原・離島)で、必要レベルは Lv.1・5・10・15・20・25・30。区画は、地図の中に隙間なく並ぶ(テストで確認)。
- 地図の大きさは、区画の右端・下端の最大から、サーバーが計算する(`WorldLand::width()`・`height()`)。画面も、`land.width`・`land.height` を使う。**区画を足せば、地図は広がる**。
- 道は、横が y=3・y=9、縦が x=3・x=9 の格子(`config/world.php` の `land.paths`)。海のマスは、陸の四隅を欠いた3か所。
- レベルの上限はない(`LevelCurve`。「頭打ちなし」)。必要な合計XPは、Lv.30で約1.1万、Lv.40で約2.1万、Lv.50で約3.6万、Lv.60で約5.6万(1問の経験値は10〜20)。
- 画面は、町(最初の区画)が枠の横幅に収まる倍率を「1」にして、スクロール・拡大する(`TownMap`・`map-view.ts`。倍率は0.4・0.6・1・1.5)。地図全体を1枚のCanvasに描く(段階1)。

## 3. 地図の広げ方

17×17の外側(東と南)に、L字に区画を足して、32×32にする。**原点(0,0)は動かさない**。

```
        x=0         16 17            31
   y=0  ┌──── 今の17×17 ────┬── 東の区画 ──┐
        │ 町・竹林・川辺 ... │ 森  草原  湖  │
  y=16  │ 海辺・丘・高原・離島│              │
  y=17  ├─── 南の区画 ───────┼── 角の区画 ──┤
        │ 林  ...           │ ...          │
  y=31  └───────────────────┴──────────────┘
```

### 3-1. 新しい区画(案)

| 名前(案) | 位置 x,y,幅×高さ | 必要レベル | 地面(今ある絵) |
|---|---|---|---|
| 東の森 | 17,0, 5×12 | Lv.35 | 竹林の地面(`bamboo`) |
| 草原 | 22,0, 10×12 | Lv.40 | 町の地面(`grass`) |
| 東の海辺 | 17,12, 15×5 | Lv.45 | 砂(`sand`) |
| 南の林 | 0,17, 12×15 | Lv.50 | 丘(`hill`) |
| 南の高原 | 12,17, 5×15 | Lv.55 | 高原(`plateau`) |
| 南東の島 | 17,17, 15×15 | Lv.60 | 離島(`islet`) |

- 区画の名前・並び・必要レベルは、**案**。ほかの形でもよい(隙間なく並び、重ならない決まりは、テストで守る)。
- 地面の絵は、**今ある絵を使い回す**(新しい絵は要らない)。新しい地面の絵は、届いたら差し替える(`GROUND_ART` に1行足すだけ)。
- 今のレベルが足りない人(ほぼ全員)には、新しい区画は**雲に隠れて**見える(今の竹林などと同じ。「Lv.35で解放」の札つき)。
- 区画が開いたときのお祝い(`plots_new`・雲が晴れる)は、今のまま。新しい区画のひとことは `UNLOCK_LINES` に足す(なければ「新しい土地が広がったよ」)。

### 3-2. 道

- 今の格子を延ばす。横の道 y=3・y=9 を x=31 まで、縦の道 x=3・x=9 を y=31 まで。新しい区画の中の道は、**自分で引く**(段階2の機能)。
- 海のマス(`water`)は、今のまま(新しい区画の中の海は、足さない)。今の地図の端にあった海のくぼみ(15〜16,0〜1 など)は、そのまま湖のように残る。

### 3-3. 自然の景色(置けない飾り)

- 新しい区画に、**木・岩・茂み**を、マスの座標から決まる位置(毎回同じ)に、少し置く。**置けない目印**として扱う(道・畑・家と同じ。アイテムは置けない・Spruは通れない)。
- 密度は、区画の面積の約8%。**道のマス・区画のふち1マス・海**には置かない。絵は今ある `tree`・`pine`・`large_tree`・`birch`・`bush`・`rock`。
- サーバーが `land.landmarks` に足して返す(開いた区画のものだけ)。画面は今の目印と同じに描く(新しい描き方は要らない)。**今の7区画には足さない**(置いた物に影響しないため)。
- 景色の木を、あとで「伐る」などで置ける場所にする話は、今回しない。

## 4. サーバー

| 場所 | 内容 |
|---|---|
| `config/world.php` | `land.plots` に6区画を足す。`land.paths` を延ばす。`land.scenery`(区画ごとの密度・絵の種類) |
| `WorldLand::landmarks()` | 設定の目印 + 景色(`scenery()` が、区画・座標から決まる位置を作る。何度呼んでも同じ) |
| `WorldLand::toArray()` | 変わらない(区画・目印・道が増えるだけ) |
| `WorldRepair` | 変えない。今の座標の物は、そのまま置ける。新しい区画は雲(Lv.35〜)なので、置き物は入らない |
| 家族の町 | 同じ `land` を使うので、そのまま広がる |

- 景色は、設定ファイルに書き並べず、**決まりから作る**(約8%・座標のハッシュ。`decalAt` と同じ考え方)。サーバーと画面で、同じ位置を出す必要はない(サーバーが作って送るだけ)。

## 5. 画面

- **倍率**: 地図が約4.6倍の幅(今は約2.5倍)になるので、全体を1画面に入れる最小の倍率を下げる。`ZOOM_STEPS` を、0.2・0.35・0.6・1・1.5 にする(0.2で、32×32全体が1画面に入る)。
- **メモリ**: Canvasは、幅4096pxの上限がある(段階1)。32×32では、倍率1で約3,600px×2,000px(1枚約30MB)。層が3枚+作業用で、ピーク約120MB。**実機のスマホで測り**、重ければ、画面の密度の上限を下げる(`MAX_DPR` 2 → 1.5。大きい地図だけ)。
- **雲**: 閉じた区画の雲(最大で約700マス分)は、いまは毎フレーム描く。雲は動かない(開いた直後の動きだけ)ので、**地面の層に入れて、保存する**。毎フレームの重さを増やさない。開いた直後の雲(`veil`)は、今のまま動く層で描く。
- **見る位置**: 最初に、家と畑のある町の区画が、枠に収まる位置に出る(今のまま)。「スプルの家へ戻る」ボタンも、そのまま。
- **歩く・道を引く**: 広くなっても同じに動く(経路探索は、開いた区画の範囲だけ。重くならない)。道は、上限300マスのまま(広い土地で足りなければ、あとで設定を変える)。
- 地図の描き方を、見える範囲だけにする(カメラ)のは、48×48にするときの仕事。今回はしない。

## 6. テスト

- **Pest**: 区画は13で、重ならず、32×32の中に隙間がない / 必要レベル(35〜60)で開く / 新しい区画は、レベルが足りなければ目印・景色・道が出ない(雲)/ 道の格子が延びて、置けないマスに入る / 景色は、毎回同じ位置・道・ふち・海にない・密度が約8% / 景色のマスには置けない・道を引けない / 今の7区画に景色が入らない / 今の座標の物は、そのまま置けて、`world:repair` が何も戻さない / 家族の町も広がる。
- **Vitest**: `zoom`(新しい倍率の列)・雲の層に入ること(`scene-model`)・目印の型(景色のキー)。
- **画面**(Playwright・スマホ幅): 雲が増えた地図が最小倍率で全体に入る / 開いた区画(テスト用にレベルを上げる)で、景色が出て、置けない・歩けない / 軽さ(段階1の数値と比べる)。**実機のスマホでの確認は、Ownerにお願いする**。

## 8. 危ないところ

- **メモリ(スマホ)**: 5章のとおり。実機で測る。重ければ、密度の上限・層の数を減らす。それでも重いなら、48×48と同じ、カメラ(見える範囲だけ描く)の作りに前倒しする。
- **新しい区画が、全員に雲として出る**: 今の町の東と南に、雲の区画が増える。広がりを感じさせる一方で、「また雲か」と感じるかもしれない。札(「Lv.35で解放」)で、先の楽しみとして見せる。
- **Lv.35以上は、ほとんど誰も届いていない**(テスト用のデモ以外)。新しい区画の中身の遊びは、届く人が出るまで、試せない。`town:demo`(Lv.30のデモ)をLv.60にして、確認に使う。
- **新しい地面の絵がない**: 今の絵の使い回しなので、似た地面が並ぶ。絵が届いたら差し替える。
