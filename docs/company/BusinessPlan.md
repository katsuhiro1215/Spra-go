# 事業計画

## サービス概要

- サービス名: SpraGo（仮）
- コンセプト: 「世界を冒険しながら、自分だけの世界図鑑を完成させるRPG」
- 興味が世界を広げ、世界が言葉を教えてくれる。ゲームとして遊んでいるうちに、自然と言語・文化・歴史・地理への興味が広がる教育エンタメを目指す。

詳細な世界観・ゲーム設計は以下を参照：

- `docs/AppInfo.md` — コンセプト・システム構成全体
- `docs/MainQuiz.md` / `docs/MainQuizDesign.md` — メインクイズ企画（クイズ＝戦闘、世界図鑑を埋める体験設計）
- `docs/Stage.md` / `docs/StageDesign.md` — ステージ機能の仕様・設計

## ターゲット

老若男女問わず楽しめるWebアプリ。

## プラットフォーム戦略

1. フェーズ1: Webアプリとして展開（Next.js、PC・スマホブラウザ対応）
2. フェーズ2: 事業拡大が見えた段階でスマホアプリ（Flutter / React Native等）への移行を検討

## 事業目標

- 当面のマイルストーン: **月商100万円**
- 達成手段の試算（必要ユーザー数・課金率など）はCEO主導でマーケティング部門・企画部門と詰める

## 収益モデル（`docs/AppInfo.md`より）

- メンバーシップ: 無料 → 有料 → ファミリー（将来追加）
- ポイント経済（XP・コイン）とショップ（将来的な課金アイテムも検討）
- 将来的に学校向けプラン・企業向けプランも視野
